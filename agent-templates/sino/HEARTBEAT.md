自动巡检，没人在旁边。按下面四步走，**能不动手就不动手**。

## 1. 复盘回流（每次必做）

`hamuna ops list review --json` 看最近投放的复盘数据。

- 有素材已经投放超过 48 小时、但还没建复盘 → 提醒用户录一次数据（数据只有他能从后台看到）
- 已有的复盘出现新规律 → `hamuna ops add rule --source reflection`，`status: proposed`，`confidence` 按样本量给（一条样本不给超过 0.4）
- 都没变化 → 什么都不做

**不要为了"有话说"硬造结论。** 两条数据说服不了任何人。

## 2. 排期空缺（每次必做）

`hamuna ops list asset --json` 看已排期的素材。

- 这周还有空档、手上又有 `ready` 但没排期的素材 → 提醒一句「X 还没排期，要不要定个时间」
- 排期撞车（同一天同一平台两条）→ 提醒
- 都满 → 不做任何事

**不要自动排期。** 时间是否合适只有用户知道。

## 3. 卡住的活（每次必做）

- 选题停在 `planned` 超过 7 天 → 提醒「X 排进制作一周了，还做吗」
- 素材停在 `draft` 且 `progress` 一周没动 → 提醒
- 最多提 1 条，挑最久的

## 4. 有东西要说才说

- **什么都不用做** → 只回 `HEARTBEAT_OK`，一个字都别多
- **有东西要说** → 挑最重要的**一件**说，3 行内，别罗列全部发现

一次心跳最多说一件事。用户不是来读日报的。

---

## 红线（override 一切）

1. **不采集需要登录态的数据。** 无人值守时没有登录态，打不开创作者后台。数据采集一律留到用户在场时手动做。
2. **不发布、不改账号设置、不评论、不私信。** 心跳期间权限是全开的，靠你自己守。
3. **不花钱。** 不调付费生成（图 / 视频 / 音乐 / TTS）。
4. **不改 `ops/state.json`。** 一切写操作走 `hamuna ops`，见 `.claude/rules/05-OPS.md`。
5. **不重复。** 上一轮说过、这轮没新进展的事不要再提。翻 `memory/` 最近的日志确认。
6. **拿不准就沉默。** 回 `HEARTBEAT_OK` 是正确行为，不是失败。
