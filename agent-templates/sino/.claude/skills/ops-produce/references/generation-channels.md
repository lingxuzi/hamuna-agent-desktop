# 生成通道：谁来画、谁来拍、谁来配音

> **方法论来源**：本项目自研（Easel / Beav 都不管"用哪个工具生成"，两边没有对应文件）——
> 没有上游要同步，改这里不用看别处。

`visual-director.md` 管**画什么**（分镜、锚点、封面表）。这份管**拿什么去画**，
以及没有工具可用时怎么办。

## 一、先看有什么，再决定怎么调

**不要凭记忆写工具名。** 当前会话里能用的生成工具，就是工具列表里真实存在的那些 `mcp__*`。

1. 看工具列表，按能力分三档：**出图** / **出视频** / **出语音**（TTS）。
2. 每一档可能不止一个来源（内置的、用户自己装的第三方）。挑**当前会话真的有**的那个。
3. 工具的参数怎么传，以它的**工具描述**为准 —— 版本会改参数名，记忆里的签名不作数。

**sino 常见的三档（供对照，不是唯一答案）：**

| 能力 | 工具名前缀 | 典型工具 | 备注 |
|---|---|---|---|
| 出图 | `mcp__multimedia-creator__` | `agnes25_image_generate` / `agnes25_image_edit` | 跟随工作区默认启用；`_edit` 才是能带参考图的那个 |
| 出视频 | `mcp__multimedia-creator__` | `agnes25_video_generate` | 有 `text` / `keyframe` / `reference` 三种模式 |
| 出语音 | `mcp__edge-tts__` | `text_to_speech` / `list_voices` | 内置，需用户开启 |
| 出图（备选） | `mcp__gemini-image__` | `generate_image` / `edit_image` | 内置，需用户开启；**只能文生图，收不了参考图** |

**对不上就是没启用，别硬编。** 列表里找不到出视频的工具，就是这一轮做不了
`video_aigc` —— 走第三节，不要拿"再试一次"或者"换个名字猜"顶上。

## 二、真实物料怎么进画面

用户的要求是**画面里的产品必须是资产库里真实的那个**，不是"长得像"。

流程始终是：`ops/materials/` 里的原件 → 当**参考图**传进生成工具 → 生成。

**参考图必须真的传进去，不能只在 prompt 里描写。** 每张要在 prompt 里写明角色
（`visual-director.md`「主体锚点与环境锚点」）：

```
图 1：产品形状与材质参照（折叠桌，桌面纹理和卡扣结构以此为准）
图 2：场景氛围参照
```

- **视频**：用参考图引导模式（`reference` 类），把产品图放进 `images[]`，prompt 里用
  `<Picture 1>` 这类占位符指回它。有明确起终点语义的两张图才用首尾帧模式。
- **图片**：必须用**能接收本地文件路径**的工具（`agnes25_image_generate` / `agnes25_image_edit`
  都有 `image_paths`），而不是纯文生图 —— 纯文生图必然把产品画歪。
  ⚠️ `gemini-image` 的 `edit_image` **不能**当参考图通道：它只接受自己上一轮生成的 `contextId`，
  传不进 `ops/materials/` 的原件。没装 multimedia-creator 时它只能做纯文生图，不能做产品图。
- **没有产品实拍**（只翻到描述性 note、或者原件根本不在）→ 停下问人。**不要用生成画面
  顶替真实产品**，那正是这条流水线要解决的问题。

## 三、工具不在 / 生成失败：三条路，别自己选第三条

| 情况 | 怎么办 |
|---|---|
| 没有对应能力的工具（未启用） | 报给人「缺出视频通道，需要开启 X」。**不要降级成自己拼** |
| 调用报错（余额不足 / 参数不合法 / 超时） | 重试**最多一次**；还失败就报人，带原始错误 |
| 生成出来主体变形 / 产品认不出 | 加死锚点重跑，**需要重跑问一句再跑**（每张都是时间和钱），见 `visual-director.md` 第七节 |

**降级只能由人决定。** 真要退回 `image_text` 做，必须人点头，并在台账上写
`--downgrade-note`（`05-OPS.md` 有口径）。自己悄悄降级 = 用户以为拿到的是视频。

## 四、产物落盘

生成工具通常写到它自己的输出目录（默认 `~/HamunaAgent/agnes-output` 之类），
**那不是工作区**。拿到结果后：

1. 复制到 `ops/assets/<assetId>/`，文件名带角色（`cover.png` / `shot-01.mp4` / `vo.mp3`）。
2. 台账里图片走 `--image`，成片走 `--video` —— **两者不同列**，别把视频塞进 `--image`。
3. 源物料的路径记进 `--source-ref`，下一轮才知道这条成品用了哪批原图。

## 五、本文件不管什么

- **画什么、怎么构图、锚点怎么写** — `visual-director.md`。
- **什么时候可以调付费生成** — `SKILL.md` 的预览硬门（拼图确认过才行）。
- **生成前的合规** — `compliance-gate.md`。脚本没过关就调生成 = 花钱做一个不能发的东西。
