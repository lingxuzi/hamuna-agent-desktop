## 一、吸睛机制：一张图只用一个主机制

「吸睛机制」指画面靠什么把人钉住。**一次一个主机制，最多再加一个次机制**——两个主机制并排，读者只觉得吵。

| 机制 | 什么时候用 | 画面怎么做 |
|---|---|---|
| `oversized_headline` | 大多数封面、观点、清单、承诺 | 巨大可读的字，2–8 个字，高对比 |
| `human_gaze` | 人设、亲身经历、口播封面 | 面部特写，直视镜头，表情明确 |
| `macro_texture` | 食材、锅底、材质、手工 | 极近特写，纹理（蒸汽 / 油光 / 纤维 / 切面） |
| `hard_flash` | 街头、夜市、年轻感 | 直打闪光，硬阴影，故意像随手拍 |
| `color_block` | 清单、价格、品类强钩 | 饱和色块，边界清楚，配色大胆 |
| `surreal_scale` | 新品、概念、礼盒 | 巨大化单个物件 + 极小场景，夸张但干净 |
| `problem_scene` | 痛点内容、翻车、误区、对比 | 杂乱/尴尬的真实场景，前后反差 |
| `creator_proof` | 实操、测评、开箱、探店 | 手、第一视角、真实使用痕迹 |
| `handwritten_markup` | 攻略、教学、清单 | 箭头、圈、批注、手写标注 |
| `collage_layer` | 合集、趋势、节日 | 抠图、贴纸、层叠道具，编辑感 |
| `diagonal_motion` | 动感、旅途、上菜、清理 | 斜构图、轻微动态模糊、动态裁切 |
| `cinematic_light` | 高级感、严肃话题 | 戏剧光比、轮廓光、氛围 |
| `saveable_checklist` | 攻略、教学、知识型 | 干净卡片 + 大承诺 + 可收藏的小清单 |
| `event_culture_hook` | 节日、赛事、时令 | **只放一个文化锚点**，不要堆符号 |

**判断顺序**：先问「读者点进来是想要什么」（一个结果 / 一个反差 / 一个身份认同 / 一个可收藏的清单），再选机制。**不要先选风格再倒推内容。**

## 二、风格包

风格包是「整张图的视觉配方」，和吸睛机制正交：机制说靠什么抓人，风格包说整张图长什么样。

| 风格包 | 适合 | 视觉配方 |
|---|---|---|
| `XHS Saveable Editorial` | 攻略、清单、生活建议 | 精致版式，干净标题区，有用的视觉标注 |
| `Creator Handheld Proof` | 测评、实操、产品、**探店** | 手、桌子、真实房间、诚实质感 |
| `Hard Flash Street` | 潮流、年轻、**夜市** | 手机闪光感，大胆裁切，生猛 |
| `Dopamine Flatlay` | 送礼、文具、小食 | 明亮平铺，俏皮道具，强对比 |
| `Mess To Calm` | 收纳、清洁、效率 | 前后反差，最终是安静整洁 |
| `Chrome Edge Tech` | 电子、工具 | 冷光、金属/玻璃、锐利边缘光 |
| `Premium Editorial` | 高端、严肃品牌 | 雕塑感构图，克制的字，高概念 |
| `Warm Golden Lifestyle` | 家庭、**食物**、情感 | 暖光，有人生活的痕迹，软但饱满 |
| `Theatrical Reveal` | 发布、礼物、公告 | 聚光、揭幕手势、缎带/卡片 |
| `Pinterest Saveable Moodboard` | 规划类 | 精致生活场景，可收藏的清晰标题 |
| `Bilibili Explainer Thumbnail` | 测评、教程、知识视频 | 表情鲜明的主体 + 对比图 + 可信的标题 |

## 三、平台与品类的倾向

**平台倾向**（只说画面气质，不说画幅）：

| 平台 | 倾向 |
|---|---|
| 抖音 / 快手 | 快钩子、高对比，人和动作/结果放前面 |
| 小红书 | 可收藏、有用、生活质感，强但克制 |
| 视频号 | 信任、关系、成熟干净 |
| 微博 | 事件海报感、话题标题、公共情绪 |
| B 站 | 测评/讲解承诺、表情鲜明、内容可信 |
| 知乎 / 公众号 | 结论先行、可信证据，少装饰 |

**品类倾向**（我们这个号最常用的是这三行）：

| 品类 | 强方向 |
|---|---|
| **食物 / 饮品 / 小食** | 咬、倒、蒸汽、脆、冰、一桌人 |
| **食材 / 产地** | 极近纹理、湿气、土、切面、竹筐 |
| **门店 / 探店** | 门头、桌面、锅第一次沸腾、服务员的手 |

## 四、节日与事件借势：做生活场景，不做官方海报

这条最容易做错：一看到节日就做「XX 节快乐」的红底金字。**那不是借势，那是把节日当背景板。**

正确做法是把节日转成**正在发生的场景**：一群人围着一口锅、一个时间点才有的东西、一个人因为天冷了才做的动作。节日在画面里是**原因**，不是装饰。

- 用**受场景启发**的配色和道具，不用官方 logo / 官方视觉。
- **不要硬把我们自己塞进每一张图。** 经常最好的一张是「产品不在场」的场景，让这个时节显得急。
- 反向也要守住：灾难 / 事故 / 逝世类事件**不借**（`hot-riding.md`「五、风险」）。

## 五、封面：先出方案表，再生成

封面是这组图里最要紧的一张——**缩略图上大字要认得出**。所以文字必须在生成之前被确认过，不能让图片模型自由发挥。

生成前先给这张表（`image_text` / `image_only` 都走）：

```markdown
| 图 | 角色 | 吸睛机制 | 画面策略 | 图上文字 |
|---|---|---|---|---|
| 1 | 封面 | oversized_headline + macro_texture | 锅底特写 + 巨字标题区 | `主标题`<br>`可选副标题` |
| 2 | 配图 | creator_proof | 手掰菌子，桌面 | （无字） |
```

表后面一句话收尾：**「图上出现的字就这些，改完我再生成。」**

**硬边界：图上文字只有表里这几行。** 生成后如果图上多出任何别的字，这张就不能用——重跑，不要「凑合能看」。

**文字怎么来**：从 `hook-title-formulas.md` 挑一句，压到 12 字以内；封面文案与内容标题**不要求一致，但不要一字不差**——一字不差等于浪费一次曝光位。

**视觉不要靠大 emoji / 手写感**（`xiaohongshu-viral-methodology.md` 已定的硬要求）。张力来自字号层级和留白。

## 六、分镜：先出一张拼图，再花钱

`video_aigc` 的 plan 里 `shots` 写完，**下一步不是调视频生成，是出一张分镜拼图**。视频是最贵的一步，拼图是最便宜的一道确认。

### 网格

| 镜数 | 拼图 |
|---|---|
| 1–4 | 四格 |
| 5–6 | 六格 |
| 7–9 | 九格 |
| > 9 | 拆成多张，每张最多九格 |

一张拼图是**一张输出**：`count = 1`，每一格的描述都写在同一个 prompt 里。从左到右、从上到下，顺序与 `shots` 表一致。**不许为了填满空格多编几镜。**

拼图上**不出现**镜号、表格文字、说明标签——它是用来判断构图和连贯性的，不是文档。

### 主体锚点与环境锚点

跨镜一致性靠两段**固定不变的描述**，不是靠每镜重新描述一遍场景：

```
主体锚点：<谁/什么，外观、衣着、关键道具、风格> —— 每一镜原样复用
环境锚点：<地点类型、布局、背景元素、光线、色板、时间感> —— 每一镜原样复用
```

- **先出核心环境主帧**：一个完整空间（布局 / 关键元素 / 主体落位 / 主要道具 / 光线逻辑），它作为后续每一镜的环境参照。**不要一上来就出孤立特写**——后面几镜会各长各的。
- 后续每一镜只改「这一镜真正不同的部分」，其余照抄锚点。
- 有参考图时，在 prompt 里**逐张写明角色**（`图 1：产品形状与材质参照` / `图 2：人物身份参照` / `图 3：场景氛围参照`）。**不许只在散文里描述参考图而不传进去。**

### 镜头时长

| 项 | 规矩 |
|---|---|
| 单镜默认 | 1–3 秒 |
| 未获明确同意 | 不超过 5 秒 |
| 硬上限 | 15 秒（超过就拆镜，不是「一次生成更长」） |

「口播一句话配一个长镜头」是最常见的失败形状：画面一停，完播率就掉。

### 生成模式

| 模式 | 什么时候 |
|---|---|
| 文生视频 | 只有文字、没有可用画面参照 |
| 参考图引导 | 有产品图 / 人物图 / 场景图，要吸收其外观、风格、构图 |
| 首尾帧 | 两张图有**明确的起点/终点语义**（「从 A 到 B」「开场/收尾」） |

只有风格参照、没有起终点语义的两张图，**不是**首尾帧，仍走参考图引导。

## 七、生成后自检

一次生成完，逐张过一遍再交：

| 检查 | 不过怎么办 |
|---|---|
| 图上只有确认过的字 | 有别的字 → 重跑 |
| 缩略图尺寸下主标题读得出 | 缩不小 → 减少字数 |
| 第一眼有钩子（不是空白/平铺） | 回到机制那一栏换一个 |
| 需要保持身份的主体没变形 | 重跑，锚点写更死 |
| 产品/人物不在场是**故意的** | 不是故意的 → 补 |
| 不像通用素材站的图 | 换风格包 |

给用户一张小表就行：`| 图 | 通过 / 需复核：… | 保留 / 建议重跑 |`。**需要重跑的问一句再跑**，别自己连着刷——每张都是时间和钱。
