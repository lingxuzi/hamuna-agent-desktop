# 平台内容标准路由

> **方法论来源**：Easel `skills/builtin/social-content/references/content-formats.md` 与 `hashtag-strategy.md`，按 sino 的平台 id 重组；平台硬上限以 App 的 `hamuna platforms <id> --json` 为准。
> **改动**：Easel 的通用格式按平台拆成路由表；不搬任何平台默认画幅（sino 的画幅只认 `formAspect`）；不写死字数 / 图片数（这些会变，归 CLI）。
> **同步**：Easel 那边改了这里要跟着改。

---

## 怎么用

1. 从 topic / asset 的 `platform` 拿平台 id。
2. 跑 `hamuna platforms <id> --json`，拿 `mediaKinds` 和 `limits`。**硬上限只认这个命令**；缺字段 = 还没核实，发布前现场看表单计数（「0/30」那种），不要猜。
3. 用本文件对应小节定**创作口径**：标题、正文结构、话题、封面 / 配图、CTA、平台特有禁忌。
4. `form` / `formAspect` 只认人在面板上定的值。**本文件不给任何平台默认画幅。**

## 小红书（xiaohongshu）

- **形态**：图文笔记。封面是第一张，决定点击率。
- **标题**：口语、有具体对象或场景，像一个真人在说话；不要写成公众号标题。
- **正文**：一段 1–3 行，短句 + 少量 emoji；结尾给收藏 / 评论的理由。
- **话题**：5–10 个，放正文末尾；大流量 + 垂直 + 品牌混搭，每条轮换，不要用同一组。
- **封面 / 配图**：封面大字在缩略图上认得出；配图一张讲一件事，和正文段落对得上。
- **CTA**：收藏 / 评论 / 看主页。平台不鼓励站外导流，别把链接当默认动作。
- **禁忌**：硬广口吻、堆砌无关话题、把别人的评论截图当素材。

## 抖音（douyin）

- **形态**：短视频优先；图文也支持。标题就是作品描述的第一行。
- **标题**：一句话说清「这条讲什么 / 为什么值得看」，别铺垫。
- **正文 / 脚本**：前 3 秒给钩子，3–10 秒交代背景，后面每 3–5 秒一个节奏变化，字幕必备。
- **话题**：3–5 个，写在文案里；1–2 个热点 / 挑战话题 + 垂直话题。
- **封面 / 首帧**：首帧就是封面，大字要认得出；视频画幅只认 `formAspect`。
- **CTA**：关注 / 评论区聊聊 / 看到最后。
- **禁忌**：搬运、低质拼接、诱导互动、用与内容无关的热点话题蹭流量。

## 快手（kuaishou）

- **形态**：图文为主。
- **标题**：直白、接地气，像跟老铁聊天；不要端着。
- **正文**：真实场景、具体细节，少用精致形容词。
- **话题**：3–5 个，贴内容和人群，不堆无关大词。
- **封面 / 配图**：真实感优先；产品图能用真的就用真的。
- **CTA**：关注 / 评论。
- **禁忌**：过度包装、假装亲历、夸大效果。

## 视频号（weixin-channels）

- **形态**：当前通道按 image-text 处理；视频通道未核实，不要承诺。
- **标题**：短、正向、说清价值；微信生态里熟人转发是主要扩散路径。
- **正文**：结构清楚、价值观正向；少用强刺激钩子。
- **话题**：少而准，跟内容强相关。
- **封面 / 配图**：干净、可读；不要把字压得太满。
- **CTA**：点赞 / 转发 / 关注。
- **禁忌**：诱导分享、夸大承诺、擦边。

## B站（bilibili）

- **形态**：当前通道按 image-text 处理；视频发布通道未核实，不要承诺。
- **标题**：具体、有信息量；B站用户对标题党敏感。
- **正文**：长图文分章节，每节有小标题；中段埋前向钩子，结尾总结。
- **话题 / 标签**：绑定准确的分区和内容标签；活动标签只在真相关时用。
- **封面 / 配图**：封面信息清楚，不靠夸张表情。
- **CTA**：点赞 / 投币 / 收藏 / 关注。
- **禁忌**：搬运、标题党、把其他平台的口播稿原样搬过来。

## 知乎（zhihu）

- **形态**：只支持 `article`（`text_only`）。
- **标题**：问题式或结论式，具体；不要做「震惊体」。
- **正文**：前 3 行给结论或反常识判断；分点论述 + 数据 / 案例；结尾引导赞同收藏。
- **话题**：绑定精准的垂直话题，避开宽泛大话题。
- **封面 / 配图**：文章配图按 CLI 的 `maxImages`，没有就不配。
- **CTA**：赞同 / 收藏 / 关注。
- **禁忌**：编造数据、软文不标注、把小红书口语稿直接搬来。

## 公众号（wechat-mp）

- **形态**：图文长文。
- **标题**：双标题制造点击，但别骗点击；标题里的关键词决定搜索可见性。
- **正文**：开头 3 段抛出痛点 / 悬念 / 结论；一个核心观点，小标题分段、重点加粗、留白。
- **话题**：没有话题标签机制；靠标题关键词 + 合集沉淀系列。
- **封面 / 配图**：封面在信息流里要认得出；配图服务阅读节奏。
- **CTA**：在看 / 分享 / 关注 / 留言。
- **禁忌**：诱导分享、洗稿、标题与正文不符。

## 跨平台：同一热点，不同平台是不同内容

- **一条 topic 只对应一个 `platform`。** 同一个热点要在多个平台发，按平台各建一条 topic（见 `ops-topic`），每条有自己的角度、形态和上限。
- **不要复制粘贴。** 同一篇稿改平台名不叫跨平台：标题、结构、长度、话题、CTA 都要按目标平台重写。
- **形态不跨平台复用。** 小红书图文不能直接当抖音视频发；`form` 是人在每个 topic 上单独定的。
- **画幅不跨平台推断。** 即使两个平台都发视频，也各自只认自己的 `formAspect`。
- **一次最多 3 条。** 跨平台也一样，提多了等于没提。
