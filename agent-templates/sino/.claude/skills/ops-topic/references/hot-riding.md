## 一、热点现在处在哪个阶段

| 阶段 | 距发生 | 现在该抢什么 |
|---|---|---|
| 爆发期 | 0–4 小时 | 速度优先，抢首发 |
| 高峰期 | 4–24 小时 | 角度优先，做差异化 |
| 衰退期 | 1–3 天 | 深度优先，做总结 / 反思 |
| 长尾期 | 3 天以上 | 复盘优先，提炼方法论 |

接硬门 3（「现在做还来得及」），三个字：**阶段决定角度，也决定还能不能提**。

- **爆发期 + 高峰期（24 小时内）**：正常追。爆发期抢首发，高峰期拼差异化。
- **衰退期（24–72 小时）**：还能提，但**必须换角度** —— 不能再做「发生了什么」，
  要做「这事意味着什么 / 我们怎么看」。硬门 3 的 72 小时还没到，过了就能提。
- **长尾期（>72 小时）**：硬门 3 直接毙。这已经不是热点选题了，当常青题处理 ——
  走七维打分，时效价值那一维给低分。

**爆发期和高峰期都要「现在就做」。** 24 小时后再看到同一个热点，能做的角度已经被别人做完了。

## 二、热度等级

| 等级 | 特征 |
|---|---|
| S | 全网刷屏，多个平台同时上榜 |
| A | 行业热议，单平台头部 |
| B | 圈层讨论，目标受众待的群里在聊 |
| C | 小范围关注 |

台账里没有这个字段 —— **写在 `--note` 里**。S/A/B/C 是判断依据，不是要入库的数据。

## 三、关联度 = 硬门 1 的判据

读 `03-USER.md` 的赛道 + `hamuna ops list direction` 的定位来判：

| 关联度 | 判据 | 例子（露营装备号） |
|---|---|---|
| 高 | 热点本身就在我们这个赛道里 | 「露营装备召回」 |
| 中 | 能从我们的角度解读 | 「多地暴雨预警」→ 雨天露营装备怎么选 |
| 低 | 得强行关联 | 蹭娱乐明星八卦 |
| 无 | 完全不搭边，蹭了减分 | 蹭某个政治人物的口水战 |

- **高 / 中** → 过硬门 1。
- **低 / 无** → **毙**。在 `--note` 里写清为什么不蹭，**并给一个替代方向**。

Easel 规则 1：关联度为「无」时必须明确建议不蹭，不许硬凑方案。硬凑出来的选题会在
七维打分里原形毕露（账号匹配那一维会掉到 1–3 分），只是浪费时间。

## 四、六种切入角度 = 硬门 2 的工具

硬门 2 问的是「同样的题材已经被讲过八百遍，我要说的是哪一句不一样的话」。
这六种就是「哪一句」的来源。

| 角度 | 做什么 | 适合 |
|---|---|---|
| 专业解读 | 从专业视角分析这个热点 | 知识型 |
| 经验关联 | 讲自己跟这个热点有关的亲身经历 | 人设型 |
| 工具 / 方法论 | 借热点引出一个能用的方法 | 干货型 |
| 反向观点 | 说跟主流不一样的看法 | 争议型（风险高） |
| 情绪共鸣 | 说出大家此刻一样的感受 | 情感型 |
| 延伸联想 | 从热点连到一个更大的话题 | 深度型 |

一个热点通常匹配 2–3 个角度，**别一次全用**：

- **角度之间不可重复**（Easel 规则 6）。三个方案讲的是同一件事，等于一个方案。
- **反向观点风险最高** —— 判断错就是跟全网对着干。判断不准就用别的角度。
- 角度要写进 `--angle`，写成「专业解读：这条里没人说清的一点是 XXX」，
  不是只写「专业解读」四个字。四个字是分类，不是角度。

## 五、风险：逐条过

| 风险 | 问自己 | 规避 |
|---|---|---|
| 政治敏感性 | 涉及政策、国际关系、意识形态吗 | 不碰。政治类热点一律不蹭，没有例外 |
| 法律风险 | 事件还没定性吗 | 涉事方未定性前不下结论，只谈已公开的事实 |
| 舆论反转 | 事件可能反转吗 | 有反转可能的，结论留余地；预判式判断不做 |
| 道德争议 | 会被说「吃人血馒头」吗 | 灾难 / 事故 / 逝世类默认不蹭 |
| 平台规则 | 触碰平台红线了吗 | 引战、擦边、导流一律不做 |

**风险不为蹭而淡化**（Easel 规则 3）。有一条过不去，这条就不提。

**sino 额外一条**：只读不互动。蹭热点靠的是选题，不是动作 ——
不去评论区自推、不去相关话题下刷存在感、不跟人对线。

## 六、落到台账

```bash
hamuna ops add topic \
  --title "选题标题（用户能一眼认出的一句话）" \
  --platform douyin \
  --source hotspot \
  --angle "专业解读：这条里没人说清的一点是…" \
  --note "爆发期（2 小时前）/ 热度 A / 关联度高 / 风险：政策相关，已避开 —— 因为…" \
  --ref "https://热榜或原话题链接"
```

`--note` 里必须有四样：**阶段 / 热度等级 / 关联度 / 风险判断**。
下一轮复盘时才知道当时是按什么判断的，也能看出哪个判断维度一直给低了。

**`--hotness` 不填热榜的热度值。** 那是平台的算法分，不是播放量。口径见 `05-OPS.md`。
