## 怎么用这组数

**基准是参照，不是目标。**

- **首次对照找差距**，建立自有历史之后一律以**自身上月**为主基准。
- **基准是参照不是目标** —— 拿它定位差距可以，拿它当 KPI 不行。
- 按垂类调整：美食 / 美妆 / 剧情类互动天然偏高，知识 / B2B 偏低。
- **小体量账号互动率天然更高，勿与大号横比。** 拆一个 10w 粉的对标号时尤其注意 ——
  拿他的互动率去对「全体平均」，天生吃亏。

## 拆对标时哪些数算得出来

基准表里带分母的指标（互动率、收藏率）能不能算，取决于**分母在公开页上拿不拿得到**。

| 平台 | 公开页拿得到播放/曝光吗 | 能不能算互动率 |
|---|---|---|
| 抖音 | 作品列表公开显示播放量 | 能 |
| B站 | 作品列表公开显示播放量 | 能 |
| 快手 | 作品列表公开显示播放量 | 能 |
| 视频号 | 作品列表公开显示播放量 | 能 |
| 小红书 | 曝光量不公开 | **不能** |
| 知乎 | 阅读量不公开 | **不能** |
| 公众号 | 阅读量只在创作者后台 | **不能** |

**分母拿不到就别算。** 那三个平台只能用拿得到的数（赞 / 藏 / 评 / 享）比**结构**
—— 收藏占比高、转发占比高、评论占比高 —— 并且在结论里写清口径。
「他的互动率 3%」这种话在算不出分母的时候是编的。

平台改版频繁，**这一列以现场读到的为准**。拿不准就说拿不准，别照抄这张表。

## 小红书

互动率 =（点赞 + 收藏 + 评论 + 分享）÷ 曝光 × 100；**收藏率是核心质量信号**。

| 评级 | 互动率 | 收藏率 |
|---|---|---|
| 偏低 | < 3% | < 1% |
| 平均 | 3-6% | 1-3% |
| 良好 | 6-10% | 3-6% |
| 优秀 | 10%+ | 6%+ |

月涨粉：平均 2-5%，强 5%+。发布频率：起号 3-5 次/周，成长期可日更。

## 抖音

**完播率是首要指标**（按推荐分发，播放量与粉丝量不成正比，小号也可爆）。

| 指标 | 平均 | 良好 |
|---|---|---|
| 完播率（< 15s） | 30-45% | 45%+ |
| 完播率（15-60s） | 15-25% | 25%+ |
| 互动率（赞+评+转 ÷ 播放） | 3-6% | 6%+ |

## B 站

看重"三连"（点赞 + 投币 + 收藏）与完播、弹幕/评论。

| 指标 | 平均 | 良好 |
|---|---|---|
| 互动率 | 3-8% | 8%+ |
| 三连率 | 2-5% | 5%+ |

## 公众号

无推荐分发，打开率依赖标题 + 存量粉丝 + 转发。

| 指标 | 参考 |
|---|---|
| 打开率 | 普遍 2-5%（粉丝越多通常越低） |
| 在看率（在看 ÷ 阅读） | 1-3% 为良好 |
| 涨粉 | 主要靠爆款单篇拉动，非稳定日增 |

## 本项目没有基准的平台

快手 / 视频号 / 知乎 —— Easel 那份没给这几个平台的基准区间。

**别拿别的平台的数套上来。** 这几个平台的数要么现场读创作者后台（自己的号），
要么就标「没有基准可比」。给一个看着像结论的数，比没有数更坏。
