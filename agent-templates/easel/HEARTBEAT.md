这是自动巡检，没有人坐在旁边。按下面四步走，**能不动手就不动手**。

## 1. 已发内容的数据（每次必做）

读 `memory/` 最近的发布记录，找出**发布 24–72 小时内**的内容。
- 数据明显好于该账号基线 → 记进 `memory/topics/<项目>.md`，标注什么起作用了
- 数据明显差 → 同样记下，写清是选题、钩子还是形式的问题
- 数据没变化 / 还没起量 → 什么都不做，等下一轮

**不要为了"有话说"而硬找结论。** 没有明确信号就不写。

## 2. 热点变化（每次必做）

看当前主流平台热榜，只关心一件事：**有没有和当前账号赛道相关、且还没做过的新热点。**

- 有 → 在 `outputs/` 下建一个简要选题记录（标题 + 为什么适合 + 建议形式）
- 没有 → 不做任何事
- 最多记 3 条，不要刷屏

**不做**：不写文案、不做图、不生成内容。发现层只到"记一个选题"为止。

## 3. 到期排期（每次必做）

检查是否有今天该发但还没发的内容（看 `outputs/` 里的排期记录）。
- 有 → 提醒用户"X 内容今天该发了"，附上路径
- 没有 → 不做任何事

**不要自动发布。** 见下面的红线。

## 4. 有东西要说才说

- **什么都不用做** → 只回 `HEARTBEAT_OK`，一个字都不要多
- **有东西要说** → 挑最重要的**一件**说，控制在 3 行内，不要罗列所有发现

一次心跳最多说一件事。用户不是来读日报的。

---

## 红线（override 一切）

1. **不发布、不登录、不改账号设置。** 心跳期间权限是全开的，靠你自己守。任何对外动作一律留到用户在场时做。
2. **不花钱。** 不调付费生成（图/视频/音乐/TTS），不跑批量任务。
3. **不改画像。** `.claude/rules/` 只在用户明确要求时改。
4. **不重复。** 上一轮已经说过的事，没有新进展就不要再说。翻 `memory/` 最近的日志确认。
5. **拿不准就沉默。** 回 `HEARTBEAT_OK` 是正确行为，不是失败。
