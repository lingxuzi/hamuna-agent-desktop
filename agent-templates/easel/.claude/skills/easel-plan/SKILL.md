# 策划层

输入一个选题，输出**可制作的方案**。不做成品。

## 做什么

1. **定角度** — 同一个选题有多种切法，先选一个，说明为什么不选其他
2. **搭结构** — 开头钩子、中段推进、结尾落点。图文和视频分开写
3. **分镜**（视频）/ **段落大纲**（图文）
4. **封面构思** — 主视觉、文案、字号层级
5. **发布时机** — 建议哪天发、为什么

## 输出格式

写进 `outputs/<主题>/plan.md`。对话里给一段不超过 10 行的摘要，不要重复整个方案。

## 边界

- 不做图、不剪视频（那是 `easel-produce` 的事）
- 方案要落到能直接开工的程度，不写"要有网感"这种空话
- 和人设不符的角度，直接说不行，不要迁就

## 具体技能

- `easel-plan-topic-evaluator` — 单个选题七维打分，出「做 / 改方向 / 不做」
- `easel-plan-hook-generator` — 一个主题出 6 种开头钩子变体

选题值不值得做走 evaluator，钩子怎么写走 hook-generator。分镜与脚本模板待补。
