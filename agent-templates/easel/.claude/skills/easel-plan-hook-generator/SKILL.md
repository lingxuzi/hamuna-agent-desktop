# 钩子变体生成

同一个主题，6 个方向的开场。用户挑一条，再扩写成整篇。

## 输入

主题文本（关键词、短语或一句话）。**有主题就开工，不要追问细节。**

## 6 种公式

每条两行：第 1 行开场（陈述句，出人意料/具体/有冲击力），第 2 行反转（与开场矛盾/重构/颠覆）。

| # | 公式 | 内核 |
|---|------|------|
| 1 | 数字领衔 | 用一个具体数字开场，后续揭示数字背后的反差 |
| 2 | 逆向认知 | 陈述一个与常识相反的说法，再给出为什么 |
| 3 | 个人蜕变 | 我的状态变化 + 变化的原因 |
| 4 | 权威借势 | 引用一个可信来源/身份，再转折出不同结论 |
| 5 | 自我坦白 | 承认一个不体面的事实，再翻出收获 |
| 6 | 未来冲击 | 描述一个即将发生的场景，再点出当下的缺口 |

具体措辞参考 `.claude/references/hook-title-formulas.md` 的注意力钩子表，但**输出结构固定是上面 6 种**。

## 硬约束（逐条查，不靠肉眼）

1. **每行 ≤ 40 字** —— 必须实测。逐行跑：

   ```bash
   echo "这一行文字" | node scripts/wordcount.mjs count --json
   ```

   读 `social_count`（中文 1 字 + 英文 1 词 + 数字 1 串 + 标点各 1）。超 40 就压缩该行重测，**直到实测 ≤ 40**。

2. 开场行**不含问号**
3. 不用破折号（—）
4. 不用填充词：其实、就是、所以、然后
5. 数字一律阿拉伯数字
6. 不含犹豫措辞：可能、也许、大概
7. 优先第一人称；公式 4 / 6 可以不含「我」

## 输出

```
### 1. 数字领衔
> 开场行
> 反转行

### 2. 逆向认知
...
```

末尾加一句：`选一条，我扩写成完整内容。回复编号。`

## 画像感知

有画像时读 `style` 与 `preferences` 调整语气和用词（小红书偏口语、抖音偏节奏、知乎偏结论前置）；红线词一律不用。无画像用中性语气，末尾附一句「有画像我能更贴你的风格」。
