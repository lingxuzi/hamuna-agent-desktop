# 营销文案

目标只有一个：**促成动作**。不为好看，为转化。

## 先分清这活该谁干

| 场景 | 谁干 |
|---|---|
| 卖货/转化导向（种草卖点、信息流广告、活动、详情页、落地页） | **本技能** |
| 通用社媒内容、涨粉互动、多平台一次成稿 | `easel-produce-social-content` |
| 只是打磨已有文字 | `easel-produce-text-polisher` |

要卖货就在这；要涨粉去 social-content。可以串：本技能出卖点文案 → 交给 social-content 适配平台。

## 输入

缺失时**先问**（这里值得打断对话，硬猜等于白写）：

1. **文案类型** — 种草 / 信息流广告 / 卖点提炼 / 活动促销 / 详情页 / 落地页
2. **产品与服务** — 卖什么、核心卖点、和竞品的差异、能带来什么结果
3. **目标动作** — 下单 / 领券 / 加购 / 点击 / 私信 / 到店
4. **投放位置** — 决定长度、语气、CTA 形式
5. **证据素材** — 销量、评价、成分参数、案例、资质
6. **受众** — 谁看、他们的消费顾虑

## 怎么写

1. **定语气** — 种草偏亲切真实，信息流偏直给，活动偏紧迫，详情页偏专业。有画像就读 `style` 与 `preferences`
2. **提炼卖点（FAB）** — 特性 → 优势 → 利益，逐条翻译并排主次。写法：`因为{特性}，所以{优势}，这意味着你能{利益}`
3. **选框架搭结构** — 从 `.claude/references/copy-frameworks.md` 选**一个**（AIDA / PAS / FAB / BAB / STAR）
4. **写标题钩子** — 从 `.claude/references/hook-title-formulas.md` 选，出 2–3 个备选
5. **填正文** — 一段一论点，沿「心动 → 信任 → 行动」推进
6. **写 CTA** — 2–3 个备选，每个都要给「为什么现在」

## 核心原则

- **清晰优先** — 清晰和创意冲突时选清晰。3 秒内让人知道在卖什么
- **讲利益不讲功能** — 特性说「它是什么」，利益说「这对你意味着什么」
- **要具体** — 「早八通勤 10 分钟出门不迟到」优于「省时高效」
- **用用户的话** — 镜像评论区、咨询里的真实说法，不用品牌自嗨词
- **信任前置** — 国内消费决策重口碑，销量/评价/资质早出现
- **CTA 给理由** — 不只说「点击购买」，配上限时、限量、赠品、价格锚点

## 字数校验（有长度限制的类型必做）

不靠肉眼数，跑脚本：

```bash
node scripts/wordcount.mjs count -f outputs/<主题>/copy.txt
```

读 `social_count` 与投放位的上限比对，超了压缩后重跑。

## 去 AI 味（强制门）

交付前过 `.claude/references/zh-ai-markers.md` 的五维评分，**≥45/50**。不过就改到过，别带着 AI 味交付。

## 输出

- 主标题/开头钩子 + 2–3 个备选
- 正文（标明用的框架）
- 卖点清单（FAB 逐条）
- CTA + 2–3 个备选
- 关键选择说明：为什么用这个框架、这个角度

写进 `outputs/<主题>/`，文件按类型命名（`copy.md` / `detail-page.md`）。

## 无画像时

主动问语气偏好和受众；没答就退回通用专业语气，末尾补一句「有画像能更贴你的品牌」。
