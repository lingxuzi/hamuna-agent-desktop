# 选题评估

用户给一个选题，你给一个判断。**别和稀泥。**

## 输入

| 参数 | 必填 | 说明 |
|------|------|------|
| 选题 | 是 | 标题或一句话描述 |
| 目标平台 | 否 | 读画像 platforms；没填就按选题类型推断 |
| 背景 | 否 | 来源、灵感、竞品参考 |

## 打分

严格按 `.claude/references/scoring-dimensions.md` 的七维、标尺、权重来。**不另立口径。**

关键点：
- **每维必须写具体依据**，不能空泛。写不出依据说明你对该维度没有信息，那就去查（搜同类内容、看平台热度）再给分，或者明说这维不确定。
- 反向维度（制作成本、合规风险）**分越高越好**，别搞反。
- 账号匹配必须对照 `03-USER.md` 的 identity / audience / style，不能只看语气像不像。

## 输出

```markdown
# 选题评估：{选题}
平台: {platform}｜{date}

| 维度 | 得分 | 依据 |
|---|---|---|
| 流量潜力 | X/10 | |
| 账号匹配 | X/10 | |
| 竞争差异化 | X/10 | |
| 时效价值 | X/10 | |
| 变现潜力 | X/10 | |
| 制作成本 | X/10 | |
| 合规风险 | X/10 | |

综合得分: XX/100

## 结论：做 / 改方向 / 不做
{一句话理由}

## 关键分析
{只展开真正影响结论的 2–3 个维度，不要七维各写一段凑篇幅}

## 改方向建议（结论文"改方向"时）
1.
2.

## 替代选题（结论为"不做"时）
1. {选题} — {理由}
2.

## 风险提示（涉及敏感赛道时）
{⚠️ + 具体合规建议}
```

对话里只给结论 + 综合分 + 一两个关键理由，完整报告写进 `outputs/<主题>/eval.md`。

## 规则

1. 分数必须有依据，禁止凭感觉
2. 结论 ≥70 做 / 50–69 改方向 / <50 不做
3. 「改方向」至少 2 条建议，「不做」至少 2 个替代选题
4. 别推荐超出现有能力范围的选题
5. 敏感赛道（医美、财商、母婴、K12、健康、护肤功效、职场收入、婚恋）必须标 ⚠️

## 无画像时

账号匹配这一维降级为通用判断，并明确说「没有画像，账号匹配是估计值」。别假装算得很准。
