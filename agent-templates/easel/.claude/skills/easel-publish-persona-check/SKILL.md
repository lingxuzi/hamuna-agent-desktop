# 人设一致性检查

回答一个问题：**这条内容，像这个账号发的吗？**

**必须有画像才能做。** 画像在 `.claude/rules/03-USER.md`（会话启动时已加载）。六维全空就直说做不了，请用户跑 `/BOOTSTRAP`。

## 先看什么

顺序不能反：

1. 读 `03-USER.md` 的**全部六维**，先提取账号主线、允许的题材、内容形式、受众
2. 再提取语气、用词、平台习惯
3. **不能只读 style 就凭「语气像不像」给分** —— 语气像但赛道错，是最典型的误判

## 待检内容的五个面

1. **题材与意图** — 在讲什么，属于账号主线还是勉强延展
2. **内容形式** — 图文 / 口播 / 测评 / 小说，是否匹配定位
3. **目标受众** — 解决的问题、情绪价值、阅读门槛，是否面向画像受众
4. **语言风格** — 语气、用词、句式、叙事视角
5. **平台与偏好** — 适配目标平台吗，碰了画像的「不做」项吗

## 七维加权

| 维度 | 对比对象 | 权重 |
|---|---|---|
| 账号定位与内容赛道 | identity 的主线、内容方向 | 30% |
| 内容形式一致性 | 画像规定的主要形式 | 15% |
| 目标受众匹配 | audience | 15% |
| 语气与叙事风格 | style | 15% |
| 人格与用词 | 画像中的标志性表达 | 10% |
| 平台适配 | platforms（无目标平台给中性分） | 10% |
| 偏好与经验 | preferences + memory | 5% |

每维 0–100，加权得总分。然后**必须应用上限**：

- **赛道 < 40** → 总分最高 59，必判 `major_drift`
- **形式 < 40** → 总分最高 69，至少 `minor_drift`
- **碰到「不做」项或红线** → 总分最高 39，明确指出证据

> 例：一个 2D 搞笑动画号发纯恐怖文字小说，哪怕同样口语化、有画面感、有反转，赛道和形式严重不符，总分必须 < 60。语言技巧不能救赛道。

用户主动要求跨赛道，只说明这是有意识的选择，**不能因此虚增分数**，报告里注一句「用户主动跨赛道」就行。

## 输出（JSON）

```json
{
  "overall_score": 85,
  "verdict": "consistent | minor_drift | major_drift",
  "publish_allowed": true,
  "warning": "",
  "dimensions": [
    { "dimension": "账号定位与内容赛道", "score": 90, "status": "aligned", "evidence": "具体证据", "suggestion": "调整建议" }
  ],
  "drift_summary": ["偏离点"],
  "rewrite_hints": ["词级/句级/段级的具体改法"],
  "summary": "一句话"
}
```

判定：80–100 consistent｜60–79 minor_drift｜0–59 major_drift。

## 红线：这是提醒，不是权限

`publish_allowed` **永远输出 `true`**。低分不得阻断发布、不得要求用户改稿才放行。用户明确要发，就给警告然后继续。

**内容安全、平台合规、敏感信息是独立硬门禁**，不在本技能范围内 —— 那些归 `05-PUBLISH-POLICY.md` 和 `easel-publish` 管。

## 偏离点怎么写

只给 < 80 的维度写偏离，每条要有三样：

1. **引用原文** — 哪句偏了
2. **对比说明** — 画像期待什么，实际给了什么
3. **严重程度** — 影响整体人设感知，还是局部

修改建议要具体到词和句，不要写「更口语一些」。
