# 发布层

**这是唯一有不可逆动作的层。** 完整红线在 `.claude/rules/05-PUBLISH-POLICY.md`，先读它。

## 流程

```
1. 平台适配   → 按各平台限制改写（标题长度、正文长度、媒体要求）
2. 硬拦扫描   → 内部信息泄露逐项查（Key / 内网 URL / 绝对路径 / 隐私）
3. 人设评分   → 80 分及以上 pass，低于 80 给 warn 和修改建议，不阻断
4. 确认发布   → 人工模式：导出包；自动模式：拿当次确认后真发
```

## 平台约束

| 平台 | 标题 | 正文 | 媒体 |
|---|---|---|---|
| 小红书 | ≤20 | ≤1000 | 必需图片/视频 |
| 抖音 | ≤55 | ≤55 | **仅视频** |
| 视频号 | — | — | **仅视频** |
| B 站 | ≤80 | ≤2000 | **仅视频** |
| 快手 | — | — | 必需 |
| 公众号 | — | — | 必需 |

**发之前就判完，不要发到一半失败。** 未登录就去登录，缺媒体就去内容库选，不丢错误了事。

## 两种模式

- **manual（默认）** — 只能产出内容 + 导出发布包。调平台发布工具会被 hook 直接拒绝。
- **automated** — 可以真发，但每次都要当次确认，不是"之前说过可以"。

不确定当前模式，按 manual 处理。

## 留痕

成功发布后记：平台、标题、画像、时间、人设评分。写进 `memory/YYYY-MM-DD.md`。

## 具体技能

- `easel-publish-persona-check` — 七维人设评分。80+ pass，低于 80 给 warn + 修改建议，**永不阻断**
- `easel-publish-checklist` — 查漏（标题/正文/封面/标签/格式/链接），有 fail 就 not_ready

顺序：checklist 查漏 → persona-check 打分 → 硬拦扫描（本文件）→ 确认或导出。

## 共用参考

`.claude/references/platform-specs.md` — 各平台字数、画幅、媒体要求。发布前就判完，不要发到一半失败。
