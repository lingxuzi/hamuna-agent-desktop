# 发现层

产出**选题清单**，不产出内容。

## 做什么

1. **拉热榜** — 微博 / 抖音 / 知乎 / B 站 / 百度 / 头条
2. **筛赛道** — 按 `03-USER.md` 的 identity 和 audience 过滤，只留账号能做的
3. **拆爆款** — 命中的爆款拆结构：钩子、节奏、情绪点、可复用元素
4. **出清单** — 每条给：选题、为什么适合这个账号、预估难度、建议形式

## 输出格式

写进 `outputs/<主题>/ideas.md`，并在对话里给一张表（不超过 10 条，按契合度排序）。

## 边界

- 不做策划细节（那是 `easel-plan` 的事）
- 不生成内容
- 热搜里有平台违规风险的（擦边、谣言），标出来不推荐

## 心跳里的轻量版

心跳巡检会调用这一层的**精简形态**：

- 只查「有没有和账号赛道相关、且还没做过的新热点」
- 有就记一条选题（标题 + 为什么适合 + 建议形式），**最多 3 条**
- 没有就什么都不做

**不**拉完整热榜、**不**拆爆款、**不**生成选题清单表格。心跳是发现信号的，不是出方案的。

## 具体技能

- `easel-discover-trending-topics` — 抓热榜、筛赛道、出二创选题

热榜数据源、降级顺序、反爬禁忌都在那个技能里。要抓数据就走它，不要自己临场发挥去开平台官网。
