# HEARTBEAT.md — 巡检配置

*心跳由应用侧驱动，不是对话里能开的开关。这个文件只是帮你改清单内容。*

## 心跳怎么才真的会跑

三个条件全部满足才会：

1. 这个工作区的 Agent 是启用状态（Agent 设置 → 通用 → 主动模式）
2. 配了至少一个 IM channel（飞书 / Telegram / 钉钉），且该 channel 已启动
3. 用户在 IM 里私聊过 bot 至少一次（需要一条私聊 target 才能投递）

**没配 IM channel = 心跳循环不会启动**，配了 `heartbeat` 配置也不会跑。这不是 bug，是当前实现的前提（`src-tauri/src/im/config_store.rs:2738`）。

## 改什么

编辑工作区根目录的 `HEARTBEAT.md` 正文（`---` 之间的 frontmatter 不用管）。

- **临时停某类巡检** → 删掉对应小节
- **全部停掉** → 清空正文。正文为空时心跳直接跳过 AI 调用，不烧 token
- **加新巡检项** → 加一个小节，写清「查什么 / 满足什么条件才动手 / 上限几条」

## 写清单的三条原则

1. **先写「不做」** — 每个小节都明确写清楚什么情况下不动作。心跳最容易出的问题是"硬找结论"。
2. **给上限** — 「最多 3 条」「最多说一件事」。没有上限的清单会变成刷屏。
3. **可判定** — 「数据好于基线」比「关注数据表现」好，因为前者能判真假。

## 间隔怎么定

在 Agent 设置里改，区间 5 分钟到任意小时。默认 120 分钟，`activeHours` 08:00–23:00。

- 追热点期 → 60–90 分钟
- 稳态运营 → 120–240 分钟
- 只做周更 → 建议直接关掉心跳，改用 TaskStore 排期

**间隔越短越贵**，每次都会跑一轮完整 turn。

## 红线提醒

心跳期间 `permissionMode` 是 `fullAgency`（`src/server/index.ts:9657`，因为无人值守不能卡权限）。所以**自主约束只能写在 `HEARTBEAT.md` 和 `.claude/rules/05-PUBLISH-POLICY.md` 里** —— 这两份文件是心跳场景下唯一的行为边界。
