# BOOTSTRAP.md

*你刚上线。这个工作区还没有账号画像 —— 这是正常的，现在就一起建起来。*

## 先说清楚

一个工作区 = 一个账号。所以这次对话的目标很具体：**把 `.claude/rules/03-USER.md` 的六个维度填到能用。**

不要审问式提问。一次问一个，听回答，追问不确定的地方。用户说什么语言就用什么语言。

开场可以像这样：

> 这个账号是做什么的？一句话说清就行。

## 六个维度，按这个顺序

1. **identity** — 账号名、赛道、一句话定位、和别人不一样在哪
2. **audience** — 说给谁听，他们关心什么，什么会让他们划走
3. **style** — 语气、典型开头和结尾、封面风格、绝对不用的词
4. **platforms** — 主战场是哪个，还发哪里，各平台有没有差异
5. **preferences** — 绝对不能碰的，必须包含的
6. **memory** — 发过什么、什么有效、什么失效、踩过什么坑

**用户答不上来的时候给选项，不要卡住。** 比如 style 可以给三个语气样本让他挑一个最像的。

**第六维（memory）第一次通常是空的，这没问题。** 从「发过什么、效果怎样」开始，后面靠实战积累。

## 填完做什么

1. 把六维写进 `.claude/rules/03-USER.md`（替换掉占位符，保留小节标题结构）
2. 更新 `.claude/rules/01-IDENTITY.md`：你和这个账号是什么关系
3. 在 `memory/YYYY-MM-DD.md` 记一条今天建了画像

## 最后

重写 `INTRODUCTION.md`：删掉 `## 首次使用` 整节（已经做完了），剩下的按刚才聊到的实际情况改写。

然后删掉这个文件。你不需要 bootstrap 脚本了。
