# 中文去 AI 味规则

*所有文案产出后必过这道门。AI 味的典型症状是「每个字都对，读起来没人味」。*

## 五条原则

1. **删填充，留事实** — 开场白、强调拐杖词、铺垫句全删
2. **打破公式结构** — 「总分总」、二元对比、三段式列举，打散重组
3. **变化节奏** — 短句后跟长句；两项优于三项；段落结尾别一个样
4. **信任读者** — 直接陈述，不软化、不辩解、不手把手
5. **删金句** — 听起来能被引用的句子，基本是 AI 写的

## 禁用词（见一个改一个）

| 禁用 | 改成 |
|---|---|
| 说白了 | 坦率的讲 / 其实就是 |
| 值得注意的是 / 值得一提的是 | 直接说，或删 |
| 不难发现 / 众所周知 | 删，直接陈述 |
| 综上所述 / 总的来说 | 具体回扣句，或删 |
| 首先…其次…再次…最后 | 口语转场（「说到这」「回到刚才那个」） |
| 不仅…更… / 不仅…而且… | 直接说结论 |
| 通过…来… | 直接动作句 |
| 此外 / 与此同时 | 删，或「还有一个」 |
| 这意味着 | 「所以呢」「换句话说」 |
| 本质上 / 某种程度上 | 「说到底」/ 说清楚具体到什么程度 |
| 不可否认 / 毋庸置疑 / 可以说 | 直接正面陈述 |

**翻译腔高频词**：持久的、格局、关键性的、展示、织锦、彰显、赋能、增强、培养、至关重要、深入探讨、宝贵的、充满活力、一站式、匠心 —— 见到即删或改成具体做了什么。

## 禁用标点

- 破折号 `——` → 逗号或句号
- 内联「标题：内容」式列表 → 逗号或疑问句
- 装饰性双引号 → 用「」或干脆不加

## 结构病

1. **长句堆砌** — 一句超 30 字、塞多个「通过/对/进行/实现」。拆成 20 字内短句
2. **段落过渡词堆叠** — 每段开头「首先/其次/最后」。删序号词，用时序叙述
3. **过度强调意义** — 「标志着/见证了/奠定坚实基础」→ 说具体改变了什么
4. **模糊归因** — 「专家认为/研究表明」→ 给具体来源，没来源就删整句
5. **-ing 式升华** — 「象征着/彰显了/体现了」→ 换具体事实
6. **宣传性语言** — 「令人叹为观止/开创性/卓越」→ 换它具体做了什么
7. **否定式排比** — 「这不仅仅是…而是…」→ 直接说结论
8. **三段式法则** — 强凑三组 → 改两项或四项
9. **虚假范围** — 「从 X 到 Y」空泛两端 → 直接陈述

## 交流模式病

- **AI 助手口吻**：「希望对你有帮助」「当然！」「请告诉我」「您说得完全正确」→ 删
- **谄媚开头**：「好问题！」→ 删，直接进内容
- **过度限定**：「可以潜在地可能产生一些影响」→「会影响结果」
- **通用积极结尾**：「未来充满无限可能」→ 删，或换成具体行动

## 注入活人感

去掉坏东西只是一半，还得加真东西：

- **情绪体感化** — 「我感到非常震撼」→「我当时就愣住了」（写身体反应，不写情绪总结）
- **第一手细节** — 「精度显著提升」→「跑到第三次，精度从 80 飙到 92，我拍了桌子」。AI 编不出这种动作细节
- **句式断裂** — 情绪高点用极短句独立成段。不能每段都用
- **承认对立面** — 讲观点前先把读者处境讲透，防御心就低了
- **口语转场**：坦率的讲、说真的、怎么说呢、你想想看
- **承认不确定**：说实话我也不确定、我自己也还在摸索

## 平台特化：小红书

在通用规则之上要「素人感」：

- **闺蜜语气** — 像私聊不像广告。姐妹们、真的会谢、我先冲了、亲测
- **素人感** — 不追求完美排版和金句，允许口语碎句、语气词、不对称结构
- **emoji 是节拍不是装饰** — 每行 0–2 个，卡在情绪点或分项处
- **痛点前置** — 开头直接戳痛点或给结果，不铺垫

## 评分（总分 50，≥45 才可发布）

| 维度 | 标准 |
|---|---|
| 直接性 | 直截了当 vs 满篇铺垫 |
| 节奏 | 长短交错 vs 机械重复 |
| 信任度 | 尊重读者 vs 过度解释 |
| 活人感 | 有体感细节 vs 机械生硬 |
| 精炼度 | 无冗余 vs 大量废话 |

35–44 良好但可再打磨；<35 明显 AI 味，重写。

## 快速自查

- 有没有「说白了 / 值得注意的是 / 综上所述」
- 有没有「首先 / 其次 / 最后」序号词
- 有没有「不仅…更…」
- 有没有破折号
- 连续三句长度一样？打断一句
- 三段式列举？改两项或四项
- 情绪是体感记忆还是知识性描述
