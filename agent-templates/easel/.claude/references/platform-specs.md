# 平台规范

*各平台的硬约束。写之前看，别写完再改。*

> 平台规则会变。这里是当前口径，遇到实际报错以平台为准，并把新规则补进本文件。

## 小红书

| 元素 | 规格 |
|------|------|
| 标题 | ≤ 20 字（`social_count`） |
| 正文 | 300–800 字，短段落 |
| 图片 | 1080×1440（3:4 竖版），1–9 张，首图即封面 |
| 标签 | 5–10 个，放正文末尾 |
| 时间 | 11–13 点、19–22 点 |

封面 + 标题决定 90% 点击，正文决定收藏。口语化、素人感，忌硬广、忌 AI 味。避绝对化用语、医疗功效、引流外链。

## 抖音

| 元素 | 规格 |
|------|------|
| 标题/文案 | ≤ 55 字 |
| 媒体 | **仅视频**，1080×1920（9:16），15–60s |
| 标签 | 3–5 个，含 1–2 个热点话题 |
| 时间 | 12–13 点、18–22 点 |

前 3 秒定生死。完播率是核心指标，每 3–5 秒要有变化。大字幕必备（大量静音观看）。

## 视频号

**仅视频**。社交推荐为主，视频号内容能在朋友圈/群里直接传播，所以开头要能对「朋友的转发」产生好奇。

## B站

| 元素 | 规格 |
|------|------|
| 标题 | ≤ 80 字（建议 40 字内更易读） |
| 正文（简介） | ≤ 2000 字，前 2 行最关键 |
| 媒体 | **仅视频**，1920×1080（16:9）为主，3–10 分钟留存最佳 |
| 标签 | 4–10 个 |
| 时间 | 工作日 19–23 点、周末全天 |

受众懂梗、反感硬广。开头 15 秒交代「讲什么、为什么值得看」。标题党适度，标题与内容不符会被差评反噬。

## 微博

| 元素 | 规格 |
|------|------|
| 正文 | 140 字最佳，≤ 2000 字 |
| 话题 | 1–3 个 `#话题#`（双井号） |
| 媒体 | 可选，单图或九宫格 |
| 时间 | 8–9 点、12 点、20–22 点 |

短平快，情绪化/观点化内容易转发。

## 公众号

| 元素 | 规格 |
|------|------|
| 标题 | 主标题 ≤ 64 字 |
| 正文 | 1000–3000 字 |
| 媒体 | **必需**，首图 900×383（2.35:1） |
| 时间 | 早 7–9 点、晚 20–22 点 |

打开率靠标题，完读率靠开头 3 段和排版。外链受限。

## 知乎

| 元素 | 规格 |
|------|------|
| 正文 | 800–3000 字 |
| 开头 | 前 3 行给结论或反常识钩子 |
| 结构 | 分点论述 + 案例 + 数据 |

专业、理性、有干货。结尾引导「赞同 + 收藏」（赞同提升排序权重）。

## 快手

**媒体必需**（图或视频）。老铁文化，接地气，少用书面语。

## 出海兜底

### X / Twitter
单条 280 字符（Premium 已放宽）。标签 1–2 个。链接降 reach，放第一条回复。首行钩子决定一切。

### LinkedIn
帖子 3000 字符，约 210 字符后折叠。标签 3–5 个放末尾。前 2–3 行必须在折叠前抓住注意力；个人故事 > 企业公告；外链放评论。
