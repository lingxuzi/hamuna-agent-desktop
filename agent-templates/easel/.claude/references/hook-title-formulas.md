# 钩子与标题公式库

*所有文案类技能的唯一公式源。别各写一份 —— 副本一漂移，同一个账号的标题风格就裂开了。*

首行 / 首图 / 前 3 秒决定 90% 的表现。**每次只用一个公式。**

## 注意力钩子（首行 / 封面）

| 公式 | 示例 |
|------|------|
| 反常识 | 我停更了一个月，粉丝反而涨了 2 万。 |
| 具体结果 | 0 基础 3 个月，我把账号做到 5 万粉。 |
| 利益前置 | 这个方法，帮我把收藏翻了 3 倍。 |
| 提问共鸣 | 你是不是也一到写文案就卡壳？ |
| 「这一个 X」 | 改了这一处，我的完播率直接拉满。 |
| 「别再 X」 | 别再无脑发笔记了，先看完这条。 |
| 身份代入 | 普通人想做副业，先看这 3 个坑。 |
| 惊人数据 | 73% 的笔记死在了封面，不是内容。 |
| 清单开头 | 私藏的 5 个免费工具，一个都不能少。 |
| 坦白/踩坑 | 交了 2 万学费才明白的一件事。 |
| 发现式 | 我发现了个宝藏。 |
| 惊叹式 | 我不是最后一个知道的吧。 |

## 标题公式（`{}` 是占位，不要写死行业案例）

**利益型**
- `{达成理想结果}，不用{付出的代价}`
- `{时间/场景}就能{结果}`
- `把{输入}变成{理想结果}`

**痛点型**
- `还在{糟糕做法}吗？`
- `别再{无效行为}了`
- `{人群}最容易踩的{数字}个坑`

**人群型**
- `{人群}闭眼入的{品类}`
- `{身份标签}必备：{核心功能}`
- `谁懂啊，{人群}的{需求}终于有救了`

**反差/悬念型**
- `我一开始也不信，直到{反差结果}`
- `{低成本}也能{高价值结果}`
- `原来{反常识观点}`

**数字/证据型**
- `{数字}{人群}都在用的{品类}`
- `{数字}天，{可量化结果}`
- `亲测{时长}，{具体变化}`

**清单/干货型**
- `{数字}个{主题}，建议收藏`
- `关于{主题}，我踩过的坑都在这`

**提问/发现型**
- `有没有那种{功能}的{产品类型}？`
- `{热点词}爆火后，我用它做了{场景}`

## 互动引导（驱动评论 / 收藏 / 转发）

| 类型 | 示例 |
|------|------|
| 提问 | 你在【主题】上最大的困扰是什么？ |
| 二选一 | 你是 A 派还是 B 派？评论区告诉我 |
| 填空 | 我用过最好用的工具是 ___ |
| 观点邀请 | 一个可能得罪人的观点：___，你同意吗？ |
| 收藏引导 | 先码住，需要的时候不迷路。 |
| 转发引导 | 转发给会用到的人 |
| 三连引导 | 觉得有用一键三连，下期讲更硬的。 |

## 短视频钩子（抖音 / B站 / 视频号）

| 类型 | 脚本开头 |
|------|---------|
| 挑战 | 赌你说不出 3 个真正有用的运营指标。 |
| 故事 | 上个月一个粉丝找到我，账号 0 播放…… |
| 教程 | 手把手教你 15 分钟写出一篇爆款文案。 |
| 反应 | 刷到一条违反所有规则的笔记，结果爆了。 |
| 清单 | 3 个免费工具，替掉我每月 500 块的软件。 |
| 破除迷思 | 都说要 1 万粉才能变现，这是骗你的。 |

## 用的时候守这几条

1. **匹配平台** — 小红书重利益点/共鸣，语气软；知乎重反常识/结论前置；抖音重悬念/挑战；微博重情绪/观点；公众号重痛点/悬念。
2. **匹配画像** — 专业号别过度挑衅，个人号可以更大胆。画像 `style` 与 `preferences` 优先。
3. **具体优于空泛** — 「3 个月涨 5 万粉」优于「涨粉很快」。
4. **每次只用一个公式** — 混两个等于没有钩子。
