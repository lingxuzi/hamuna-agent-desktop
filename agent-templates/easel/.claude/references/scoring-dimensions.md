# 评分维度（统一口径）

*给选题打分时只认这一套。维度和标尺不动，权重可以按当前目标微调。*

七个维度各打 1–10 分。**制作成本**和**合规风险**是反向维度 —— 分越高代表成本越低、风险越低，这样七维可以同向相加，分越高越值得做。

| # | 维度 | 含义 | 方向 |
|---|------|------|------|
| 1 | 流量潜力 | 受众痛感强度 + 平台话题热度 + 搜索需求 | 正向 |
| 2 | 账号匹配 | 与定位、受众、已有内容体系的契合度 | 正向 |
| 3 | 竞争差异化 | 同类饱和度 + 能否切出差异化角度（高分 = 竞争低） | 正向 |
| 4 | 时效价值 | 常青长尾 vs 一次性热点（高分 = 常青） | 正向 |
| 5 | 变现潜力 | 能否自然接广告 / 带货 / 引流 / 知识付费 | 正向 |
| 6 | 制作成本 | 素材、设备、技能门槛（**反向**：高分 = 低成本） | 反向 |
| 7 | 合规风险 | 平台规则与法律合规敏感度（**反向**：高分 = 低风险） | 反向 |

## 标尺

| 维度 | 1–3 分 | 4–6 分 | 7–8 分 | 9–10 分 |
|------|--------|--------|--------|---------|
| 流量潜力 | 小众冷门，痛感弱，月搜索 <1000 | 有一定热度，同类内容有稳定流量 | 热门话题，搜索量高或踩中时效热点 | 全民级热点，或精准戳中大体量人群刚需 |
| 账号匹配 | 完全偏离账号定位 | 有关联但需跨领域延伸 | 与核心定位相关，有内容承接 | 正中账号最强领域，强化人设 |
| 竞争差异化 | 同类 >100 条，高度饱和，无新角度 | 有竞争但角度可差异化 | 竞争适中，有明显空白角度 | 蓝海领域，几乎无同类优质内容 |
| 时效价值 | 已过时或即将过时 | 时效一般，1 周内有效 | 常青 + 时效双重价值 | 常青话题，长期有搜索价值 |
| 变现潜力 | 纯娱乐，无商业价值 | 可做品牌背书但难直接变现 | 可自然接商单或带货 | 高客单 / 高转化品类，变现路径顺 |
| 制作成本（反向） | 需专业设备 / 外景 / 多人协作 | 需准备素材但个人可完成 | 只需文字或简单拍摄 | 纯文字 / 口播 / 已有素材可直接用 |
| 合规风险（反向） | 高危赛道，易违规限流 | 有敏感点，需谨慎措辞 | 轻微风险，规避即可 | 无合规风险 |

## 加权与结论

综合分 = Σ(维度得分 ÷ 10 × 权重 × 100)，满分 100。默认权重：

| 维度 | 权重 |
|------|------|
| 流量潜力 | 25% |
| 账号匹配 | 20% |
| 竞争差异化 | 15% |
| 变现潜力 | 15% |
| 时效价值 | 10% |
| 制作成本 | 8% |
| 合规风险 | 7% |

按账号当前目标可调（如变现期上调「变现潜力」），**维度和标尺不动**。

| 综合分 | 结论 |
|--------|------|
| ≥ 70 | **做** — 立刻排期 |
| 50–69 | **改方向** — 调角度/形式/时机后再评估，附至少 2 条建议 |
| < 50 | **不做** — 附至少 2 个替代选题 |

## 敏感赛道

下列赛道在「合规风险」维度扣分并标注 ⚠️ 与合规建议：医美 / 轻医美、财商理财、母婴育儿、K12 教育、健康养生、护肤功效、职场收入、婚恋情感。
