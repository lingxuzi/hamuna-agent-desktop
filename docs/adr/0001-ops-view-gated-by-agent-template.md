# 运营视图只对运营 Agent 模板创建的会话可见

运营工作台不是 Chat 的全局功能，而是「运营 Agent 模板」创建的工作区才拥有的界面。判定依据是工作区本来就有的 `templateId` 字段，不新增任何绑定机制。

## Considered Options

- **全局工作台**（所有 chat 都渲染运营视图）：违背"只在有运营上下文的会话里出现"，而且会给非运营会话塞进一份永远为空的运营视图。
- **给 session 新增模板来源字段**：与 `templateId` 重复表达同一件事，两个真相源迟早漂移。

## Consequences

- Chat 的渲染路径多一个 `templateId` 分支；非运营模板创建的会话不渲染运营视图。
- 当前唯一来源是运营 Agent 模板。等第二个模板也需要工作台时，再把它升成模板自己声明的一项属性 —— 现在只有一个来源，先不为假想的第二个写抽象。
