# 运营范围止于素材，加上投放后的数据回流

本产品不代做投放、不存平台凭据；但保留社媒账号栈与浏览器基建，用来在用户手动触发时读取创作者后台的表现数据，供复盘与 heartbeat 的反思使用。

## Considered Options

- **连账号栈与浏览器基建一起删**：登录态是复盘采集的前置条件，删掉之后复盘域就没有数据来源，只能永远停在"手工抄数据"。
- **接平台官方 API**：需要凭据与 OAuth，与"不存凭据"冲突。
- **让 Agent 自动投放**：把不可逆的对外动作交给模型，而且绕开了人本来就该在的那道检查点。

## Consequences

- 采集依赖有用户窗口的场景：内嵌浏览器带登录态，所以采集只能在 Chat 里手动触发。
- cron / heartbeat / IM 场景没有登录态，只做纯本地分析与沉淀 —— 这个分工是刻意的：无人值守的任务不许替用户产生对外动作。
- heartbeat 因此分成两段：**采集**（手动触发，带登录态）与 **分析反思**（可无人值守，读本地表现数据，产出规则反哺选题与制作）。
