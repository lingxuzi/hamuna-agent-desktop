# 失败模式库 · marketing-ad-skill 专属

> **目的**：复用 short-drama-ad-skill 30 轮沉淀的 14 条失败模式 + 4 类营销广告的类目专属模式。新 prompt 写前必查，写后必对照规避。

---

## 一、跨 4 类必须规避（9 条 · 来自 short-drama-ad-skill 沉淀）

### #4 · hero shot 漂移

- **触发**：商品展示 6s hero shot 用 text 模式 → AI 自动生成产品造型
- **症状**：产品瓶造型随机/与品牌不匹配
- **修复**：
  1. 必须先 `image_generate` 生成 hero shot 图（用 §3.5 prompt 模板 1）
  2. `video_generate` 用 keyframe 模式（`first_frame` = hero shot URL）
  3. hero shot 段时长 ≥4s

### #5 · keyframe 12s 锚脸失败

- **触发**：12s 多变场景段用 keyframe mode 锚定下一段人物
- **症状**：人物面容/服装漂移
- **修复**：
  1. 改 reference mode
  2. 输入 ≥1 张角色立绘
  3. 段长控制在 12s 内

### #8 · 多场景 prompt 漂移

- **触发**：reference mode 多场景描述
- **症状**：AI 合并场景、跳过关键场景
- **修复**：段首加场景锁定指令"全程严格在 X 场景"

### #13 · 多角色反派镜头背景漂移

- **触发**：v2.5-flash reference mode 多角色 + 反派服装风格化
- **症状**：反派镜头背景向反派服装调性漂移
- **修复**：
  1. 场景锁定指令显式列举反派镜头背景元素
  2. 反派镜头背景同约束（"反派镜头背景也必须包含以上 X 元素"）
  3. 构图约束（"反派入画落座到对面 X 位置"）

### #14 · 涂抹场景漂移到白天窗边

- **触发**：涂抹类（美妆/食品）涂抹时段不足 + prompt 含时间切换关键词
- **症状**：涂抹场景漂移到白天窗边
- **修复**：
  1. 涂抹时段 ≥4s
  2. 删除"morning sunlight / 暖台灯切换"等暗示时间切换的关键词
  3. 暖台灯全程不切换
  4. 涂抹过程分镜细化（手部+罐+涂抹+镜中）

### v9 · AI 字幕重复/段尾不渲染

- **触发**：prompt 让 AI 生成内嵌字幕
- **症状**：字幕重复渲染（v8 实证 4 次 → 2 次）/ 段尾不渲染（最后 0.5s）/ 配音串冲突
- **修复**：**字幕永远后处理**（drawtext `enable='between(t,T1,T2)'`）

### #15 · dialogue / drawtext / prompt 三轨不同步（v10 实证 · eval-5-drama）

- **触发**：3 段视频 prompt 各加 DIALOGUE BLOCK（嘴型动作）时，只更新 `dialogue_blocks` 数组 + `drawtext_subtitles_command`，忘了回改 video_generate call DIALOGUE BLOCK
- **症状**：
  1. **嘴型动作 vs 字幕不同步**：MCP 生成的嘴型按 prompt 走，字幕按 drawtext 走，观众看到嘴动+字幕文字/时间码不一致
  2. **同核心台词跨段重复**（本次实证）：段3 江屿 25-27s prompt 仍写 "你刚才不是熊猫吗？！"，与段2 22-24s 江屿 "等等……你刚才不是熊猫吗？" 核心台词重复，剧情变两连呆愣 + 字幕串戏
- **修复**（3 轨必须严格同步）：
  1. **唯一性约束**：每段 prompt DIALOGUE BLOCK 的台词不能在另一段重复（核心反转台词尤其只能出现一次）
  2. **删除即删除**：删掉某条 dialogue_blocks 时，必须同时删除对应 drawtext entry 和对应段的 prompt DIALOGUE BLOCK 条目
  3. **时间码镜像**：drawtext 的 `enable='between(t,T1,T2)'` 必须与 prompt DIALOGUE BLOCK 的时间码 1:1 对齐，差 0.5s 观众就觉得嘴型不对
  4. **脚本校验**：新 prompt 写完必须三轨交叉校验（见 §五 checklist）

### #16 · 锚点道具 vs 持续展示混淆（v11 实证 · eval-5-drama）

- **触发**：描述配角人物持有的道具锚（如 lead male 的宵夜盒 / 同事的咖啡杯）时使用状态描述
- **症状**：
  1. prompt 写 "胸前双手捧持宵夜盒" / "单手端着咖啡杯" → AI 解读为"全 12s 都保持这个姿势"
  2. 道具被当成 hero 持续展示，挤出核心剧情节奏（用户实证："红色宵夜展示了好几秒，没有任何意义"）
  3. 段3 收束时镜头仍被道具占据，CTA/价格/购物车元素出不来
- **修复**（3 条铁律）：
  1. **改用动作描述**：用"推门瞬间单手提宵夜盒"/"路过时端着咖啡杯"等带动作的描述，不要用"胸前双手捧持"等状态描述
  2. **显式放下指令**：每个临时道具都要写"推门后立刻放在床头柜角落，不再展示"
  3. **#16 临时道具锚标记**：在 `prop_design.props[].continuity_lock_instruction` 显式标注 "#16 临时道具锚：仅 X 瞬间附带 2-3s，推门后立刻放下不再占据画面"

### #17 · 节拍节奏太慢（v12 实证 · eval-5-drama）

- **触发**：12s 段内每个 key_action / beat 时长 ≥3s，BPM < 100，整体节奏拖沓
- **症状**：
  1. 用户反馈"节拍太慢，节拍需要加快"——镜头停留太久，关键剧情点不突出
  2. 抖音黄金节奏（每 12s ≥6-7 beats）未达标，观众注意力 3-5 秒后流失
  3. 蒙太奇三连 (16-21s) 节奏过宽，关键卖点展示不紧凑
- **修复**（抖音带货黄金节奏表）：
  1. **12s 段目标 ≥5 beats**：每 beat 1.5-2.5s，超过 3s 的动作必须切短
  2. **BGM BPM 阶梯**：0-12s 段 BPM 110-115 / 12-24s 段 BPM 135-140 / 24-36s 段 BPM 128-132 + 反转 hit
  3. **蒙太奇密度**：6s 蒙太奇窗口切 ≥4 beats（每 cut 1-1.5s）
  4. **关键动作压缩**：推门 + 看到人 + 表情变化 = 1-2s（不能用 3s）
  5. **CTA 紧凑**：反转 → 卖点托举 → 价格弹出 → 购物车 → ka-ching ≤12s 内全跑完

## 二、类目专属失败模式（4 条）

### #S1 · 商品展示 · 产品造型在 12s 段内漂移

- **触发**：涂抹类（口红/面霜）涂抹动作描述模糊
- **症状**：涂抹前后产品造型不一致
- **修复**：
  1. hero shot 先 image_generate
  2. 涂抹时段 ≥4s
  3. 涂抹过程分镜细化（手部→蘸取→涂抹→镜中）

### #S2 · 电商种草 · 剧情过度学短剧带货

- **触发**：用户输入含"反转/逆袭/复仇"等短剧关键词
- **症状**：广告变成短剧，丢失产品功能展示
- **修复**：
  1. 强约束"1-2 使用场景限制"
  2. 不做反转/逆袭/复仇桥段
  3. 路由判断：含短剧关键词 → 路由 short-drama-ad-creator（不归本 skill）

### #S3 · 游戏买量 · 前 3 秒 hook 力度不足

- **触发**：hook 段平淡/剧情铺垫过多
- **症状**：前 3 秒无视觉/剧情冲击力 → 用户划走
- **修复**：
  1. 大场面战斗 / 反差身份 / 抽卡爆击 / 攻略剧情 / 社交炫耀 选 1
  2. 前 3 秒必须出现具体物/具体场景/具体动作
  3. 视觉冲击力 > 剧情（不要照搬短剧带货的剧情钩子）

### #S4 · 品牌宣传 · 强调具体功能/价格

- **触发**：品牌宣传段加入产品功能/价格描述
- **症状**：丢失品牌调性 → 变成电商种草
- **修复**：
  1. 只强品牌精神 + logo
  2. 不写功能/价格
  3. BGM 比人声重要（情绪叙事）

## 四、修改回退表（与 SKILL.md §11 对应）

| 修改类型 | 重做范围 | 不重做 |
|---|---|---|
| 改 hook（0-3s） | 段 1 重做 | 段 2/3/4 保留 |
| 改卖点（3-15s） | 段 2 重做 | 段 1/3/4 保留 |
| 改 CTA（25-30s） | 段 3/末段重做 | 段 1/2 保留 |
| 改 hero shot | 重新 image_generate hero + 末段 keyframe | 其余保留 |
| 改风格（5 风格库切换） | 全段重做（参考图全换） | drawtext 字幕表保留 |
| 改品类（美妆 → 食品） | 全段重做 | drawtext 字幕表改写 |
| 改调性（高级奢华 → 国潮东方） | 全段重做（氛围图+灯光+色调全换） | drawtext 字幕表改写 |
| 改平台（抖音 → B站） | 段拼接节奏调整（快剪 → 慢镜） | BGM 库全换 |

## 五、规避检查清单（写新 prompt 前必过）

- [ ] 时长匹配段拼接表（15s=12+3 / 30s=12+12+6 / 60s=12×5）
- [ ] 每段 ≤12s 验证
- [ ] 场景锁定指令就位（段首 + 关键动作）
- [ ] 字幕 prompt 禁写内嵌关键词（v9 决策）
- [ ] BGM/SFX 三段节奏表完整
- [ ] 风格库关键词在 prompt 中显式声明
- [ ] 失败模式 #4/#5/#8/#13/#14 已规避
- [ ] 类目专属失败模式已规避（#S1/#S2/#S3/#S4）
- [ ] **#15 三轨同步校验**：dialogue_blocks / drawtext_subtitles_command / 每段 prompt DIALOGUE BLOCK 时间码 1:1 对齐 + 核心台词不跨段重复
- [ ] **#16 临时道具锚校验**：配角持有的道具（宵夜盒/咖啡杯等）必须用动作描述 + 显式放下指令，不能用状态描述（胸前双手捧持）
- [ ] **#17 节拍节奏校验**：12s 段 ≥5 beats，BPM 110-140 阶梯节奏，单 beat 1.5-2.5s
