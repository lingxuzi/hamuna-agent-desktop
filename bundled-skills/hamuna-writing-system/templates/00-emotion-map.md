# 《【书名】》情绪地图与概念基盘

## 一、高概念一句话（Logline）
> 一句话说清：**【主角】身处【何种极限逆境】，凭借【何种独特手段/金手指】，对抗【何等庞大阻力】，以实现【何种核心欲求】。**
> 例：《断玉辞》——获罪大验玉师之女沈玉裁，化名姜棠潜入皇家玉藏局，凭借五重断玉绝技与冷血督监闻澈在生死局中由敌变友，以血肉之躯凿穿三十年皇权遮天大案。

---

## 二、核心情绪基调（Emotional Tone）
- **基调色彩**：冷硬暗黑 / 孤勇悲壮 / 炽热逆袭 / 智力狂飙
- **受众爽点内核**：
  1. 顶级技术流降维打击（用专业知识碾压权谋）
  2. 极限战损与向死而生（越残血越凶悍）
  3. 双强互托与生死同盟（拒绝工业糖精，全在生死关头见真心）

---

## 三、全书三大情绪极值点（Tonal Extremes）

```
情绪高度
   ^
100|                                             [终极绝顶: 兵临城下/终极公审]
 80|                         [大转折: 破关夺符]
 50| [入局交锋]
 20|                 [至暗时刻: 身份暴露/坠河濒死]
  0+-------------------------------------------------------------> 章节推进
   0               50               100             150            200
```

1. **至暗时刻（All Is Lost Moment）**：
   - 所在区间：约全书 50%~60%（第三卷末/第四卷初）
   - 事件描述：失去一切官方庇护，重伤残废，被全天下通缉，逼入死地绝境。
2. **惊天反转（The Pivot Point）**：
   - 所在区间：约全书 65%~75%
   - 事件描述：绝地拿到反击底牌（真遗诏/虎符），旧部死忠天降归位，从被动逃亡转向主动争霸。
3. **终极绝顶（The Climax）**：
   - 所在区间：约全书 90%~95%
   - 事件描述：在天下人注视下，真凭实据当众戳穿皇权三十年的虚伪面具，文戏与武戏双重登顶。
