# 反AI腔与去套话词典（Anti-AI Lexicon & Replacement Guide）

> **诊断背景**
> 大语言模型在小说创作中最致命的痼疾是：**"假深刻、假紧张、套话泛滥、动量不足"**。
> 本清册总结了 AI 高频中毒词汇、套路句式以及行业级的手工置换方案。

> 🔴 **ABSOLUTE 段 · 本词典硬禁用项声明**
> 本词典从 v0.3 起作为 **hamuna 原违禁词表 + 散文主干硬禁令的统一并集**使用。商业小说 / 短剧 / 网文 / 散文 / 知乎 / 论坛 / 公众号 / 行业稿 / 评测 / 教程 / 短文 / 口播 / 演讲的所有正文（含人物对白、内心理活动、旁白）必须满足以下**全部**条件，缺一即返工：
>
> **A. 散文主干结构性硬禁用项**（详见本仓 `references/prose-methods.md` 第六节 + `references/revision-routine.md` 第五遍）：
> - **翻案腔外衣清零**：禁止"不是 A 而是 B" / "并非 A 而是 B" / "不在于 A 而在于 B" / "与其说 A 不如说 B" / "看似 A 实则 B" / "你以为是 A 其实是 B" / "我一直以为 A 后来才发现 B" / "答案恰恰相反" / "A 不重要，重要的是 B" / "真正值钱的从来都与 A 无关" —— 同一动作换任何字面外衣都算命中
> - **正文零破折号**：禁止 `—` / `——` / `–`（全角破折号、双破折号、连接号式破折号）
> - **冒号单点使用**：中文 `：` 与英文 `:` 只允许引出人物直接原话；"一句话总结：" / "核心是：" / "重点是：" 等提示性冒号全部改写；网址、代码、机器字段除外
> - **同构排比 ≤ 2 项**：同一引导词或同一句型连排三次以上，留两项，第三项必须换说法或删掉
> - **抽象名词配具体动词的抒情句清零**：禁止"时间保管 / 岁月打磨 / 焦虑显形 / 孤独发芽 / 记忆安放"等
> - **动词名词化清零**："进行了 / 实现了 / 完成了对 / 起到了……作用 / 具有……意义" 还原成直接动词
> - **"说白了 / 说穿了 / 先说结论" 清零**
> - **模型洞察路标清零**："更微妙的是 / 还有一层 / 只说对了一半 / 值得注意的是 / 需要指出的是 / 从某种意义上说" 用来给段落抬价时删除
> - **27 个绝对禁词清零**：赋能、抓手、商业闭环、价值闭环、能力沉淀、拉通、底层逻辑、顶层设计、认知跃迁、价值释放、能力建设、降本增效、内容矩阵、全链路、组合拳、打开想象空间、结构性机会、关键命题、深层逻辑、技术底座、公共底座、技术主权、单点风险、主脊柱、材料锚点、认知增量、迭代闭环
> - **9 个语境检查词**：沉淀、颗粒度、对齐、协同、方法论、核心变量、打法、想象空间、不丢 —— 表示本义（化学沉淀 / 排版对齐 / 游戏战术 / "不丢人" 等）保留，替普通事情抬价时改写
> - **9 个抒情词**滥用清零：安放、抵达、微光、褶皱、丰盈、滚烫、轻盈、赤裸、剥开
>
> **B. 来自 hamuna 原违禁词表**（见下文章节）：
> - **滥用程度副词清零**：极其 / 简直 / 宛如 / 仿佛 / 毫无疑问 / 分外 / 极度
> - **廉价转折与心理说明词清零**：赫然 / 悄然 / 蓦然 / 不禁 / 不由得 / 殊不知 / 浑然不觉
> - **"不仅……更是……" 句式清零**（公文腔）
> - **"眼神中闪过一丝……" 清零**（调色盘式情绪堆叠）
> - **"嘴角勾起一抹邪魅/玩味/冰冷的笑" 清零**（套路神态）
> - **"空气中弥漫着压抑/危险/悲伤的气息" 清零**（借环境抒情）
> - **"他的 [抽象情绪] 到了极点" 清零**
>
> **C. 自动化硬执行**：每章正文交付前必须跑 `python3 scripts/check_prose.py <章节.md>`，脚本零失败项才能进 walkthrough。脚本报警项需人工核验语境（本义保留 / 抬价改写）。

## 一、高危违禁词汇黑名单（永久封杀）

在商业写作系统中，以下词汇在正式正文中出现频率**必须清零**。遇到必改！

### 1. 滥用程度副词组（严禁出现）
- ❌ **极其 / 极度 / 简直 / 宛如 / 仿佛 / 毫无疑问 / 分外**
  - *病症原因*：模型缺乏具象描写能力时，用廉价的副词向读者施压，造成语言通货膨胀。
  - *置换原则*：**删去副词，还原物理事实。**
  - 例：“他感到极其恐惧” -> “他脊梁骨窜起一股刺骨的冰凉，后背汗毛根根倒竖”。
  - 例：“速度极其飞快” -> “战马四蹄翻飞，带起连成一线的黄沙泥浪”。

### 2. 廉价转折与心理说明词（严禁出现）
- ❌ **赫然 / 悄然 / 蓦然 / 不禁 / 不由得 / 殊不知 / 浑然不觉**
  - *病症原因*：强行提示读者“这里有反转/这里要注意”，剥夺读者的观察主动权。
  - *置换原则*：**直接呈现事件主体。**
  - 例：“他低头赫然发现一滩血迹” -> “靴底踩中一滩黏稠的暗红，发出令人作呕的啪嗒声”。
  - 例：“她心中不禁泛起一丝涟漪” -> “她避开了他的目光，指尖下意识捻弄着袖口脱线的一根棉线”。

## 二、AI高频油腻套路句式清单（结构性清洗）

以下句式是各大网文平台读者“一眼识破AI”的重灾区：

### 1. “不仅……更是……”（假大空公文腔）
- ❌ **AI原文**：“这一刀不仅劈开了坚硬的铁甲，更是劈开了大胤朝三十年的虚假太平，宣告了真龙的归位。”
- 💡 **改写方案**：“长刀劈落，生铁甲片带着碎肉飞溅开来。血柱冲天而起，染红了朱雀门前三丈白玉石阶。”（*只做动作，意义由读者在情节中自行领悟！*）

### 2. “眼神中闪过一丝……”（无意义眼神特写）
- ❌ **AI原文**：“他那双深邃的眸子里，飞快地闪过了一丝诧异、一丝狠厉与一丝不易察觉的温柔。”
- 💡 **改写方案**：“他眯了眯眼，眼角那道暗红色的刀疤微微扯动，握刀的虎口稍稍紧了半分。”（*人类面部不可能同时调色盘式展示复杂情绪！*）

### 3. “嘴角勾起一抹邪魅/玩味/冰冷的笑”
- ❌ **AI原文**：“男人居高临下地看着他，嘴角勾起了一抹残忍而冰冷的笑意。”
- 💡 **改写方案**：“男人垂眼看着地上的残尸，下唇微挑，自喉底滚出一声极其短促的嗤笑，靴底碾过断刀的残片。”

### 4. “空气中弥漫着压抑/危险/悲伤的气息”
- ❌ **AI原文**：“四周一片死寂，空气中弥漫着令人窒息的危险与绝望。”
- 💡 **改写方案**：“风停了。四下静得连黄沙落在枯叶上的沙沙声都听得一清二楚。战马打了个响鼻，烦躁地在原地刨起蹄子。”
