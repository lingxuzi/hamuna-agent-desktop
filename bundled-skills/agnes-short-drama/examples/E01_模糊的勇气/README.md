## 2. Phase 3：第 1 集剧本

### 集标题：《模糊的勇气》

> 命名公式：成长日记型 `{心境} + {蜕变}`

### 完整剧本

【场景】当代高中校园，图书馆，黄昏。窗外樱花飘落，暖色夕阳光线斜射进木质书架间。

△ 镜头缓慢推近一排排深棕色木质书架，暖色光线在书脊上投下长影。

△ 一本深棕色日记本夹在两本词典之间，封面右下角烫金"LXM"字样微微反光。

林小满（16岁，深蓝色校服，黑色长发及肩，神色怯懦，敏感）从座位上抬起头，被日记本的微光吸引。

林小满（惊讶，迟疑）："……这是什么？"

【道具】深棕色日记本（封面烫金"LXM"字样，纸张微黄陈旧）

△ 林小满颤抖着伸出指尖，触碰日记本封面。日记本翻开空白页，纸张泛起淡蓝色微光。

日记（音色清冷，旁白式）："林小满，你还有三天。"

林小满（惊惶，失声）："谁……谁在说话？！"

日记（平静，叙事式）："我是十年后的你。"

△ 镜头快速上拉，对准林小满因惊惶而睁大的双眸。周围空气仿佛凝固。

林小满（颤抖，呢喃）："十年后……的我？"

日记（坚定，告警式）："三天后是告白截止日。你必须说出真话，否则十年后的你将永远困在遗憾里。"

△ 镜头微微前推，对准日记本上开始显现的墨迹——十年后的笔迹，刚劲但带颤抖。

日记（温柔，嘱托式）："不要害怕被拒绝。真正的勇气，是敢在最熟悉的人面前，做最不熟悉的自己。"

【道具】日记本（空白页显现墨迹："你做到了"）

△ 镜头拉远，画面回到图书馆全景。夕阳将林小满的身影拉长，她怀抱日记本站在书架前，神色从惊惶转为复杂。

林小满（内心独白）："我……真的能说出来吗？"

△ 镜头缓慢下摇，落幅在林小满紧攥日记本的指尖——指尖微颤，但未松开。

内心 BGM 响起（钢琴轻音乐，缓慢上行）

## 5. 单集合成（ffmpeg 命令）

```bash
# 假设 13 个镜头视频已生成于 shots/E01/
cd shots/E01

# 创建 concat 列表
ls E01_Shot*.mp4 | sort | sed "s/^/file '/; s/$/'/" > concat_list.txt

# 拼接（重新编码避免时基漂移）
ffmpeg -f concat -safe 0 -i concat_list.txt \
  -c:v libx264 -preset slow -crf 18 \
  -c:a aac -b:a 192k \
  "../../final/E01_模糊的勇气.mp4"
```
