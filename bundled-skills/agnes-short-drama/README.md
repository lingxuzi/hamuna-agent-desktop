# Agnes Short Drama · AI 短剧创作导演工作台

[English](README_en.md)

从 100 字故事种子到多集 AI 短剧——你的 AI 短剧创作导演。

一个将 AI Agent 转化为 **AI 短剧创作导演** 的 Skill，覆盖微短剧/竖屏短剧的完整制作流程：从一个故事创意到可直接使用的多集导演式剧本 + 资产库关键帧提示词 + 分镜视频提示词。

## 工作流程

整个流程对应真实短剧制作的阶段：

```
"内向的高中女生在图书馆捡到一本会说话的日记本..."
                  ↓
   Phase 1: 创意简报        ← 用户 4 字段输入（故事种子 + 风格 + 比例 + 集数）
   Phase 2: 世界观与角色     ← AI 自动展开（剧集/故事类型/目标受众/剧情概要/世界观/角色设定）
   Phase 3: 分集剧本         ← 导演式语法【场景】/△/角色（情感，语调）：/【道具】
   Phase 4: 资产库          ← 角色/场景/道具关键帧提示词（agnes-image-2.5-flash）
   Phase 5: 分镜与拍摄       ← 多宫格分镜图 + 12 字段单镜视频提示词（agnes-video-2.5-flash）
   Phase 6: 审片与交付       ← 迭代修改 + ffmpeg 合成全集
                  ↓
   可直接复制使用的剧本、资产提示词、视频提示词 + 最终合成 mp4
```

## 核心特性

- **用户输入极简** — 只需 4 个字段（故事种子 + 风格 + 比例 + 集数），AI 自动展开其余 6 个元数据
- **三大风格层级** — 60+ 模板：真人电影（25+）、3D 风格化（10+）、2D 动画（25+）
- **4 种 AI 短剧叙事模型** — 悬念递进型、冲突升级型、爽点连发型、成长日记型
- **导演式剧本语法** — 统一 4 种标记贯穿"集→分镜"两层
- **12 字段分镜模板** — 起幅/景别/运镜/角色/场景/动作/转场/表情/对白/音效/光线/落幅
- **风格 = 四维耦合** — 不只是滤镜，是视觉 + 镜头 + 剧本 + 情绪的完整约束
- **即拷即用** — 提示词可直接通过 `mcp__multimedia-creator__agnes25_*` 工具调用

## 三种风格层级

### 1. 真人电影风格（Live-Action Realism）
- 25+ 模板：悬疑电影、90年代港片、昆汀胶片、古偶唯美、韩剧柔光、俄罗斯忧郁、是枝裕和日式纪实、恐怖电影等
- 适合：剧情向、反转向、情感向、人性向

### 2. 3D 风格化（3D Stylized）
- 10+ 模板：3D 古风国漫、国风 3D 渲染、3D 迪士尼、UE5 写实、3D 简约卡通、粘土动画等
- 适合：仙侠、玄幻、爽文、奇幻、美食

### 3. 2D 动画（2D Animation）
- 25+ 模板：二次元动漫、宫崎骏画风、日式少女漫、东方水墨、中式皮影、宫崎骏、上美厂老动画等
- 适合：校园、青春、情感、治愈、二次元向

## 四种叙事模型

| 模型 | 名称 | 核心逻辑 | 适合题材 |
|------|------|---------|---------|
| A | 悬念递进型 | 每集一层真相，结尾埋下一层 | 悬疑/推理/犯罪 |
| B | 冲突升级型 | 每集一次冲突升级，主角处境更艰难 | 情感/校园/职场 |
| C | 爽点连发型 | 每集一个"打脸"或"获胜"事件 | 穿越/逆袭/爽文 |
| D | 成长日记型 | 每集一次内心蜕变，最后集总结 | 青春/治愈/奇幻 |

## 入口模式（自动检测）

| 模式 | 触发信号 | 起始 Phase |
|------|---------|-----------|
| **A：完整短剧创作流** | "帮我做一个短剧"、"我想做一个 5 集短剧" | 创意简报 |

## 快速上手：一部 5 集校园奇幻短剧的诞生

### Step 1 — 一句话故事种子

> "内向的高中女生在图书馆捡到一本会说话的日记本，日记里记录着十年后自己写给现在的信，她必须在天台告白截止日之前鼓起勇气。"

AI 自动展开为：
- 风格：二次元动漫
- 集数：5 集
- 比例：9:16
- 故事类型：校园奇幻
- 目标受众：青少年

### Step 2 — AI 自动生成世界观/角色

- 剧情概要（4-6 句结构：开场钩子→核心冲突→升级→转折→高潮→钩子）
- 世界观设定：当代高中校园，主要场景为图书馆、教室与天台
- 3 个角色 + 1 物件：
  - 林小满（主角，内向高中女生）
  - 陆言（暗恋对象，阳光男生）
  - 日记（会说话的奇幻物品）

### Step 3 — AI 生成 5 集导演式剧本

每集用统一的 4 种标记：
```
【场景】当代高中校园，图书馆（回忆：三年前）。
...
△ 镜头动作/视觉描述。
林小满（紧张，颤抖）："为什么……为什么我不敢说出口。"
【道具】深棕色日记本
```

### Step 4 — AI 通过 agnes-image-2.5-flash 生成资产库

- 角色资产图：@林小满（全身 / 中近景 / 状态切换）
- 场景资产图：@图书馆 / @教室 / @天台
- 道具资产图：@日记本

### Step 5 — AI 通过 agnes-video-2.5-flash reference 模式生成视频

每镜独立生成，用 12 字段完整 prompt：
```
[约束]: 片段时长请限制在4-15s
[起幅]: 中近景起幅，@林小满 站在图书馆窗边
[景别]: 中近景
[运镜]: 镜头微微前推
[角色@]: @林小满
[场景@]: @图书馆
[动作]: @林小满 翻开空白页，泪水滴落在纸上
[转场]: 无
[表情]: 眼眶泛红，咬紧嘴唇
[对白]: "为什么……为什么我不敢说出口。"
[音效/声]: 内心 BGM 响起（钢琴轻音乐）
[色调/光线]: 暖色夕阳光线 + 高饱和度
[落幅]: 落幅在日记本上逐渐模糊的"LXM"烫金字上
```
