> **核心使命**：Phase 5 分镜与拍摄阶段的实操手册。覆盖多宫格分镜图、视频提示词的 Multi-Phase 结构、合成导出。

## Part 1：分镜图（Storyboard Grid）的两种路径

微短剧有两条生成路径：

| 路径 | 何时用 | 优势 |
|------|--------|------|
| **A：多宫格分镜图（Grid Mode）** | 1 集全部镜头一次性可视化 | 整体节奏可视化、跨镜头一致性检查 |
| **B：单镜头分镜图（Per-shot Mode）** | 镜头需要精细控制或重做单镜 | 单镜可控、失败易修复 |

**默认推荐**：先用 B（per-shot）跑通单镜头，确认风格/资产后再升级到 A（grid）做全集节奏优化。

## Part 2：多宫格分镜图（Grid Mode）

### 2.1 宫格规格

| 集时长 | 推荐宫格 | 单镜头时长 |
|--------|---------|-----------|
| 50-104s（5 集默认） | 3×3 = 9 宫 | 8-12s |
| 5-6s 单镜特殊短片 | 2×2 = 4 宫 | 1.5s |
| 10 集（每集 90s） | 3×4 = 12 宫（拆 2 张） | 7-8s |

> **注**：单段视频最大 12s，单集 90s 通常需拆 8-10 个视频，**配合 grid 9 宫或 12 宫刚好对齐**。

### 2.2 多宫格 prompt 模板

```
{风格锚定词}风格，{集名}分镜图集，
3x3 九宫格布局，9 个等大方格，每个方格独立显示一个镜头：

【宫 1】{镜头 1 简述}：{角色名}，{动作}，{景别}，{表情}
【宫 2】{镜头 2 简述}：...
【宫 3】{镜头 3 简述}：...
【宫 4】{镜头 4 简述}：...
【宫 5】{镜头 5 简述}：...
【宫 6】{镜头 6 简述}：...
【宫 7】{镜头 7 简述}：...
【宫 8】{镜头 8 简述}：...
【宫 9】{镜头 9 简述}：...

整体统一色调：{主色调}，{光线方向}，胶片质感（或其他风格锚定）。
每宫间有清晰分割线，每个镜头内含角色 + 场景视觉锚点。
```

### 2.3 多宫格生成工作流

```
步骤 ① 收集 9 个镜头的简述（来自 Phase 5 单镜头 prompt 摘要）
步骤 ② 用 agnes-image-2.5-flash 生成 1 张 9 宫分镜图（9:16 或 16:9）
步骤 ③ 用户复检分镜图 → 不通过则调整简述重生成
步骤 ④ 通过 → 进入单镜头视频生成（用 reference 模式）
```

**关键参数**：
- 比例 `9:16`（短剧竖屏）或 `16:9`（横屏电影感）
- size `1K`（快速预览）或 `2K`（高精度复检）
- ratio 根据宫数选：3×3 用 `1:1`（九宫格本身方形排版）

### 2.4 多宫格的复用价值

**生成 1 次可复用 N 次**：
- 9 宫分镜图整体 → 用作整个 5 集项目的"视觉总谱"
- 每个宫格独立裁剪 → 用作单镜头的 reference 图
- 跨集修改 → 局部宫格重生成即可

## Part 3：视频提示词的 Multi-Phase 结构

### 3.1 什么是 Multi-Phase

agnes-video-2.5-flash 的 video prompt 分为 4 个 Phase：

| Phase | 含义 | 何时填 |
|-------|------|--------|
| Phase 1 | 风格与画质锚定 | 永远必填 |
| Phase 2 | 主体描述（角色/场景/动作） | 永远必填 |
| Phase 3 | 镜头语言（景别/运镜/转场/光线） | 永远必填 |
| Phase 4 | 情绪/音效/落幅 | 永远必填 |

**视频提示词不是单段文本，而是 4 段结构化提示**。

### 3.2 Multi-Phase 完整模板

```
[Phase 1 - 风格画质]
{风格锚定词}风格，{画质锚定词}，{画幅比例}。
例如：悬疑电影风格，电影级摄影，9:16 竖屏。

[Phase 2 - 主体描述]
主体：@{角色名}（从资产库引用）。
场景：@{场景名}（从资产库引用）。
动作：{动词} + {细节}。
道具：@{道具名}（如适用）。

[Phase 3 - 镜头语言]
景别：{特写/近景/中近景/中景/过肩中景/双人中景/全景/远景}。
运镜：{8 种运镜之一}。
转场：{5 种转场之一}。
色调/光线：{光线方向} + {色调}。

[Phase 4 - 情绪音效]
表情：{情绪关键词}。
对白："{台词原文}"。
音效：{声音描述}。
落幅：落幅在{画面描述}上。
```

### 3.3 真实示例（Multi-Phase 写法）

```
[Phase 1 - 风格画质]
悬疑电影风格，电影级摄影，9:16 竖屏。

[Phase 2 - 主体描述]
主体：@林远，45 岁古董店老板。
场景：@地下密室。
动作：@林远 蹲在铁门前，指尖颤抖着触碰地面锈蚀的锁。
道具：@匿名信（散落地面）。

[Phase 3 - 镜头语言]
景别：特写。
运镜：镜头缓慢下摇。
转场：叠画（回忆）。
色调/光线：侧光 + 蓝橙色调 + 阴影深重。

[Phase 4 - 情绪音效]
表情：神色惊惶，眼底有痛楚。
对白："弟弟……你还在吗。"
音效：远处警笛长鸣。
落幅：落幅在 @林远 因愤怒而微微颤抖的指尖上。
```

## Part 4：分镜图 → 视频生成的工作流

### 4.1 推荐流程（reference 模式）

```
步骤 ① 生成多宫格分镜图（1 张）
步骤 ② 裁剪/选择 1 个宫格作为单镜头 reference
步骤 ③ 用 agnes-image-2.5-flash 生成单镜头精修关键帧（可重复至完美）
步骤 ④ 用 agnes-video-2.5-flash reference 模式 + [精修关键帧, 资产图] 生成单镜头视频
步骤 ⑤ 用户审片 → 通过则保留，不通过则回到步骤 ③ 重生成
```

### 4.2 agnes-image-2.5-flash 调用（关键帧）

```js
{
  model: "agnes-image-2.5-flash",
  size: "1K",
  ratio: "9:16",  // 或 "1:1" 用于资产图
  prompt: "<分镜或资产提示词>"
}
```

### 4.3 agnes-video-2.5-flash 调用（reference 模式）

```js
{
  model: "agnes-video-2.5-flash",
  mode: "reference",
  size: "720P",
  seconds: "12",  // 或 "4"–"12" 范围内
  aspect_ratio: "9:16",
  timeout_seconds: 600,
  poll_interval_seconds: 5,
  images: [
    "<分镜关键帧 HTTPS URL>",  // Picture 1：分镜精修图（**HTTPS URL 最稳**）
    "<资产图 HTTPS URL>"        // Picture 2：角色/场景资产
  ],
  prompt: "<Multi-Phase 视频提示词>"
}
```

**参数锁定**：
- size 必须 `720P`（flash 不接受 1080P）
- seconds 必须 `≤ 12`（flash 上限）
- images 最多 5 张，videos 0（不接受视频参考）

**images 字段最佳实践（端到端验证 2026-09-08）**：
- **HTTPS URL 最稳**：调用 `image_generate` 后从响应 `data[0].url` 取出，传给后续 `video_generate`
- 本地路径不稳：MCP CWD 跨机器不同（`hosted_mcps/agnes-video-25/outputs/images/` vs `<project>/outputs/images/`），需先确认 MCP CWD
- 错误信息 `"images is neither HTTPS URL, data URI, nor existing local file"` 即路径问题

### 4.4 跨参考图策略（多张 reference）

当单镜视频需要 **2-3 张参考图**（如"角色 + 场景 + 道具"三参考）：

```
images: [
  "<角色资产图>",     // Picture 1：角色一致性
  "<场景资产图>",     // Picture 2：场景一致性
  "<分镜关键帧>"      // Picture 3：构图参考
]
prompt 中显式标注：
  "参考 <Picture 1> 角色外观，
   参考 <Picture 2> 场景环境，
   参考 <Picture 3> 镜头景别与构图。"
```

**关键约束**：
- reference 总数 **≤ 3 张**——超出模型会丢上下文
- prompt 中必须**显式标注每张图的用途**——避免模型混淆语义

## Part 5：合成与导出

### 5.1 单镜视频命名约定

```
{项目名}_{集号}_{镜头号}_{风格锚定}.mp4
例如：
  暴雨夜的回声_E01_Shot04_悬疑电影风格.mp4
  古刹剑魂_E02_Shot07_3D古风国漫.mp4
```

### 5.2 集级合成

**用 ffmpeg 拼接同一集的所有镜头**：

```bash
# 镜头列表（按顺序）
shot_files=(
  "暴雨夜的回声_E01_Shot01_悬疑电影风格.mp4"
  "暴雨夜的回声_E01_Shot02_悬疑电影风格.mp4"
  ...
  "暴雨夜的回声_E01_Shot13_悬疑电影风格.mp4"
)

# 创建 concat 列表
printf "file '%s'\n" "${shot_files[@]}" > concat_list.txt

# 拼接（注意重新编码以避免时基不一致）
ffmpeg -f concat -safe 0 -i concat_list.txt \
  -c:v libx264 -preset slow -crf 18 \
  -c:a aac -b:a 192k \
  "暴雨夜的回声_E01.mp4"
```

**参数建议**：
- 视频编码：`libx264`，预设 `slow`，质量 `crf 18`
- 音频编码：`aac`，码率 `192k`
- 输出格式：`.mp4`（兼容播放）

### 5.3 跨集合成（全集）

```bash
# 拼接所有集
for episode in E01 E02 E03 E04 E05; do
  echo "file '暴雨夜的回声_${episode}.mp4'"
done > concat_all.txt

ffmpeg -f concat -safe 0 -i concat_all.txt \
  -c:v libx264 -preset slow -crf 18 \
  -c:a copy \
  "暴雨夜的回声_全集.mp4"
```

### 5.4 加片头片尾

```bash
# 拼接：片头 + 第 1 集 + ... + 第 N 集 + 片尾
ffmpeg -f concat -safe 0 -i concat_with_intro.txt \
  -c:v libx264 -preset slow -crf 18 \
  -c:a aac -b:a 192k \
  "暴雨夜的回声_完整版.mp4"
```

### 5.5 字幕嵌入（可选）

如需嵌入字幕（中文硬字幕）：

```bash
ffmpeg -i "暴雨夜的回声_全集.mp4" \
  -vf "subtitles=字幕.srt:force_style='FontName=PingFang SC,FontSize=24,PrimaryColour=&H00FFFFFF,OutlineColour=&H00000000,BorderStyle=1,Outline=2'" \
  -c:v libx264 -preset slow -crf 18 \
  -c:a copy \
  "暴雨夜的回声_全集_带字幕.mp4"
```

> **注**：本 skill 不在范围内处理字幕生成。字幕由用户使用专门的字幕工具生成（如 Aegisub、Arctime），本 skill 只负责嵌入。

## Part 6：分镜节奏检查清单

生成完整集后，用此清单逐项核对：

| 检查项 | 通过标准 |
|--------|---------|
| **总时长** | 50-104s（5 集默认） |
| **镜头数** | 13-18 个 |
| **单镜时长** | 4-12s（flash 上限） |
| **景别分布** | 特写 30-40% / 中景 40-50% / 全景 10-20% |
| **运镜变化** | 至少 4 种不同运镜 |
| **转场使用** | 5 种转场中至少出现 3 种 |
| **情绪曲线** | 开场慢 → 中段中 → 高潮快 → 收尾慢 |
| **资产引用** | 所有镜头都引用了 @角色/@场景/@道具 |
| **风格一致性** | 全集风格锚定词统一 |
| **线索/钩子** | 收尾镜头必含开放钩子（悬念/留疑） |

## Part 7：常见错误与规避

### 错误 1：分镜图与单镜视频脱节

❌ 错误：分镜图画得很好，但单镜视频完全跑偏
✅ 正确：分镜图裁剪后作为 video reference 传入

### 错误 2：宫格内塞太多文字描述

❌ 错误：每个宫格里写 50 字以上的镜头描述
✅ 正确：每宫 5-15 字简述（详见 2.2 模板）

### 错误 3：单镜视频超过 12s

❌ 错误：把 18s 的内容硬塞进一个视频
✅ 正确：拆 2 段（10s + 8s），转场用叠画或闪白

### 错误 4：reference 图塞了 5+ 张

❌ 错误：images=[角色, 场景, 道具, 状态, 备用]（5 张）
✅ 正确：images 最多 3 张——超出模型会丢上下文

### 错误 5：分镜图比例与单镜视频比例不一致

❌ 错误：分镜图 16:9，单镜视频 9:16（强行变形）
✅ 正确：分镜图与单镜视频比例统一（默认 9:16）

### 错误 6：合成时音频时基不一致

❌ 错误：直接 concat 单镜视频（音频时基漂移）
✅ 正确：concat 时用 `-c:a aac -b:a 192k` 重新编码

### 错误 7：字幕嵌入字体不兼容

❌ 错误：用系统字体，Windows 显示正常 Mac 显示乱码
✅ 正确：强制 `FontName=PingFang SC` 或 `FontName=Microsoft YaHei`

### 错误 8：跨集风格漂移

❌ 错误：第 1 集暖色调，第 5 集冷色调（同一项目应有整体主色调）
✅ 正确：跨集主色调统一（季节/情绪变化允许微调）
