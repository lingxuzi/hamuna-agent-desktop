## Part 1：12 字段分镜模板（详解）

```
[约束]: 片段时长请限制在4-15s，输入"@"可引用角色、场景
[起幅]: {特写/近景} 起幅，{起始画面描述}
[景别]: 特写 / 近景 / 中近景 / 中景 / 过肩中景 / 双人中景 / 全景 / 远景
[运镜]: 镜头固定 / 镜头缓慢下摇 / 镜头拉远 / 镜头跟随 / 镜头推近 / 镜头微微前推 / 镜头快速上拉 / 镜头向右横移
[角色@]: @{角色名}（从资产库引用）
[场景@]: @{场景名}（从资产库引用）
[动作]: {动词} + {细节}
[转场]: {转场类型}（叠画 / 水波纹幻觉 / 横移重组 / 闪白 / 淡入淡出）
[表情]: {情绪关键词}（神色惊惶 / 嘴角挂着自信的微笑 / 满脸陶醉）
[对白]: "{台词原文}"
[音效/声]: {声音描述}（滋啦一声热油泼在葱花上 / 刀刃起落声）
[色调/光线]: {光线方向} + {色调}（逆光 / 画面色调变黄 / 热浪袭人）
[落幅]: 落幅在{画面描述}上
```

### 字段 1：[约束]

**格式**：`[约束]: 片段时长请限制在4-15s，输入"@"可引用角色、场景`

**目的**：锁定 agnes-video-2.5-flash 的硬约束
- **必须保留**：每个 prompt 必含这条
- agnes-video-2.5-flash 时长上限 12s（不是 15s）；如必须超过，拆成 2 段

### 字段 2：[起幅]

**格式**：`[起幅]: {特写/近景} 起幅，{起始画面描述}`

**目的**：锁定第一帧画面——决定镜头从哪儿开始

**示例**：
- `[起幅]: 特写起幅，一枚老旧工牌斜放在木桌上，编号 0012 模糊可见`
- `[起幅]: 近景起幅，@林远 站在雨中，背对镜头，雨衣帽遮住半脸`
- `[起幅]: 中景起幅，@林小满 站在图书馆窗前，手中捧着一本深棕色日记本`

### 字段 3：[景别]

**8 种景别速查**：

| 景别 | 适用 | 情绪密度 |
|------|------|----------|
| 特写 | 道具 / 微表情 / 关键文字 | 高 |
| 近景 | 面部情绪 / 对话起点 | 高 |
| 中近景 | 半身对话 | 中 |
| 中景 | 多人对话 / 动作开始 | 中 |
| 过肩中景 | 对话经典（镜头在一方肩上） | 中 |
| 双人中景 | 双人互动 | 中 |
| 全景 | 角色全身 + 环境 | 低 |
| 远景 | 大场景 / 开场 / 收尾 | 低 |

**景别分布经验**（单集 13-18 个镜头）：
- 特写：30-40%（聚焦情绪与道具）
- 中近景 / 中景：40-50%（对话主体）
- 全景 / 远景：10-20%（空间定位）

### 字段 4：[运镜]

**8 种核心运镜**：

| 运镜 | 描述 | 适用场景 |
|------|------|---------|
| 镜头固定 | 完全不动 | 对话、揭示瞬间 |
| 镜头缓慢下摇 | 从上往下移动 | 揭示地面 / 物件 |
| 镜头拉远 | 镜头后退，画面变广 | 收尾 / 揭示空间感 |
| 镜头跟随 | 镜头跟着角色移动 | 角色走路 / 追逐 |
| 镜头推近 | 镜头前进，画面收紧 | 揭示 / 情绪升级 |
| 镜头微微前推 | 慢速推近 | 情绪酝酿 |
| 镜头快速上拉 | 从下往上急拉 | 揭示高空 / 跳切 |
| 镜头向右/左横移 | 水平扫过 | 揭示广景 / 时间流逝 |

**风格特化运镜偏好**：

| 风格 | 偏好运镜 |
|------|---------|
| 真人电影 | 镜头固定 / 镜头跟随 / 镜头缓慢下摇 |
| 3D 风格化 | 镜头跟随 / 镜头拉远 / 镜头微微前推 |
| 2D 动画 | 镜头推近 / 镜头快速上拉 / 镜头向右横移 |

### 字段 5：[角色@]

**格式**：`[角色@]: @{角色名}`

**必填字段**——每个镜头必须显式引用出现的角色（从资产库）

**示例**：
- `[角色@]: @林远`
- `[角色@]: @林远, @林近（双人中景对话）`
- `[角色@]: 无（空镜）`

### 字段 6：[场景@]

**格式**：`[场景@]: @{场景名}`

**必填字段**——每个镜头必须显式引用所在场景

**示例**：
- `[场景@]: @古董店`
- `[场景@]: @地下密室`
- `[场景@]: @天台`

### 字段 7：[动作]

**格式**：`[动作]: {动词} + {细节}`

**动词必须精确**：

| 类别 | 动词库 |
|------|--------|
| 走/移动 | 走入 / 踏入 / 踱步 / 缓步 / 疾步 / 奔向 |
| 看/视线 | 凝视 / 瞥见 / 注视 / 打量 / 凝视远方 |
| 手部 | 攥紧 / 握拳 / 颤抖 / 轻抚 / 摆弄 / 翻转 |
| 面部 | 皱眉 / 咬唇 / 嘴角微扬 / 眼眶泛红 |
| 物件 | 撬开 / 撕碎 / 举起 / 捧起 / 砸向 |

**示例**：
- `[动作]: @林远 快步走入密室中央，蹲下，指尖颤抖着触碰地面的铁锁`
- `[动作]: @林小满 捧起日记本翻到空白页，咬唇犹豫`

### 字段 8：[转场]

**5 种转场类型**：

| 转场 | 描述 | 适用 |
|------|------|------|
| 叠画 | 两个镜头叠加过渡 | 时间流逝 / 回忆 |
| 水波纹幻觉 | 画面如水波荡漾 | 梦境 / 幻觉 |
| 横移重组 | 画面横向滑过重组 | 跳切 / 场景切换 |
| 闪白 | 一瞬纯白过渡 | 强情绪冲击 |
| 淡入淡出 | 渐黑 / 渐显 | 收尾 / 开场 |

**风格特化**：

| 风格 | 偏好转场 |
|------|---------|
| 悬疑电影 | 叠画（回忆）/ 闪白（冲击）/ 淡入淡出（结尾） |
| 3D 风格化 | 横移重组（场景切换） |
| 2D 动画 | 水波纹幻觉（情感波动） |

### 字段 9：[表情]

**格式**：`[表情]: {情绪关键词}`

**情绪词库**：

| 类别 | 词库 |
|------|------|
| 积极 | 嘴角挂着自信的微笑 / 满脸陶醉 / 眉开眼笑 / 眼底含光 |
| 中性 | 神色凝重 / 神色平静 / 面无表情 / 眉头微蹙 |
| 消极 | 神色惊惶 / 满脸泪水 / 瞳孔收缩 / 咬紧牙关 / 眼眶泛红 |
| 戏剧 | 神色狰狞 / 眼神空洞 / 嘴角疯狂上扬 / 双眼猩红 |

### 字段 10：[对白]

**格式**：`[对白]: "{台词原文}"`

**约束**：
- **每个镜头对白不超过 1-2 句**（保证 4-15s 内能说完）
- 中文必须带**双引号**
- 长台词**拆 2 个镜头**——一个开嘴说，一个收嘴说

### 字段 11：[音效/声]

**格式**：`[音效/声]: {声音描述}`

**音效词库**：

| 类别 | 词库 |
|------|------|
| 物件声 | 滋啦一声热油泼在葱花上 / 刀刃起落声 / 纸张翻页声 / 钥匙插入锁孔 |
| 环境声 | 暴雨敲击屋檐 / 远处警笛长鸣 / 寂静得只有钟表滴答 |
| 心理声 | 内心独白：... / 内心 BGM 响起 / 旁白：... |
| 警示声 | 电流短路 / 玻璃碎裂 / 门被猛然踹开 |

**约束**：
- 真人电影风格 → 偶有
- 3D 风格化 → 偶有
- 2D 动画 → 显式（"内心 BGM 响起"是 2D 动画标志）

### 字段 12：[色调/光线]

**格式**：`[色调/光线]: {光线方向} + {色调}`

**光线方向库**：
- 逆光 / 侧光 / 顶光 / 底光 / 顺光 / 暮色 / 雨夜微光

**色调库**：
- 蓝橙色调 / 暖黄色调 / 冷灰低饱和 / 高饱和 / 暖白高调柔光 / 苍白色调

**示例**：
- `[色调/光线]: 逆光从大门射入 + 画面色调变黄`
- `[色调/光线]: 侧光 + 蓝橙色调（teal & orange）`
- `[色调/光线]: 暮色雨夜 + 冷灰低饱和`

### 字段 13：[落幅]

**格式**：`[落幅]: 落幅在{画面描述}上`

**目的**：锁定最后一帧——决定镜头停在哪儿

**示例**：
- `[落幅]: 落幅在 @林远 因愤怒而微微颤抖的嘴唇上`
- `[落幅]: 落幅在 @匿名信 那张三十年前的旧照片上`
- `[落幅]: 落幅在 @阳春面 袅袅升起的热气上`

## Part 3：跨镜头的视觉连贯策略

### 3.1 镜头连续性原则

**轴线规则（180 度规则）**：
- 同一场景中，摄像机始终在轴线一侧——避免"跳轴"造成观众空间感混乱
- 对话镜头轴线：两人连线的 180 度一侧
- 运动镜头轴线：运动方向的 180 度一侧

### 3.2 节奏控制（单集内）

| 时段 | 节奏 | 镜头密度 |
|------|------|----------|
| 开场（建置） | 慢 | 1-2 镜头 / 5-7 秒 |
| 中段（冲突） | 中 | 3-4 镜头 / 4-6 秒 |
| 高潮（对决） | 快 | 5-6 镜头 / 3-4 秒 |
| 收尾（钩子） | 慢 | 1-2 镜头 / 6-8 秒 |

### 3.3 跨集视觉一致性

**3 道防线**：
1. **资产库锁定**（pre-production.md）：所有角色/道具/场景先出资产图
2. **prompt 中显式引用资产**：`@角色名` / `@场景名` / `@道具名`
3. **光线色调绑定**：同一集内主色调一致，跨集允许微调但大方向统一

### 3.4 特殊镜头类型的处理

**闪回镜头**：
- 转场用"叠画"
- 色调刻意变旧/泛黄/褪色
- 标注括号注：`（回忆：三年前）`

**梦境/幻觉镜头**：
- 转场用"水波纹幻觉"
- 色调刻意失真/过饱和
- 音效明显区别（钟表倒转、风声扭曲）

**对话镜头**（最常见）：
- 默认用过肩中景 + 反打中近景
- 两人对话用对切镜头：a 过肩 → b 中近 → a 过肩 → b 中近
- 节奏 4-6 秒/个，长对话拆 5-8 个镜头

## Part 4：视频生成提示词的失败模式

### 失败 1：prompt 模糊导致模型自由发挥

❌ 错误：`画面是林远走进密室，表情凝重`
✅ 正确：12 字段全部填齐（运镜/景别/光线/落幅）

### 失败 2：把 5+ 个动作塞进一个镜头

❌ 错误：`林远走入密室 → 蹲下 → 撬锁 → 拾起工牌 → 转身离开`
✅ 正确：拆 3 个镜头（走入 / 撬锁 / 拾起）

### 失败 3：prompt 描述"内心感受"而非"画面"

❌ 错误：`林远感到非常悲伤`
✅ 正确：`[表情]: 眼眶泛红，咬紧嘴唇` + `[音效/声]: 内心独白：...`

### 失败 4：prompt 用真实演员名字

❌ 错误：`@林远 像梁朝伟`
✅ 正确：只描述外形特征，不引用真实演员

### 失败 5：缺落幅导致镜头"漂"

❌ 错误：12 字段里没有落幅
✅ 正确：每个镜头必含 `[落幅]: 落幅在...的画面上`

### 失败 6：把对白塞超过 2 句

❌ 错误：4 句话全堆在一个镜头里（4-15s 说不完）
✅ 正确：拆 2 个镜头，每个 1-2 句

### 失败 7：转场不规范

❌ 错误：`转场：自然过渡`
✅ 正确：`转场：叠画` 或 `转场：闪白`（从 5 种标准转场里选）

### 失败 8：光线描述缺方向

❌ 错误：`光线很暗`
✅ 正确：`侧光 + 蓝橙色调 + 阴影深重`

### 失败 9：场景引用不一致

❌ 错误：第 1 集用"@古董店"，第 5 集用"@林远古董店"
✅ 正确：所有集统一 `@古董店`——资产库引用名要锁定

### 失败 10：忽略视频时长上限

❌ 错误：单段视频 15 秒（超过 agnes-video-2.5-flash 12s 上限）
✅ 正确：单段 ≤ 12s；长时长拆 2 段
