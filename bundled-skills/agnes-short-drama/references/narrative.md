# AI 短剧叙事模型与设定公式

> 本文件是 SKILL.md Phase 2/3 的知识库。**何时读**：生成世界观、角色、剧情概要、集标题之前。

## 一、4 种 AI 短剧叙事模型

### 模型 A：悬念递进型（Mystery Escalation）

**适用题材**：悬疑、推理、惊悚、犯罪、心理
**核心机制**：每集揭开一层真相，但暴露更深一层秘密；观众永远处于"已知-未知-想知道"循环

**结构公式**：
```
第 1 集：钩子（异常事件/失踪/死亡）
   ↓
第 2-N-1 集：碎片证据（每集一个线索 + 一个误导）
   ↓
第 N 集：真相大白 + 反转（必含"表里不一"揭露）
```

**时间限制**：核心事件必有时限（"三日破案"/"七日失踪"）

**集标题公式**：`{场景/意象} + {事件转折}`
- 例：雨夜残局与旧影 / 照片中的旧影 / 警局内的博弈 / 废弃工厂里的暗门 / 旧日工牌的真相

**剧本特征**：
- △ 高密度（每段 3-5 个）
- 闪回/转场频繁（场景后括号标"回忆：X年前"）
- 内心独白罕见（只露在表情）
- 音效/光影提示多（电流声、警笛、阴影）

**代表样本**：雾城迷踪（10 集）、暴雨夜的回声（5 集）

### 模型 B：冲突升级型（Conflict Escalation）

**适用题材**：情感、校园、家庭、职场、商战
**核心机制**：每集主角处境更艰难；反派/对手一次比一次狠；观众处于"被压迫-期待反抗"循环

**结构公式**：
```
第 1 集：初始冲突（建立人物 + 矛盾）
   ↓
第 2-N-1 集：冲突升级（每次反派加码，主角暂时吃亏）
   ↓
第 N 集：彻底决裂/和好/反转
```

**时间限制**：通常无明显时限，靠"持续累积压力"驱动

**集标题公式**：`{人性观察} + {冲突阶段}`
- 例：两面三刀的舍友 / 怀疑的种子 / 伪装下的真面目 / 恶人先告状 / 真相大白与决裂

**剧本特征**：
- △ 中等密度
- 对白密度高（情感冲突靠对话）
- 道具频繁（关键证物）
- 内心独白中等

**代表样本**：绿茶舍友的现形记（5 集）

### 模型 C：爽点连发型（Power Climax）

**适用题材**：穿越、逆袭、霸总、玄幻爽文、重生复仇
**核心机制**：每集一个"打脸"/"获胜"/"反杀"事件；观众处于"压抑-打脸-爽"循环

**结构公式**：
```
第 1 集：开局地狱难度（主人公处于最低谷）
   ↓
第 2-N-1 集：每次"打脸"（小反派→中反派→大反派逐级升级）
   ↓
第 N 集：终极对决 + 大胜利（伴随身世/真相揭露）
```

**时间限制**：常含具体天数（"二两银子三天还清"）

**集标题公式**：`{事件} + {胜利}` 或 `{菜名/动作} + {戏剧冲突}`
- 例：首单阳春面 / 葱油面的对决 / 油泼面破局 / 逼债封店 / 声名鹊起

**剧本特征**：
- △ 高密度（特别在动作/食物镜头）
- 道具频繁（菜名、票据、契约）
- 内心独白显式（"内心独白：开局地狱难度？正好..."）
- BGM/蒙太奇提示多（"【快剪蒙太奇，配轻快国风BGM】"）

**代表样本**：小满面馆（5 集）

### 模型 D：成长日记型（Growth Diary）

**适用题材**：青春、治愈、奇幻校园、跨时空沟通
**核心机制**：每集一次内心蜕变；情感积累型；观众处于"陪伴-共情-期待成长"循环

**结构公式**：
```
第 1 集：起点（主角处于迷茫/封闭状态）
   ↓
第 2-N-1 集：每次小事件触发内心变化（被动接受→主动尝试）
   ↓
第 N 集：突破（关键选择 + 新自我确立）
```

**时间限制**：常含具体日期（"三天后的天台告白截止日"）

**集标题公式**：`{心境} + {蜕变}`
- 例（待补）：模糊的勇气 / 一封未寄出的信 / 雨中的等待 / 告白的练习 / 你做到了

**剧本特征**：
- △ 高密度（配合心理独白）
- 内心独白频繁（独白框式："内心独白：...")
- 旁白/物件独白（"日记：..."）
- BGM 显式（"内心 BGM 响起"）

**代表样本**：十年后的回信（5 集，AI 生成元数据 + 待生成集标题）

## 二、世界观设定公式

**统一格式**：
```
{时间} + {地域/空间} + {主要场景列表（2-4 个）} + {社会/科技/时代背景} + {冲突基调}
```

**模板**：
```
故事发生在{时间}的{地域}，主要场景为{场景 1}、{场景 2}、{场景 3}，
社会背景为{背景}，{冲突基调}。
```

**示例对照**：

| 题材 | 示例 |
|------|------|
| 现代悬疑 | 故事发生在当代一座旧城区，主要场景为古董店、废弃工厂及地下密室，社会背景围绕城市变迁中隐藏的历史秘密与人性黑暗面。 |
| 都市奇幻 | 当代高中校园，主要场景为图书馆、教室与天台，社会背景为青春期成长与奇幻日记介入。 |
| 仙侠玄幻 | 故事发生在修仙世界的青云古刹，这里既是清修之地也是封印魔尊的枢纽，时间处于魔族复苏的动荡前夜。 |
| 古代市井 | 架空古代南方县城老街，主要在充满市井烟火气的林家面馆、厨房灶台和街边堂食区展开故事。 |
| 都市刑侦 | 当代都市，主要场景为阴雨连绵的老旧街区、警局与地下实验室。社会背景为科技高度发展但人性冷漠，记忆操控技术处于灰色地带。 |

## 三、角色设定公式

**每角色 2-3 行格式**：
```
{姓名} {身份/职业}，{核心性格}，{关键特征}。{核心动机是X}，{成长弧/阻碍是Y}。
```

**4 条铁律**：

### 铁律 1：3 个角色是黄金数
- **主角**（必须）
- **对手/盟友**（必有张力）
- **辅助/反派/信物**（必备转折点）

### 铁律 2：至少一个"表里不一"角色
身份反转是 AI 短剧的高频套路：
- 古刹剑魂的玄慈住持（表面慈悲庄严，实则野心勃勃）
- 雾城迷踪的陈局长（表面公事公办实则暗中施压）
- 暴雨夜的林远父亲（囚禁儿子 30 年）
- 绿茶舍友的周妍（装柔弱实则心机）

### 铁律 3：角色描述必带"核心动机"和"成长弧"
- 核心动机示例："揭开真相并找回兄弟" / "完成告白并理解日记真相"
- 成长弧示例："从酗酒落魄到揭开真相" / "从内向逃避到直面未来"

### 铁律 4：物件可当角色
- 十年后的回信：日记本（会说话的信物）
- 雾城迷踪：净室标识、工牌、徽章
- 小满面馆：欠条、阳春面、铜板

**扩展非人实体维度**：当剧情核心驱动是非人实体时，把它列为"角色"。

## 四、剧情概要公式

**4-6 句结构**：
```
{开场钩子（场景+时间锚点）} →
{核心冲突（含时间限制）} →
{升级事件} →
{关键转折（必含"表里不一"揭露）} →
{高潮对决} →
{结局钩子（开放/留疑）}
```

**关键句式模式**：

| 步骤 | 句式 | 示例 |
|------|------|------|
| 开场钩子 | `{时间}，{主人公}{动作}{关键物件/事件}` | 暴雨夜，古董店老板林远收到匿名信... |
| 核心冲突 | `他必须{时限内}做{X}，否则{严重后果}` | 若不立刻重塑灵根，魔尊将在三日内破封... |
| 升级事件 | `{调查/行动}过程中，{新发现}` | 发现近年来多起离奇失踪案... |
| 关键转折 | `真相是{X}，幕后黑手竟是{Y}` | 幕后黑手现身，竟是林远以为早已去世的父亲 |
| 高潮对决 | `{最终事件}{解决方式}` | 兄弟俩合力制服父亲，真相大白 |
| 结局钩子 | `开放/留疑结尾` | 暴雨停止，阳光照进地下室...旧城黑暗消散 |

## 五、6 集以上短剧的"中段防塌"策略

**5 集结构**（推荐起点）：
```
第 1 集：建置（角色 + 世界 + 钩子）
第 2 集：第一次冲突（小反派）
第 3 集：升级 + 关键线索
第 4 集：高潮前夜（最大压力）
第 5 集：高潮 + 收束
```

**10 集结构**：
```
第 1 集：建置 + 主线钩子
第 2 集：第一层真相碎片
第 3 集：第二层真相碎片 + 误入歧途
第 4 集：核心地点首次进入
第 5 集：人物关系重置（关键揭示）
第 6 集：高潮前夜（最大压力）
第 7 集：体制/盟友的阻力
第 8 集：迷雾突破（真相 80% 揭露）
第 9 集：高潮对决
第 10 集：余波 + 开放钩子
```

**中段塌方检测信号**（出现任一即需调整）：
- 第 N-1 集与第 N 集张力相同（无升级）
- 同一"地点"反复出现（缺空间扩展）
- 反派动机始终单一（缺层次）
- 主角无内心变化（缺成长弧）

## 六、风格对叙事模型的反向约束

| 风格层级 | 适合的叙事模型 | 不适合的叙事模型 |
|---------|--------------|----------------|
| 真人电影 | 悬念递进 / 冲突升级 / 成长日记 | 爽点连发（视觉风格太严肃） |
| 3D 风格化 | 爽点连发 / 仙侠悬念递进 | 现实题材成长日记 |
| 2D 动画 | 成长日记 / 校园冲突升级 | 重工业题材悬念递进 |

> 选风格时同步选叙事模型，避免"古风 3D + 现代都市刑侦"的违和组合。
