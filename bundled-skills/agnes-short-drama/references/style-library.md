# Agnes 短剧风格库（60+ 模板）

> 本文件是 SKILL.md Phase 1/4 的知识库。**何时读**：用户选择风格时。

## 核心概念：风格 = 视觉 + 镜头 + 剧本 + 情绪 四维耦合

Pavo 风格库的"风格"**不只是滤镜**，它同时约束：

1. **视觉美学**（色调/光线/景别偏好）
2. **镜头语言**（运镜节奏/景别分布）
3. **剧本语法**（是否含蒙太奇标注、内心独白、转场提示）
4. **情绪密度**（每分钟情感转折数）

**举例**：
- "悬疑电影风格"= 蓝橙色调 + 缓慢推近镜头 + 闪回/转场密集 + 情绪克制
- "3D 古风国漫"= 国风色系 + 长镜头飘逸运镜 + 偶尔蒙太奇 + 情绪释放
- "二次元动漫"= 高饱和 + 夸张运镜 + 大量内心独白 + 情绪起伏大

## 七、自定义风格（user-custom）

Pavo 风格库支持"自定义风格"——用户可输入自己的风格描述。此时：
1. AI 必须先**复述一遍风格描述**，让用户确认理解一致
2. 基于该描述选择最接近的风格锚定词组合
3. 标注"自定义风格"标识，便于后续追溯
