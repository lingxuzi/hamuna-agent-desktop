# AI 短剧资产库生成框架

> **核心使命**：分集剧本定稿后、出分镜关键帧之前，先生成一套**视觉资产图**——为后续所有镜头锁定"人、物、景"的视觉基准。
> **本质**：资产图 = 短剧的"选角 + 置景 + 道具定妆"。微短剧跨多集、跨多镜，视觉一致性是最高优先级——资产图就是这一致性的"单一权威"。

---

## Part 1：资产规划——从分集剧本到资产清单

> 拿到 N 集剧本后，不要急着逐镜出图。扫一遍所有集，问三个问题：

### 问题一：谁出镜？

- **主角 + 配角 + 反派** → **必须做角色资产图**
- **物件 / 信物**（日记、剑、欠条、徽章、面碗） → 判断是否需要道具资产图
- **场景**（古董店、地下密室、面馆厨房、青云古刹、天台） → 每个独立场景做场景资产图

### 问题二：哪个角色必出？

| 规则 | 处理 |
|------|------|
| 戏份跨 ≥ 3 集的常驻角色 | ✅ 必须做角色资产图 |
| 仅在 1 集出现的次要人物 | ⚠️ 可省略，prompt 中文字描述 |
| 反派/对手 | ✅ 必须做（必含"表里不一"切换状态） |
| 信物（会说话的日记 / 灵剑 / 工牌） | ✅ 必须做（视觉锚定） |
| 群像（路人、警察、邻里） | ❌ 不做，文字描述即可 |

### 问题三：场景重复用吗？

| 规则 | 处理 |
|------|------|
| 同一场景跨多集反复出现 | ✅ 必须做场景资产图 |
| 单集独占的临时空间 | ⚠️ 可省略，prompt 中文字描述 |
| 关键记忆/闪回空间 | ✅ 必须做（场景跨度大，防止视觉漂移） |
| 移动空间（过道、街道） | ❌ 不做，prompt 中文字描述 |

### 资产清单产出顺序

```
① 角色资产图（人物是短剧的灵魂——所有情感都来自"人"）
② 道具资产图（关键信物锁定——后续镜头反复出现的物件）
③ 场景资产图（最后一个独立生成，色调跟资产图协调）
```

## Part 2：三种资产的定义

### 2.1 角色资产图

**目的**：锁定角色外观、年龄、服装、姿态。后续所有镜头都引用此图保持角色一致性。

**生成数量（每个核心角色）**：
- 全身正面（默认）
- 中近景（对话镜头）
- 状态切换（日常 / 战斗 / 受伤 / 流泪）——仅当角色跨状态时

**Prompt 模板**：
```
{风格锚定词}风格，{角色名}，{身份}，{年龄段}，
{核心服装描述}，{关键道具}，{标志性姿态/表情}，
{场景背景描述}，{光线}，{镜头景别}。
```

**示例（来自暴雨夜的回声 / 林远）**：
```
悬疑电影风格，林远，45岁古董店老板，
深灰色羊绒大衣，胸口别着银色怀表链，表情沉稳但眼底有疲惫，
站在布满旧物的古董店中，逆光从雨夜窗户射入，
中近景，特写面部，电影质感，蓝橙对比色调。
```

**示例（来自古刹剑魂 / 青梧）**：
```
3D古风国漫风格，青梧，18岁剑修少女，
飘逸月白长裙，腰系青玉剑穗，神色隐忍，眉心有一点朱砂痣，
立于古刹前殿石阶，背景为朱红古柱与袅袅檀烟，
全身正面，长镜头，国风色系。
```

**示例（来自十年后的回信 / 林小满）**：
```
二次元动漫风格，林小满，16岁内向高中女生，
深蓝色校服，黑色长发及肩，怀抱一本深棕色日记本，表情略显怯懦，
站在图书馆木制书架前，樱花飘落，
中近景，特写，日系二次元，大眼萌系。
```

**关键约束**：
- 角色资产图必须是 **1:1 或 3:4 比例**（不要 9:16，留给视频镜头的比例空间）
- 资产图风格锚定词必须与 SKILL.md Phase 1 用户选择的风格**完全一致**
- **不可省略"关键道具"**——角色身上的物件是后续镜头的视觉锚点

### 2.2 道具资产图

**目的**：锁定关键物件的外观、材质、纹理。物件在多集剧情中反复出现时，必须有视觉锚点。

**生成数量（每个核心道具）**：
- 1 张特写（默认）——包含材质、光泽、纹理
- 1 张使用状态（可选）——手持 / 摆放 / 与角色同框

**Prompt 模板**：
```
{风格锚定词}风格，{道具名}，{材质}，{尺寸/比例}，
{细节描述（磨损/光泽/纹理/铭文）}，{光线}，{背景纯色或模糊场景}。
```

**示例（来自十年后的回信 / 日记本）**：
```
二次元动漫风格，一本深棕色日记本，皮质封面，A5 尺寸，
封面右下角有烫金"LXM"字样，纸张微黄陈旧，
暖色台灯侧光，背景虚化为图书馆桌面。
```

**示例（来自小满面馆 / 阳春面碗）**：
```
真人古风写实风格，一碗阳春面，
白瓷碗，面条金黄透亮，葱花翠绿点缀，汤色清澈见底，
侧光特写，热气微微升起，背景虚化为古旧木桌。
```

**示例（来自雾城迷踪 / 旧工牌）**：
```
悬疑电影风格，一张泛黄的旧工牌，
塑料材质，蓝色边框，白底黑字，印有"雾城第七研究所 编号 0012"，
冷光侧打，胶片质感，背景纯黑。
```

**关键约束**：
- 道具资产图优先 **1:1** 比例（特写质感清晰）
- 不可省略"尺寸/比例"——后续镜头尺寸感知的统一基准
- 包含至少一个**可识别的视觉特征**（铭文、Logo、特殊纹理）——跨镜头一致性搜索的 hook
- **风格强化**（已验证必要）：道具特写易被 agnes 自动降级为写实质感。如风格为 2D 动漫，需在 prompt 追加 `(style: anime lineart, 2D illustration, avoid photorealistic textures)` ——端到端测试观察：仅"二次元动漫风格"被解读为接近写实插画，需显式锁定线稿/2D

### 2.3 场景资产图

**目的**：锁定场景的空间感、光影基调、色温。多个镜头同一空间必须从同一张资产图派生。

**生成数量（每个核心场景）**：
- 1 张广角空镜（默认）——无人物，纯场景
- 1 张光照变体（可选）——昼夜 / 雨晴 / 季节切换

**Prompt 模板**：
```
{风格锚定词}风格，{场景名}，{时间}，{地点}，
{空间描述（环境/陈设/装饰）}，{光线方向}，{色调}，{氛围}。
无人物。
```

**示例（来自暴雨夜的回声 / 旧城区地下密室）**：
```
悬疑电影风格，地下密室，黄昏，废弃工厂地下二层，
斑驳水泥墙，铁制锈门，一盏昏黄吊灯摇曳，阴影深重，
侧光，蓝橙色调，胶片质感。无人物。
```

**示例（来自古刹剑魂 / 青云古刹前殿）**：
```
3D古风国漫风格，青云古刹前殿，清晨，山顶云雾中，
朱红古柱巍峨，金顶铜瓦闪耀，袅袅檀烟缭绕，
晨光斜射，国风色系，工笔线条。无人物。
```

**示例（来自十年后的回信 / 天台）**：
```
二次元动漫风格，高中学校天台，黄昏，夕阳西下，
水泥护栏，远处城市天际线，樱花花瓣随风吹散，
暖色夕阳光线，高饱和度。无人物。
```

**关键约束**：
- 场景资产图优先 **16:9 或 1:1** 比例（广角视野）
- **明确标注"无人物"**——防止后续误用为含人镜头
- **反面词强化**（已验证必要）：在 prompt 末尾追加 `no people, no characters, no humans, empty scene`——agns 对中文"无人物"易忽略，显式英文反面词才能稳住空镜（端到端测试观察：仅"无人物"被模型忽略，加英文反面词后通过）
- 不可省略"光线方向"和"色调"——这是后续镜头派生时的视觉基准

## Part 3：资产图生成的工作流

### 3.1 生成顺序与依赖

```
步骤 ① 角色资产图（独立）
步骤 ② 道具资产图（可与 ① 并行）
步骤 ③ 场景资产图（在 ①② 之后——色调需要协调）
```

### 3.2 参考图（reference 模式）应用

**agines-image-2.5-flash 支持 reference 模式**，可用于：
- 角色三视图 → 用全身正面作为参考，生成中近景 / 状态切换
- 道具 → 用特写作为参考，生成使用状态
- 场景 → 用广角作为参考，生成光照变体

**reference 模式工作流**：
```
资产图 1（基线）
   ↓
[reference: <基线图>, prompt: <衍生描述>]
   ↓
资产图 2（衍生）
```

**关键约束**：
- reference 图不要超过 **3 张**（防止 prompt 语义干扰）
- 衍生 prompt 必须**保留风格锚定词**——避免 reference 把风格带跑

### 3.3 资产一致性维护

**视觉漂移检测信号**（出现任一即需重生成）：
- 角色面部/服装与角色资产图明显不一致
- 道具尺寸/材质在两镜头间不一致
- 场景光影色调在两镜头间不一致

**修正策略**：
| 不一致项 | 修正 |
|---------|------|
| 角色外观漂移 | 重生成角色资产图，再用 reference 模式重出受影响镜头 |
| 道具尺寸漂移 | 在 prompt 中显式标注"按资产图 @道具名 尺寸生成" |
| 场景光影漂移 | 在 prompt 中显式标注"沿用资产图 @场景名 光线方向" |

### 3.4 资产图的"@ 引用"机制

资产图一旦生成，必须用 `@角色名` / `@场景名` / `@道具名` 的引用形式写入分镜 prompt：

**示例**：
```
[角色@]: @林远 走入地下密室
[场景@]: @地下密室
[道具@]: @旧工牌 摆在桌面
```

**好处**：
1. 提示词语义锚定明确，模型跨镜头一致性高
2. 修改资产图 → 所有引用自动更新
3. 后期人员一眼能看出镜头用了哪些资产

## Part 4：常见错误与规避

### 错误 1：角色资产图省略关键道具

❌ 错误：林远的中近景资产图只画了大衣，没画怀表链
✅ 正确：每张角色资产图必含"标志性道具"——剧情反复出现的物件

### 错误 2：场景资产图混入人物

❌ 错误：地下密室场景图里有一个人剪影
✅ 正确：场景资产图显式标"无人物"——保证广角空镜纯度

### 错误 3：跨集的角色资产图风格漂移

❌ 错误：第 1 集林远资产图是暖色古风，第 3 集突变冷色现代
✅ 正确：同一角色跨所有集只生成**一套资产图**——后续镜头全靠 reference + 镜头级 prompt 微调

### 错误 4：道具资产图未含可识别特征

❌ 错误：日记本资产图只是一本棕色笔记本
✅ 正确：日记本资产图必须含"LXM"烫金字——后续镜头一致性搜索的 hook

### 错误 5：场景资产图比例错位

❌ 错误：天台场景图用 9:16 竖屏（变成只能看头顶）
✅ 正确：天台场景图用 16:9 横屏广角——保留天际线视野

### 错误 6：reference 模式同时塞 5+ 张资产图

❌ 错误：reference prompt 同时塞 角色 + 道具 + 场景 + 状态 + 备用 = 5 张
✅ 正确：reference 模式最多 **3 张**——超出模型会丢上下文或冲突

### 错误 7：把场景的色调"留白"给模型自由发挥

❌ 错误：场景资产图只写"古刹"，没指定光影色调
✅ 正确：场景资产图必含"光线方向 + 色调 + 氛围"——这是跨镜头一致的视觉契约

## Part 5：资产清单模板（输出格式）

```
=== 资产清单 ===

【角色】
  1. @林远
     - 数量：3 张（全身正面 / 中近景 / 受伤状态）
     - 风格锚定：悬疑电影风格
     - 关键道具：银色怀表链
     - 生成批次：Batch-1
  2. @林近（同上，略）
  3. @苏晴（同上，略）

【道具】
  1. @旧工牌
     - 数量：1 张特写
     - 风格锚定：悬疑电影风格
     - 关键特征：编号 0012
  2. @匿名信（同上，略）

【场景】
  1. @古董店
     - 数量：1 张广角
     - 风格锚定：悬疑电影风格
     - 光影基调：暖色侧光 + 阴影深重
  2. @地下密室（同上，略）
  3. @废弃工厂（同上，略）
```

> 资产清单生成后 → 必须等用户确认 → 才能进入 Phase 5 分镜。
