# 反懒惰合同

> 来源：director-agent/anti-laziness-contract + romance-design/Common-12-Section-Protocol，适配 TVC 场景。
> 触发时机：Phase 4 镜头表生成时、Phase 6 故事板编译时、Phase 9 提示词撰写时。

## 一、违禁词强制转译

以下词汇在 TVC 导演工作中**禁止直接使用**，必须立即转译为可执行的摄影/剪辑/声音决策：

| 违禁词 | 转译公式 | 示例 |
|--------|---------|------|
| cinematic / 电影感 | 具体机位+焦段+景深+快门 | "24mm、浅景深f/1.8、180°快门" |
| more tension / 更有张力 | 镜头运动+剪辑节奏+构图压迫感 | "沿Z轴匀速推镜3秒，中景至特写，前景遮挡" |
| richer emotion / 情感更丰富 | 具体微动作+光线变化+色彩温度 | "角色视线停顿0.5s，主光从45°转为正面平光" |
| director thinking / 导演思维 | 具体的场面调度决策 | "角色从画面右侧入，沿对角线走向中心，3s完成" |
| 高级感 / 质感 | 具体材质描述+光影比例 | "哑光不锈钢拉丝方向可见，高光占画面8%" |
| 氛围感 / 有氛围 | 具体声源+光源+色彩参数 | "低频设备嗡鸣40Hz，暖光2700K，饱和度降低15%" |
| 很压迫 / 很有冲击力 | 具体摄影参数 | "24mm广角、主体居中、逆光轮廓、前景遮挡、暗部60%" |
| 慢慢移动 | 具体速度+方向+时长 | "沿Z轴匀速推镜，中景至中近景，3秒" |
| 动态感 / 有动感 | 明确发力起点+路径+终点 | "角色从静止到加速，重心前倾，衣料滞后0.3s" |
| 精致 / 精美 | 具体材质细节+接触物理 | "玻璃杯壁冷凝水珠沿弧形滑下，折射环境光" |

**自检规则**：写完任意描述后，问自己——"一个冷静的摄影师能否直接执行这条指令？"如果不能，就是违禁词，必须重写。

## 二、假电影感补查

生成前检查以下假电影感模式，发现即修正：

- [ ] **无来源光**：画面有光但找不到光源（窗户/灯具/反射面）
- [ ] **滤镜代替色彩叙事**：用"暖色调""赛博朋克色"代替具体色温数值
- [ ] **无动机慢推**：镜头推进但没有叙事/情绪/信息动机
- [ ] **过度雾化**：画面整体泛白泛雾，看不清材质
- [ ] **过亮霓虹**：光源亮度超过场景合理范围，无衰减
- [ ] **无意义浅景深**：背景虚化没有叙事目的（如产品全片都是模糊背景）
- [ ] **导演姓名代替技术写法**：出现"诺兰式""韦斯·安德森式"等人名

## 三、通用材质与物理规则

以下模糊词禁止出现在镜头描述中，改用可执行参数：

| 模糊词（禁） | 可执行词（例） |
|-------------|---------------|
| 金属 | 哑光不锈钢、拉丝方向、边缘氧化、冷凝水 |
| 布料 | 经纬纹、缝线、压褶、磨损区、受力褶皱 |
| 地面 | 潮湿粗糙混凝土、积尘、擦痕、局部反射 |
| 纸张 | 哑光纤维、折痕、卷边、褪色 |
| 霓虹 | 可见灯管/招牌、局部染色、湿面反射 |

**禁止现象**（生成时自动拦截）：
- 手指或道具穿模
- 粘连/漂浮/无故增殖
- 方向反转（水往天上流等）
- 接触不受力（手放在桌上但没有压力褶皱）
- 光源与阴影方向冲突

## 四、尾帧连续性标准

每个镜头的"结束状态"必须包含以下 6 项，确保下一镜可无缝衔接：

```
尾帧 = 人物位置 + 姿态 + 道具最终状态 + 光源方向 + 背景锚点 + 下一镜入口
```

**示例**：
```
尾帧：主角右手持瓶立于画面右侧1/3处，身体微侧向左；
      瓶身标签朝前；主光从右上方45°入射，阴影投向左侧地面；
      背景台面左侧可见抽油烟机边缘；
      下一镜入口：镜头从右侧绕至正面，主角视线同步转向镜头方向。
```
