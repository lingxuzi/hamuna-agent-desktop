# 换机位空间硬规则

> 来源：ai-storyboard-director，适配 TVC 场景。
> 触发时机：Phase 4 镜头表生成前、Phase 6 故事板编译前。

## 核心原则

**世界状态固定，相机移动，画面投影必须重算。**

所有镜头共享同一张"世界地图"——地理锚点、角色位置、光源方向、环境动态一旦在 Phase 3 场景锚卡中确定，后续任何换机位都不改变这些事实。相机角度变化只影响观众看到的投影，不影响世界本身。

## 四条硬规则

### 1. 世界状态不变

建立一张固定世界地图，在 Phase 3 场景锚卡完成后写入：

```
世界地图（固定，后续所有镜头共享）：
- 地理锚点：[如"厨房台面沿东墙，冰箱在左后方"]
- 角色位置：[如"主角始终站在台面右侧，面向镜头方向"]
- 光源方向：[如"主光来自右上方窗户，色温 5600K"]
- 环境动态：[如"抽油烟机出风口持续向右吹轻雾"]
```

任何换机位镜头**不得改变**以上任意一项。

### 2. 画面投影必须重算

换机位后，以下四项必须逐项重新推导，不得复制上一镜：

| 检查项 | 问题 | 答案格式 |
|--------|------|---------|
| 左/右/中投影 | 角色/产品在当前机位下落在画面的哪个区域？ | "角色在画面右侧1/3，产品居中偏左" |
| 遮挡关系 | 当前机位下，哪些物体遮挡哪些物体？ | "前景：抽油烟机叶片遮挡30%画面顶部" |
| 光源方向 | 当前机位下，光从哪个方向入射？阴影指向哪里？ | "主光从左上方45°入射，阴影投向右侧地面" |
| 不该入镜的人/物 | 此机位下，哪些元素必须彻底出框？ | "冰箱门完全出框；右侧背景走廊不出现" |

### 3. 不该入镜的人必须彻底出框

换机位后，原画面中的某些角色或道具在新视角下可能进入画面——此时必须主动将它们排除：

- 明确的出框声明：`"左侧穿堂风区域无其他人物出现"`
- 禁止通过景深虚化"假装看不见"——虚化人物仍会被识别为人形
- 如果无法自然排除 → 换机位角度错误，退回重算

### 4. 光源按世界方向延续

光源方向是世界地图的一部分，换机位不改变光源位置，只改变光源在画面中的投影方向：

- 主光方向（如"右上方"）在所有机位下保持一致
- 阴影投射方向随之变化，但**不能翻转**（如前一镜阴影朝右，换机位后不能突然朝左）
- 允许的光源变化仅两种：时间推移（日落变暗）/ 场景切换（新空间）

## 执行格式

每个换机位镜头在镜头表中必须附带一段空间自检：

```
[镜N · 换机位自检]
世界锚点确认：与镜N-1 一致（地理/角色/光源/环境均无变化）
左/右/中投影：[填写]
遮挡关系：[填写]
光源投影：[填写]
必须出框元素：[填写]
```
