# 黏土白模故事板风格

> **规范速查**：本文件的提示词 + 参考图规范权威来源为 [`asset-prompting-cheatsheet.md`](../asset-prompting-cheatsheet.md)（§4 故事板图 + 自适应网格算法）。本文是展开版，cheatsheet 是速查表。

> 适用于所有 TVC 故事板生成（九宫格 / 单格详情图 / 最终拼接）。
> 触发时机：Phase 6 故事板编译前确认。

## 风格定义

**黏土白模**（Clay White Model）是一种预可视化风格，将所有视觉元素渲染为白色或米白色的雕塑质感模型——类似动画工业中常用的 white clay render。核心目的：**排除色彩干扰，专注构图、光影、空间关系和动作节奏**。

## 视觉参数

| 参数 | 值 |
|------|-----|
| 整体色调 | 纯白 / 米白 / 暖白（禁用彩色） |
| 材质质感 | 哑光黏土 / 石膏 / 素烧陶土 |
| 光源 | 单一主光（通常右上方45°），柔和阴影 |
| 背景 | 与主体同色或极浅灰白渐变 |
| 景深 | 适度景深，前后层次清晰可辨 |
| 高光 | 柔和高光点（模拟釉面微反光，非金属） |

## 必须遵守的规则

1. **全片白色调**：角色、产品、场景全部为白色/米白色雕塑体，不允许出现任何彩色（肤色、服装色、产品原色一律去掉）
2. **造型保留**：产品和角色的外形轮廓必须准确（通过参考图锚定），只改变材质表面为白模质感
3. **光影塑造形体**：用明确的明暗交界线表现体积，不用色彩表达情绪
4. **禁止**：彩色渲染、照片写实质感、卡通上色、3D 游戏渲染感、塑料光泽

## Agnes 提示词模板

```
黏土白模故事板风格，3行3列共9格，每个格子展示产品广告的关键镜头状态：
风格统一：所有元素均为白色哑光黏土雕塑质感，单一主光从右上方45°入射，柔和阴影塑造体积，纯白背景。
禁用色彩，禁用照片写实，禁用卡通上色。
格1(左-上, 0-Xs)：[景别·视角]：{镜头描述}，白模质感
格2(中-上, X-Ys)：[景别·视角]：{镜头描述}，白模质感
...
格9(右-下, Y-Zs)：[景别·视角]：{镜头描述}，白模质感
要求：白底干净布局，格子间有细线分隔，禁止出现镜号/数字/时间码/字幕/箭头/水印
```

## 单格详情图提示词（逐格输出时用）

```
[景别·视角]：{镜头描述}
风格：黏土白模预可视化，白色哑光雕塑质感，单一主光右上方45°，柔和体积阴影，纯白背景。
角色姿态：{精确姿态描述}
产品状态：{精确产品位置/状态描述}
光影：明暗交界线清晰，高光柔和，无彩色
```

## 参考案例描述词（可粘贴到 prompt 辅助风格锚定）

- `pre-vis clay model, monochrome white foam core style, clean studio lighting`
- `maquette white model, stop-motion pre-production still, no color, pure form`
