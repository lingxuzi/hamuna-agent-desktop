# 产品图锚定 — 多视角生成策略

> **规范速查**：本文件的提示词 + 参考图规范权威来源为 [`asset-prompting-cheatsheet.md`](../asset-prompting-cheatsheet.md)（§1 产品多角度资产图）。本文是展开版，cheatsheet 是速查表。

> **所有产品宣传视频必须上传产品参考图。** 产品参考图是后续所有 Agnes 生成保持产品外观一致性的唯一来源。核心目标：**让后续所有 Agnes 生成的产品帧与原始图片视觉一致**。

---

## 一、触发条件

- **产品宣传视频** → 必须上传（无例外）
- 用户明确上传了产品图片（URL 或本地路径）

未上传产品参考图时，**必须在 Phase 1 创意简报阶段主动追问**，不得以"无参考图用纯文字描述"替代。

---

## 二、Step 0：多视角生成（在创意草案之前执行）

收到产品参考图后，在输出任何创意内容前，先执行多视角生成。

### 2.1 工具选择

| 需求 | 推荐工具 | 理由 |
|------|---------|------|
| 直接基于原图生成多视角 | `mcp__multimedia-creator__agnes_image_edit` | 图生图，保留产品外观不变 |
| 从原图提取产品特征 + 全新生成 | `mcp__multimedia-creator__agnes_image_generate` | 适合需要重新渲染/换底色的场景 |

**默认用 `agnes_image_edit`**：原图作为 `image_paths`，prompt 描述需要的视角和背景变化。

### 2.2 Prompt 模板（agnes_image_edit）

```
基于这张产品图，生成一张产品 3×3 网格多视角 Turnaround 展示图。
9 个格子排列成 3 行 3 列，每个格子独立展示同一产品的不同视角：

第一行（正面视角）：
- 左格：正侧面（产品正对镜头，完整展示外观）
- 中格：正面全身（产品正对镜头，正面视角）
- 右格：右侧45度经典角度（展示产品立体感）

第二行（侧面视角）：
- 左格：左侧面全身
- 中格：正侧面全身（与第一行中区镜像对应）
- 右格：右侧面全身

第三行（背面+细节）：
- 左格：背面全身
- 中格：顶部俯视
- 右格：关键细节微距特写（产品最具辨识度的局部）

要求：白底影棚，统一侧光+轮廓光，所有格子光照一致。
保持产品外观、颜色、材质与参考图完全一致，不改变产品本身的设计。
商业摄影风格，8K 分辨率，干净背景，专业产品展示图。
```

### 2.3 特殊产品类型处理

| 产品类型 | 注意事项 | 特殊提示词调整 |
|---------|---------|--------------|
| 可穿戴产品（手表/首饰/鞋） | 需要展示佩戴效果 | 追加"展示佩戴效果的特写格" |
| 液体/食品 | 注意反光和透明质感 | 强调"玻璃/金属反光清晰，液体状态真实" |
| 电子产品 | 接口/按键/屏幕需清晰 | 强调"屏幕内容清晰，按键细节分明" |
| 服装/面料 | 纹理是关键 | 强调"面料纹理清晰可见，褶皱自然" |

### 2.4 输出

多视角图生成后，将其保存为 `(图1)` 引用——所有后续资产图（角色穿着产品、场景中的产品特写）都通过 `(图1)` 引用保持产品视觉一致。

---

## 三、多视角图在管线中的引用规则

### 3.1 引用格式

所有后续 Agnes 图片生成 prompt 中，产品相关内容统一使用 `(图1)` 指代多视角图：

```
...脚穿(图1)的同款白色跑鞋...
...手腕佩戴(图1)的银色手表...
...桌面上放置(图1)的香水瓶...
```

### 3.2 产品一致性铁律

- **不可用文字替代 `(图1)`**：所有产品出镜帧必须引用 `(图1)`
- **每格重复引用**：多格故事板中，每个画格的产品相关描述都必须重复写 `(图1)`，单次提及会被 AI 忽略
- **产品图生成失败**：若 `agnes_image_edit` 失败，重新生成一次；仍失败则告知用户并等待新图，不得降级为纯文字描述

---

## 四、与现有 Step 1-3 的衔接

```
Step 0：上传图片 → 多视角生成 → 确定(图1)
   ↓
Step 1：创意草案（分析产品图特征，推测画风/材质/配色）
   ↓
Step 2：画风确认 + 多视角图确认（用户确认产品图是否符合预期）
   ↓
Step 3：自动补全（全部产品出镜帧引用(图1)）
```

**关键**：Step 0 的多视角图是后续所有产品帧一致性的唯一来源。如果多视角图失败，整个产品视觉一致性链会断裂——因此 Step 0 必须优先执行，不得跳过。
