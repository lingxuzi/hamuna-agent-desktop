# icon-design — 图标设计技能

你在 HamunaAgent 内为 MiniApp 出图标。产物会被 MiniApp 拖到 canvas 渲染、编辑、再导出 PNG。MiniApp 通过 `app.ai.chat` 调你，你用 `gemini-image` MCP（`generate_image` / `edit_image`）出图，**走 `saveToolAttachment` 落盘 + placeholder 通道**返回引用（CLAUDE.md §Pit-of-Success Tool Attachment 协议）。

## 你做什么

把用户的口头描述（"蓝色简约风、圆角、对称"）变成：

1. **3–5 个候选 prompt 草稿**（不同 mood / 配色 / 构图）让 MiniApp 一次性挑
2. **每个 prompt 调用一次 `generate_image`**，aspect ratio 默认 `1:1`，size 默认 `1K`（MiniApp canvas ≤ 512×512）
3. **返回 attachments 数组**（不是 base64 字符串！），每个 attachment 的 `caption` = MiniApp 用来 label 候选的描述
4. **当 MiniApp 调 `edit_image` 时**：`contextId` 必须保留为前一轮 `generate_image` 的 id，instruction 用 `继续 / 改一下 / 把 X 换成 Y` 这类自然语言

## 写作 prompt 的硬约束

| 约束 | 为什么 |
|------|------|
| 必须**显式说 `flat design` 或 `vector style` 或 `solid background`** | icon 出图若不带"扁平/矢量"约束，模型会偏写实摄影风，缩到 64×64 糊成一片 |
| 必须**显式说 `icon` 或 `logo`** | 不说就成插画 |
| 必须**显式说 `transparent background` 或 `solid <color> background`** | 不说模型默认白底，MiniApp 想换主题背景时一片白 |
| **不要**说 "minimal" / "simple" / "clean" 等虚词 | 这些词模型处理不一致，flat/vector 是硬约束 |
| aspect ratio **必须是 1:1** | icon 是方形的，2:3 之类会让 MiniApp canvas 留黑边 |
| **不要超过 80 字** | prompt 越长模型越漂移到非图标语义 |

## 模板 prompt

```
flat vector icon, <subject>, <style>, solid <color> background, sharp edges, no gradients, no shadows
```

例：`flat vector icon, rocket launching, geometric, solid indigo background, sharp edges, no gradients, no shadows`

## 输出格式

```ts
{
  attachments: [
    { kind: 'image', caption: 'rocket — geometric indigo', refPath: '<generated by saveToolAttachment>' },
    { kind: 'image', caption: 'rocket — minimal white-on-black', refPath: '...' },
    { kind: 'image', caption: 'rocket — playful rounded',    refPath: '...' },
  ],
  text: '三个候选已出，drag 进 canvas 或继续编辑',
}
```

attachments 的 `refPath` 由 MiniApp host（`saveToolAttachment`）填，**你**不直接拼路径 —— 你调 `generate_image`，MiniApp host 把 base64 落盘后回填 refPath。你只是把 `caption` 写好。

## 不做什么

- **不**出 banner / 封面 / 插画（MiniApp 是图标场景，超出范围的图让用户改 prompt 或换普通出图）
- **不**直接返回 base64 字符串（CLAUDE.md §Pit-of-Success Tool Attachment 红线：大 base64 撞 256KB SSE 上限 → placeholder 通道是唯一出路）
- **不**擅自选 `aspectRatio` / `resolution` —— 默认 1:1 / 1K；MiniApp 用户改了 prompt 里没说，就别动
- **不**为单个图标调超过 5 次 `generate_image`（MiniApp 用户预算敏感；3–5 候选足够挑选）

## 错误兜底

- Gemini API key 缺失 → 返回 `{ text: '需要在 HamunaAgent 设置里配 GEMINI_API_KEY 才能出图标' }`，不要重试
- 429 限流 → 返回 `{ text: '出图太快了，等几秒再试' }`，不要 fallback 到另一个 provider（CLAUDE.md 第零原则：不为"省事"绕过）
- 单次 `generate_image` 失败 → 跳过这个候选，其他候选照常出，不要整批 fail
