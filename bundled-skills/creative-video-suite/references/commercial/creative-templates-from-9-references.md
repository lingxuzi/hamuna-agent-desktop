## 1. 模板详细

### 模板 #1 — 古风IP包装（一纸花约·冷泡茶）

**原型拉片要点**：
- 场景：军帐议事厅 / 案桌前 / 野外战场 / 营地阅兵场等6场景，全部古风化（无现代元素混入）
- 角色：武将（角色A）+ 士兵（角色B）+ 谋士（角色C）等，全部古装
- 产品植入：紫色蝴蝶花瓣图案 + 三色瓶身（紫/绿/黄）+ 同色包装盒 + 字幕"丢进去秒出汤"功能性台词
- 字幕风格：毛笔字/竖排古风字幕

**创意机制**：
- **反差套利**：用当代消费品的"工业感"对撞古代场景的"古朴感"，制造视觉新鲜感
- **多色系列 = 多场景分镜**：每个口味对应一个独立场景，避免单场景冗长
- **功能性台词代替品牌名**：让产品使用方法（"丢进去秒出汤"）成为台词本身，而不是旁白报品名

**复用条件**：
- ✅ 适合：食品 / 饮料 / 茶饮 / 日化（产品有≥2口味/颜色可对应多场景）
- ✅ 适合：品牌调性含"国潮"/"传统"/"古风"关键词
- ❌ 不适合：纯科技产品（强行古风会脱节）

**参数边界**：
- 时长：6-12 秒（古风场景切换需要时间）
- 场景数：3-6 个（每个场景对应一个口味/颜色）
- 角色数：2-4 人（小阵容古风戏）
- 字幕：必须用古风字体（如楷体/隶书），不能现代 sans-serif

**Cross-ref**：`references/commercial/corporate-business-video-ref.md §叙事母题与现实感`（古风=母题之一）

### 模板 #2 — 经典IP痛苦解救（vivo Y600Pro）

**原型拉片要点**：
- 场景：沙漠标题/沙海/雪山/火山/唐僧讲法/产品揭幕/沙僧解脱/飞越山海 8 场景
- 角色：唐僧/沙僧/悟空等取经路IP角色（vivo产品=解救工具）
- 产品植入：四级递进——对话提及 → 口播介绍 → 机身logo → 终幕书法口号
- 叙事弧：恶劣环境痛点（背囊重）→ 产品介入（vivo Y600Pro）→ 解脱/飞越山海

**创意机制**：
- **经典IP+痛点角色绑定**：用观众熟悉的IP角色自带叙事期待，再把当代痛点（充电/背重物）植入角色遭遇
- **四级递进植入**（**关键模式**）：让产品从"对话配角"升级到"视觉主角"，避免一次硬广让用户跳戏
- **恶劣环境→轻盈飞越的转折**：用强对比（沙海重负 vs 飞越山海）放大产品价值

**复用条件**：
- ✅ 适合：科技产品 / 出行装备 / 效率工具（产品本身=解救方案）
- ✅ 适合：品牌愿意借势经典IP（西游/三国/红楼/水浒等）
- ❌ 不适合：奢侈品类（借IP会拉低调性）/ IP授权费不可控

**参数边界**：
- 时长：8-12 秒（IP叙事需要铺垫）
- IP角色数：1-2 个主角（避免IP版权纠纷+叙事焦点）
- 递进级数：3-4 级（少=植入突兀，多=节奏拖）
- 转折镜头：必须 1 个强对比（黑暗→光明 / 沉重→轻盈）

**Cross-ref**：`references/commercial/product-marketing-ad-video-no-storyboard-ref.md §传播主线与创意巧思`（递进植入=核心方法之一）

### 模板 #3 — 都市倦怠+奇观逃离（一口乐事）

**原型拉片要点**：
- 场景：办公室（夜景）→ 青柠水乐园 → 麻辣小龙虾峡谷 → 火锅城 → 办公室（夕阳）4 大场景块
- 角色：林静怡（短发青年女性）同一角色 4 套装扮——白衬衫（办公室）/ 蓝裙+草帽（水乐园）/ 牛仔外套（小龙虾）/ 红中式短袖+丸子头（火锅城）
- 产品植入：3 袋乐事薯片分别对应 3 个奇观场景（橙色袋=水乐园烧烤味/红色袋=火锅麻辣锅味/蓝色袋=办公室青柠味），办公室桌面始终散落3袋作为静态道具
- 字幕："踏过青柠浪，通关夏日场"/"一城辣食，满口雄心"/"乐事薯片，一口即是远方"/"你值得片刻的出逃"

**创意机制**：
- **都市开场+奇观逃离+都市回归**：用真实工作场景建立共鸣（加班夜景），奇观作为心理逃离，终幕回归现实（夕阳办公室）+ 产品作为"出逃的载体"
- **同一角色换装承载多场景**：省角色介绍时间，让"穿越感"成为视觉叙事
- **口味 = 奇观场景**：让味觉（薯片口味）= 视觉（场景主题）的同构映射，观众自然记忆

**复用条件**：
- ✅ 适合：食品 / 饮料（产品有≥3口味/规格）
- ✅ 适合：目标人群=都市白领 / 学生（共鸣基础）
- ❌ 不适合：B端产品 / 工业品（缺乏"逃离"叙事基础）

**参数边界**：
- 时长：12 秒上限（多场景切换紧凑）
- 场景数：3-4 个奇观 + 2 个现实（开场+结尾）
- 角色数：1 主角色（承载所有场景）+ 极少配角
- 奇观类型：与产品口味一一对应（避免奇观/口味脱节）

**Cross-ref**：`references/commercial/ugc-talking-video-ref.md`（都市白领日常共鸣）

### 模板 #4 — 反转悬念式情感（小不礼·日子）

**原型拉片要点**：
- 场景：老式中式小面馆 / 面馆后厨 2 场景，反复切换 3-4 次
- 角色：服务员（角色A，举瓶问"点给谁的？"）+ 厨师（角色B，后厨受关心方）+ 顾客群演
- 产品植入：橙黄色饮料瓶（黄色瓶盖、透明瓶身、橙黄色液体）作为贯穿性叙事道具，无品牌特写，靠"举瓶"的视觉重心传递
- 叙事弧：服务员举瓶问顾客"点给谁的？"→ 顾客摇头 → 切换后厨厨师惊讶表情 → 循环 3-4 次 → 最后镜头揭示=送后厨闷声干活的厨师

**创意机制**：
- **反复设疑+最后揭示**：用反复的"点给谁的？"建立悬念，结尾揭示给最不显眼的人（闷声干活者），制造情感反转
- **无品牌特写+视觉重心传递**：让产品不抢戏，情感反转成为主角
- **真实场景+群演增强**：老式中式面馆+多排顾客低头进食，建立真实生活感

**复用条件**：
- ✅ 适合：节日情感营销（母亲节/教师节/护士节等"关心特定人群"场景）
- ✅ 适合：餐饮 / 服务类（产品+服务对象关系清晰）
- ❌ 不适合：科技/工业产品（情感反转不适用）

**参数边界**：
- 时长：12-30 秒（悬念需要铺垫时间，**超出 12s 边界**走 `long_video_stitch_mode`，详见 `references/agnes-ai-api.md §视频时长边界`）
- 切换次数：3-4 次（少=悬念不足，多=节奏拖）
- 揭示镜头：必须 1 个特写（揭示对象的表情/反应）

**Cross-ref**：`references/commercial/corporate-business-video-ref.md §叙事母题与现实感`（反转=情感母题）

### 模板 #5 — 拟人IP+冷暖反转（Lucas·洁柔纸巾）

**原型拉片要点**：
- 场景：雪山粉红房车 / 雪山雪地（兔子雪滑） / 木屋室内 / 雪山雪地（产品特写）4 场景
- 角色：白色拟人化兔子吉祥物（角色A，雪地雪滑载具=洁柔抽纸盒）+ 金发女性（角色B，木屋受寒→温暖弧线）
- 产品植入：品牌名"LOTION / 洁柔"出现 3 处（兔子脚下抽纸盒 / 室内边桌 / 雪面产品特写主视觉），品牌抽纸盒=兔子雪滑载具=IP与产品强绑定
- 冷暖弧线：冷蓝雪地 → 室内受寒（蓝调）→ 金色逆光特写（暖金）→ 雪面产品特写（冷暖对比收尾）

**创意机制**：
- **品牌IP拟人化**：用品牌吉祥物（兔子）=产品的载体，让 IP 与产品视觉绑定（兔子脚下就是产品）
- **冷暖反转=产品功能可视**：把抽象的"舒适/温暖"翻译成具体的色彩弧线（冷蓝→金色逆光），让产品=温暖载体
- **情绪绑定**：通过"寒冷→温暖"弧线，把产品（纸巾）与"舒适感/被照顾感"绑定

**复用条件**：
- ✅ 适合：日化 / 母婴 / 食品（产品需要情感+IP支撑）
- ✅ 适合：品牌已有吉祥物 / IP
- ❌ 不适合：B端 / 工业品（情感弧线不适用）

**参数边界**：
- 时长：12-22 秒（情绪弧线需要铺垫+转折+收尾）
- IP角色数：1 个吉祥物（强聚焦）
- 冷暖转折：必须 1 个金色逆光特写（暖色符号镜头）
- 收尾：雪面/户外产品特写必须 1 个（产品最终主角化）

**Cross-ref**：`references/commercial/corporate-business-video-ref.md §叙事母题与现实感`（冷暖=情感母题）

### 模板 #6 — 异族部落+神迹降临（暴风AIGC·容声冰箱）

**原型拉片要点**：
- 场景：沙漠部落营地 / 沙漠天空 / 沙漠地面（冰箱出现） / 沙漠营地（儿童欢庆）/ 沙漠村庄（黄昏）/ 冰箱内部特写 / 沙漠村庄（产品展示）9 场景
- 角色：部落长老 / 部落女性 / 部落男孩 / 部落小女孩 + 群演民众与孩童（深肤色、豹纹短裙、编织头带、串珠项链）
- 产品植入：五段递进——对比反差（沙漠干旱 vs 冰箱满载）→ 功能可视（食物涌出）→ 信任象征（孩童依偎睡眠）→ 反应镜头印证 → 品牌收束（书法"容聲冰箱"+"時光不敗 新鮮"）
- 叙事弧：部落求雨（痛点）→ 天降冰箱（神迹）→ 水果涌出（功能可视）→ 孩童依偎（信任）→ 内部特写（功能建立）→ 反应镜头 → 品牌收束

**创意机制**：
- **极致痛点→神迹降临**：把产品功能（保鲜/冷藏）包装成"神迹"，让产品=救赎
- **异族服装+异域场景**：用文化差异感（非洲部落+沙漠）建立"异世界感"，强化神迹的视觉冲击
- **五段递进植入**：比四级递进更系统，每段都强化产品价值的不同侧面

**复用条件**：
- ✅ 适合：家电 / 大件耐用品（产品功能=用户痛点的解决方案）
- ✅ 适合：品牌愿意做"叙事大片"调性
- ❌ 不适合：快消品（神迹调性太重，过度营销）

**参数边界**：
- 时长：15-30 秒（叙事大片需要铺垫，**超出 12s 走 long_video_stitch_mode**）
- 场景数：6-9 个（叙事大片需要多场景支撑）
- 角色数：3-5 个核心 + 多群演（建立"部落"感）
- 收尾书法：必须 1 个书法文字（建立"品牌调性"）

**Cross-ref**：`references/commercial/corporate-business-video-ref.md §叙事母题与现实感`（神迹=母题之一）

- **三句连续字幕收尾**：把产品功能翻译成品牌 slogan（"即醒的奇迹"），形成记忆点

**复用条件**：
- ✅ 适合：食品 / 饮料（产品原料可拟人化）
- ✅ 适合：品牌调性含"探险/发现/异域"关键词
- ❌ 不适合：纯科技产品（原料拟人不适用）

### 模板 #8 — 现实痛感+反复怼脸（心相印原生木浆）

**原型拉片要点**：
- 场景：沙漠 / 直播间室内 2 场景（强对比）
- 角色：沙漠中卡其衬衫男青年（角色A）/ 直播间白衣长发女主播（角色B）/ 直播间黑衣长发女主播（角色C）/ 拟人化雄狮（角色D）

- 价格口播梯度：19.9 4 箱 → 20 → 40 → 60 → 80 → 8 大箱（反复口播递进+纸箱堆叠同步递进）

**创意机制**：
- **拟人化受众=观众代入**：用拟人化狮子/受众角色，让观众通过"拟人受众"代入消费场景
- **反复怼脸+价格递进口播**：用"19.9 / 20 / 40 / 60 / 80"反复口播 + 纸箱同步堆叠，强化促销信息
- **沙漠→直播间强对比**：用异域场景（沙漠）做"前奏痛点"，直播间做"解决方案"，反差建立需求

**复用条件**：
- ✅ 适合：电商促销 / 直播带货（产品+价格+数量信息密集）
- ✅ 适合：日用快消品（购买决策短+频次高）
- ❌ 不适合：奢侈品 / 高单价产品（价格梯度口播=拉低调性）

**参数边界**：
- 时长：12-34 秒（电商口播需要节奏，**超出 12s 走 long_video_stitch_mode**）
- 价格梯度：3-5 级（少=信息不足，多=节奏拖）
- 纸箱/产品堆叠：与价格梯度同步增长（视觉+口播同步）
- 拟人化角色：1-2 个（受众代入不抢戏）

**Cross-ref**：`references/commercial/ugc-talking-video-ref.md §USE WHEN`（电商促销=UGC典型场景）

### 模板 #9 — 纯产品镜头叙事（灵感AIGC局·水蜜桃汁）

**原型拉片要点**：
- 场景：开场产品图卡 / 桃园果树 / 桃肉与水面 / 室内倒汁 / 户外产品静物 5 场景
- 角色：无（仅"角色A（仅露手的成年人）"作为倒汁动作的实施者，无面部/身份展示）
- 产品植入：Charlotte 品牌名出现 5 处（开场图卡 / 室内倒汁罐身 / 室内举罐展示 / 户外静物罐身 / 结尾字幕）+ 粉色产品罐+粉色桃汁+桃肉切片形成视觉同色系
- 叙事弧：原料产地（桃园）→ 加工（桃肉落入水面）→ 使用（室内倒汁）→ 静物（户外产品并置）→ 字幕收尾

**创意机制**：
- **无角色叙事+纯产品镜头**：省演员成本，把"产品本身的视觉美感"作为主角
- **原料→加工→使用→静物四段弧**：用产品生命周期作为叙事节奏，让观众理解"产品从哪里来、怎么用、长什么样"
- **同色系元素贯穿**：粉色产品罐+粉色桃汁+桃肉切片+草地蓝天=同色系视觉一致
- **字幕承担全部叙事**：旁白字幕"选自无锡阳山水蜜桃"/"果肉嫩到透光"/"从果肉到果核的甜润"承担所有信息

**复用条件**：
- ✅ 适合：饮品 / 食品 / 化妆品（产品本身视觉美感强）
- ✅ 适合：品牌调性含"小清新/治愈/极简"关键词
- ❌ 不适合：B端 / 工业品（无角色=无差异化）

**参数边界**：
- 时长：12-24 秒（四段弧需要节奏）
- 场景数：4-5 个（原料/加工/使用/静物/收尾）
- 角色：0 个（仅手部局部）或 1 个局部（不露脸）
- 字幕：必须承担全部叙事（旁白+字幕二选一）

**Cross-ref**：`references/commercial/ugc-talking-video-ref.md`（纯产品=无角色UGC）

  │   │
  │   ├─ 日化/快消 → 模板 #5 拟人IP 或 #8 电商促销
  │   │
  │   └─ 科技/出行 → 模板 #2 经典IP（痛点解救）
  │
  ├─ 品牌调性？
  │   ├─ 国潮/传统 → 模板 #1 古风IP
