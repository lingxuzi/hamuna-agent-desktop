# 分镜切分 Ref

当已有完整故事并由用户确认/由用户提供，需要拆分为集数、片段和镜头时读取本文件。

## 输入要求

需要具备：

- 完整故事或单集内容。
- 角色清单与核心人设。
- 关键场景清单。
- 项目风格和画幅比例，如已确定。

如果故事基础缺失，返回 `scriptwriter.md`。

## 澄清策略

写分镜前确认或默认：

- 要处理哪几集。
- 单集时长。短剧默认 72 秒（MCP 单段视频 12s 上限 × 6 段）。
- 片段长度。默认每集 6 个 12 秒片段。
- 镜头密度。默认每个 12 秒片段 3-6 个镜头。
- 台词、旁白、字幕、音效、音乐要求。
- 是否优先使用低风险连续动作以适配 AI 视频生成。

## 分镜规划规范

在拆分集数和规划剧情节奏时，必须根据剧本的大单元故事进行分配：
- **大单元集数分配**：每个大单元故事分配 15-25 集讲完一个完整事件。
- **小高潮节奏**：在各个大单元故事内部，保证每 5-8 集讲完一个小高潮，确保爽点持续输出。

## 资产统一铁律（跨段跨集跨场景固定编号）

**核心原则**：同一角色、同一场景、同一道具在所有 segment、所有集、所有镜头里必须复用**完全一致的编号 + 稳定特征**，不漂移、不重置、不省略。

| 资产类型 | 编号格式 | 示例 |
|---|---|---|
| 角色 | `图N`（N 从 1 开始首次出现分配） | `[图1] 林远`（左脸特写 1 + 三视图 1） |
| 场景 | `@场景N`（每集复用场景集编号） | `@场景1 江城苏家大厅` |
| 道具 | 明确中文名称（不用代词 / 量词） | `[道具] 亡父怀表` |

**硬规则**：

1. **首次出现分配编号**：剧本 / assets 阶段首次提及角色 / 场景 / 道具时立刻分配 `图N` / `@场景N` / 道具明确名称，跨 segment 表头同步记录。
2. **跨段一致**：同一角色 / 场景 / 道具在所有分镜里编号不变，外观特征（服装 / 发型 / 体型 / 道具状态 / 场景锚点）只在剧本明确变化时才变。
3. **镜头脚本必须用资产标签**：分镜的 Prompt 部分**禁止用代词**（他 / 她 / 它 / 他们 / 那个男人 / 少年），必须用 `[图N] 姓名` / `@场景N` / `[道具] 名称` 指代。
4. **场景标记独立行**：每个 segment 开头 + 每次场景切换时，单独一行 `场景：[场景名称]=@场景N`，不与时间戳同行。
5. **不能因为新 segment 重置编号**：30 集连续剧的 segment-100 出现的林远仍是 `[图1] 林远`，沿用全局编号。

**与 assets 阶段的关系**：assets 阶段建 `[图1] 林远` 的特写 + 三视图（命名 `04_assets/characters/<角色名>/...`）；分镜阶段所有镜头描述**直接复用** assets 阶段已分配的编号，禁止临时改名。

## 输出规则

- 默认每批输出 1-3 集，除非用户明确要求更多。
- 每集默认 72 秒（6 段 × 12s）。
- 每集必须包含 6 个完整 12 秒片段：
  - 00:00-00:12
  - 00:12-00:24
  - 00:24-00:36
  - 00:36-00:48
  - 00:48-01:00
  - 01:00-01:12
- 每个 12 秒片段必须包含 3-8 个镜头。
- 每个镜头必须包含**绝对时间戳**、景别、视角类型（第三人称客观视角 / POV 第一人称视角 / POV 与第三视角切换）、机位运动、拍摄角度与主体朝向（正面/侧面/背面等）、画面动作、台词、旁白、音效、音乐、字幕和转场中适用的信息。**时间戳必须首尾相连，确保片段总时长严格等于 12 秒**。

## 时长模型：默认 12s 节奏档 + 灵活档（并存）

**两套并存**，planner / storyboard 阶段必问用户要哪种：

### 默认档：12s 节奏档（短剧风格）

适用于冲突密集、打脸爽点、节奏极快的剧情。规则见下方"分镜节奏速查表"——1.5-2s 极快 / 2-3s 快 / 3-5s 中速，每 12s 段镜头数 2-7 个。

### 灵活档：4-12s 三段式（电影质感）

适用于悬疑 / 情感 / 文艺 / 慢节奏剧情。**每段总时长在 4s-12s 之间**，按剧情完整动作单元决定时长，不机械凑满。**三段式结构**（参考材料 30s 哲学按 MCP 12s 上限比例压缩）：

| 时段 | 功能 | 内容要求 |
|---|---|---|
| **钩子**（段前 25%） | 视觉钩子 | 用高冲突动作、强烈微表情或异常视觉关系立即建立张力，**不**空转 |
| **展开**（段中 50%） | 核心展开 | 以动作—反应—信息释放逐级推进 |
| **悬念**（段末 25%） | 结尾留白 | 保留未完成动作、视线落点、声响来源或空间留白，连接下一段 |

**时长选择规则**：

- 优先整数秒；确需半秒 / 小数时边界精度必须一致且精确闭合。
- 台词必须在可自然说完的镜头时长内完成；台词密度过高时**增加镜头时长或拆分 segment**，**不**靠不自然高速语速。
- 超短段（4-6s）仍须有清晰钩子 + 收束落点。
- 每段镜头时长之和 = 该段总时长（**禁**重叠 / 跳秒 / 留空）。

### 默认档 vs 灵活档：何时切

| 信号 | 用哪档 |
|---|---|
| 用户要"快 / 爽 / 短剧 / 重生打脸 / 战神" | 默认 12s 节奏档 |
| 用户要"电影质感 / 文艺 / 慢节奏 / 悬疑" | 灵活档 4-12s 三段式 |
| 用户说"你来定" | planner 默认推默认档；storyboard 阶段主动确认 |
| 默认档单镜头 < 1.5s 拍不出来（动作复杂 / 信息量大） | 局部切灵活档（单段放宽到 4-12s） |

> **🔗 MCP 时长边界**：默认档 12s / 灵活档 4-12s 三段式都在 MCP `video_generate.seconds` 字符串合法值集合内（`"4"` / `"5"` / ... / `"12"`）。**完整约束（9 合法值集合 / 双重约束 / 各分支锁定策略 / 边界外异常处理）见 `references/agnes-ai-api.md §视频时长边界（单一权威）`**。

## 镜头语言与运镜规范

在编写分镜时，必须准确使用影视级的景别和运镜术语，以精确控制观众的情感代入和叙事焦点。

### 1. 景别控制

景别决定了观众与主体的距离，直接影响情绪：

| 术语 | 定义 | 核心功能与情绪指向 |
|---|---|---|
| **大特写** | 只展现人物面部的局部，如眼睛、嘴唇。 | 强调微表情，放大极致情绪（爱、恨、惊恐）。 |
| **特写** | 展现人物从头肩的部分。 | 聚焦面部表情，传递强烈情绪，拉近心理距离。 |
| **近景** | 展现人物胸部以上。 | 既能看清表情，又能兼顾部分肢体语言。 |
| **中景** | 展现人物膝盖或腰部以上。 | 常用于对话场景，展现人物间的互动关系。 |
| **全景** | 完整展现人物全身及其周围小范围环境。 | 交代人物的完整动态与环境的直接互动。 |
| **远景** | 人物在画面中占比极小，环境成为主体。 | 强调环境氛围，表现人物的渺小、孤独或宏大叙事。 |
| **大远景** | 人物在画面中几乎成为一个点。 | 极致地渲染环境，常用于史诗感开场或结尾。 |
| **过肩镜头** | 从一个角色的肩膀后方拍摄另一个角色。 | 增强对话的代入感，让观众感觉身临其境。 |
| **第三人称客观视角** | 从角色外部观察人物动作、空间关系和场面调度。 | 交代人物站位、动作结果、环境关系，适合多数叙事镜头。 |
| **POV 第一人称视角** | 模拟某个角色眼睛看到的画面，镜头即该角色的主观视线。 | 提供沉浸式体验，强化压迫、惊吓、亲密互动、追逐、观察或手部操作。 |
| **POV 与第三视角切换** | 同一片段内在主观视线和客观外部镜头之间切换。 | 先用 POV 建立代入感，再用第三人称交代动作结果或空间关系，增强节奏变化。 |

### 1.1 POV 与第三视角切换规则

- 分镜可以采用 `POV 第一人称视角` 与 `第三人称客观视角` 来回切换的形式编排。
- 使用 POV 时必须明确 POV 所属角色，例如“林远 POV 第一人称视角”，避免只写“第一人称”。
- POV 镜头应从该角色眼睛高度出发，写清视线方向、被观看对象的位置、可见手部 / 手持道具 / 衣袖 / 伤痕等前景元素；POV 镜头中不能出现该角色完整正脸。
- 第三人称镜头负责交代空间关系、人物站位、动作结果和场面调度；如果从 POV 切回第三人称，必须写清切换后的机位、主体朝向和动作承接。
- POV 与第三视角来回切换时，角色服装、发型、道具持有状态、伤痕、湿衣服、光影方向、场景锚点必须连续，不能因为视角变化造成前后矛盾。
- 禁止把 POV 写成自拍、监控视角、无人机视角或第三人称过肩镜头；如需要过肩镜头，必须明确写“过肩镜头”，不要写 POV。

### 2. 导演级运镜语言

必须明确指出机位状态。**禁止**含糊其辞。

**基础运动运镜（控制叙事节奏与焦点）**
| 运镜术语 | 导演意图与适用场景 |
|---|---|
| **推镜** | 聚焦细节、强调重要性、拉近心理距离、制造紧张感。适用于角色做出关键决定前或发现重要线索。 |
| **拉镜** | 揭示环境、展现人物与场景的关系、营造疏离感。适用于故事结尾或展现角色身处宏大环境中的孤独。 |
| **摇镜** | 水平或垂直巡视场景，跟随主体移动。适用于扫视群像或从高处摇到低处。 |
| **移镜** | 轨道镜头，水平/向前/向后平移。创造强烈的空间感和沉浸感，适用于跟随角色行走。 |
| **升降镜** | 摇臂镜头，垂直大幅度升降。营造宏伟或压抑感，如从地面升至上帝视角。 |

**情绪表达运镜（外化人物内心世界）**
| 运镜术语 | 导演意图与适用场景 |
|---|---|
| **环绕运镜** | 围绕主体做弧形运动。产生强烈戏剧张力，适用于双人对峙或全方位展示关键物品。 |
| **手持感运镜** | 模拟手持摄影机的轻微晃动。增强纪实感、主观感和紧迫感，适用于追逐、打斗或混乱人群。 |
| **希区柯克变焦** | 推拉镜头同时进行反向变焦。背景产生急剧扭曲，适用于角色得知惊天秘密时的极度震惊或恐惧。 |
| **呼吸感镜头** | 带有轻微的周期性焦距变化。产生“呼吸”的生命感，适用于长时间凝视的静态特写。 |

**动作与冲击力运镜（武戏场景）**
| 运镜术语 | 导演意图与适用场景 |
|---|---|
| **甩镜转场** | 极快速地摇动镜头产生动态模糊。用于创造快速、生硬的转场，连接两个高速场景。 |
| **格挡震动** | 在撞击、爆炸或重物落地瞬间产生剧烈震动。增强物理打击感。 |
| **子弹时间** | 主体动作极度放慢甚至静止，镜头高速环绕。全方位展示决定性瞬间（如躲避子弹）。 |
| **冲刺跟拍** | 极快速侧面平移跟拍。画面充满动态模糊和颠簸感，营造强烈的速度与激情。 |

### 3. 拍摄角度与主体朝向

必须明确镜头拍摄的主体朝向，这对于 AI 视频生成时的角色一致性和空间关系至关重要：

| 角度与朝向 | 核心功能与适用场景 |
|---|---|
| **正面** | 展现角色的完整面部表情，与观众建立最直接的视觉交流。适用于重要台词、情绪爆发。 |
| **侧面 (左侧/右侧)** | 强调角色的轮廓或动作，常用于双人对话交锋或表现角色在思考、观察。 |
| **半侧面 (3/4侧)** | 最常用的角度，既能展现表情又有立体感，适用于大多数日常叙事和互动。 |
| **背面** | 营造神秘感、疏离感，或引导观众视线看向角色所看的前方。适用于角色离开、隐藏真实情绪。 |
| **仰拍** | 从下往上拍。赋予主体高大、威严、压迫感，适用于展现反派的嚣张或主角的觉醒。 |
| **俯拍** | 从上往下拍。使主体显得渺小、弱势、无助，适用于角色受挫或展现全局环境。 |
| **平视** | 与主体视线齐平。客观、平等的视角，适用于常规叙事。 |

### 4. 光影与色调设计

在关键分镜中，需补充光影以塑造氛围：

| 维度 | 分类 | 常用词汇/适用场景 |
|---|---|---|
| **光线质感** | 硬光/柔光/伦勃朗光 | 硬光（轮廓分明，制造冲突感）、柔光（干净治愈）、伦勃朗光（经典人物肖像，脸颊有三角光斑）。 |
| **光线方向** | 顺光/侧光/逆光/底光 | 侧光（强烈明暗对比）、逆光（勾勒金色轮廓、剪影）、底光（从下往上打，制造恐怖悬疑氛围）。 |
| **色调风格** | 饱和度/色温/特殊风格 | 低饱和度（情绪内敛、忧郁）、冷色调（赛博朋克/悬疑）、复古胶片色（港风怀旧）。 |

## 运镜按景别分级（特写 / 中近 / 中远三档强制）

**核心约束**：运镜强度必须匹配景别——特写禁剧烈晃动，中远景禁死板 tripod。**这是 AI 视频生成稳定性的硬规则**（特写剧烈运镜 → 面部融化 / 残影；中远景 tripod → 失去空气感）。

### 特写与大特写

- **运镜**：`tripod static shoot` 或 `ultra-stable micro-jitter`
- **强制标签**：`high facial detail focus` + `high-focus depth of field`
- **禁用**：剧烈晃动 / 手持感运镜 / 希区柯克变焦
- **质量红线**：睫毛 / 瞳孔 / 咬肌 / 嘴角纹理清晰，**无残影、无溶解**

### 中近景 / 双人对峙 / 台词戏

- **运镜**：`subtle cinematic handheld` + `realistic camera inertia`
- **强制标签**：摄影机随体态产生轻微低频滞后跟拍，保留温和惯性拖拽
- **禁用**：死板 tripod / 极端推拉

### 中远景 / 全景 / 铺垫空镜

- **运镜**：`full-scale cinematic handheld` + `natural breathing`
- **强制标签**：慢速漂移 + 手持呼吸拉扯表现环境空气感
- **强制约束**：主体轮廓仍须**稳定可辨**（不能漂到模糊）

### 高频合法标签（自然语境自由组合）

`cinematic handheld camera` / `natural breathing` / `micro expressions` / `realistic camera inertia` / `subtle performance` / `cinematic motion` / `ambient light drift` / `handheld realism`

**禁止**：在一个分镜里同时堆砌所有标签（**机械堆砌** = 失去重点）。

## 动作规则

- **肢体细化 + 程度量化**：写清身体部位，必须补充幅度、速度、力度（如：缓慢抬手、快速转头、用力蹬地、微微低头）。
- 优先使用低缓连续小动作：缓慢行走、轻轻抬手、顺势坐下。
- 除非剧情必须，避免狂奔、大跳、翻滚、复杂打斗等大动态不稳定动作。
- 写清动作过渡，让前后镜头因果衔接。必须写明惯性与承接关系（如：借着转身惯性顺势抬手、从停顿状态自然过渡到举手）。
- **五维物理表演（强制）**：分镜的表演描述**严禁使用抽象情绪词**（”难过 / 愤怒 / 委屈 / 失望 / 崩溃 / 麻木” 等），必须通过以下**至少 3 维度**呈现，关键近景尽量覆盖 5 维：
  1. **微表情与视线**：瞳孔骤缩 / 慢扩、睫毛颤动、视线失焦 / 重聚、咬肌收紧、嘴角肌理位移。
  2. **肢体与体态**：重心微调、双肩随呼吸起伏、指尖拧抓衣角、指节泛白、手腕紧绷 / 松弛。
  3. **动作中间态**：欲言又止、转身一滞、半步悬停、抬手悬空、触碰前微顿等**未完成状态**——这是 AI 视频生成稳定性的核心约束，**禁**写”已完成动作 + 跳到下一个已完成动作”。
  4. **生理应激**：喉结滚动、鼻翼微翕、额角青筋微凸、眼睑不自主抖动、胸腔节律变化。
  5. **光影呼吸**：呼吸和体态变化带动皮肤与轮廓阴影实时位移，使用 `ambient light drift` 标签。

- **6 种表演范式（按情境融合，不得直接把范式名称当作画面描述）**：
  - **轻俏嗔笑**：眼底细碎反光收敛，单侧唇角微翘，头部轻偏，手腕抬起半挡，呼吸平缓。
  - **强忍情绪**：眼尾泛红含水光，双唇反复轻抿微颤，呼吸短暂停顿，双肩微收，喉结低频滚动。
  - **沉绪落空**：视线失焦下坠，长气缓慢吐出，胸腔塌落，双肩下垂，重心后移。
  - **冷厉紧绷**：瞳孔微缩锁定目标，下颌咬肌隆起，呼吸重而急，五指缓慢攥紧至指节泛白。
  - **破碎失控**：视线高频颤动，呼吸杂乱急促，身体本能后撤微晃，双臂环抱，肌肉细颤。
  - **空心死寂**：眼底无焦，呼吸极弱，肌肉松弛，面颊出现无声湿痕；**此范式免除常规胸腔起伏**。

- **跨镜头情绪一致性**：同一情绪在镜头 1 → 镜头 2 的体态 / 呼吸 / 视线状态必须连续（例如”愤怒”从镜头 1 的”双拳紧握、下颔线紧绷” → 镜头 2 不能直接”释然长舒一口气”，需经过中间态”指节泛白、呼吸短促”）。

## 连续性规则

- **因果逻辑清晰**：每个镜头都要能逻辑衔接到下一个镜头。在每个镜头的末尾必须写明转场方式（如：`[硬切]`、`[叠化]`）。前后镜头必须存在严密的因果联系（例如：上一个镜头有人扔出文件，下一个镜头必须是另一个人低头看文件后产生反应）。
- 如果上个镜头抛出道具，下个镜头要交代落点或人物反应。
- 台词长度必须适配镜头时长（3秒内只能说一两句短语）。
- 旁白应克制，只在必要时使用，并在画面内容后使用『』标注。
- **角色与道具命名强一致性**：在所有分镜中，对同一个角色或道具必须使用**完全一致的称呼**（例如：必须全程使用“黄衣小哥”或“林远”，严禁中途改用“他/那个男人/少年”等代词或别称）。
- **禁止使用群体量词概括角色**：当多个角色同时出场或互动时，**严禁使用数字或量词概括**。
  - ❌ 错误示范：`三个人面面相觑`、`众人大惊失色`、`反派们冲了上来`。
  - ✅ 正确示范：`黄衣小哥，粉裙少女，灰头发老太 面面相觑`、`周凯，李总，黄毛 大惊失色`。必须完整写出当前镜头内出现的所有具体角色名称。

## 交付前硬校验（静默检查，不输出过程）

AI 完成分镜输出前 MUST 静默自检以下项；任何一项不通过 = 重新修订，禁止带着问题交付：

**结构与格式**

- [ ] 输出结构与上方"输出格式"模板完全匹配（标题 / 故事提要 / 片段分镜 三段齐全）
- [ ] 每个镜头独占一行，以**绝对时间戳**开头（用户视角），无"镜头 1 / Shot 1"等编号
- [ ] 每个 segment 开头 + 每次场景切换时，单独输出 `场景：[场景名称]=@场景N`，**不**与时间戳同行
- [ ] 段尾"验收与修改建议"四方向（节奏 / 动作连贯性 / 情绪张力 / 下一步）齐全

**时间轴与节奏**

- [ ] 每段从 `00:00` 起步，每段结束时间等于该段总时长（默认 12s 节奏档 6 段 = 00:00-01:12；灵活档每段 4-12s）
- [ ] 相邻镜头**首尾相连、无重叠、无跳秒、无留空**——所有镜头时长之和**严格等于**该段总时长
- [ ] 灵活档每段含钩子（段前 25%）/ 展开（段中 50%）/ 悬念（段末 25%）三段功能
- [ ] 默认档单镜头时长匹配节奏速查表（极快 1.5-2s / 快 2-3s / 中速 3-5s）

**资产与命名**

- [ ] 角色 / 场景 / 道具**编号跨段一致**（`[图N]` / `@场景N` / 道具明确名称，**不**漂移、不重置）
- [ ] 所有镜头脚本用资产标签指代（**禁**"他 / 她 / 它 / 那个男人"等代词或英文代词）
- [ ] 多角色同框完整写出所有角色名（**禁**"三个人面面相觑" / "众人"等量词概括）

**表演与运镜**

- [ ] 关键近景表演描述覆盖五维物理表演**至少 3 维**（特写尽量 5 维全覆盖）
- [ ] 抽象情绪词已替换为具体身体细节（**禁**"很悲伤 / 非常愤怒 / 绝望 / 崩溃 / 麻木"）
- [ ] 运镜强度匹配景别分级（特写 `tripod static` / 中近 `subtle handheld` / 中远 `full-scale handheld`）
- [ ] 跨镜头情绪状态连续（不出现"上一镜愤怒 / 下一镜直接释然"的跳跃）

**视觉安全**

- [ ] 禁止 Meta 指令（**禁**"短剧节奏 / 电影级 / 9:16 画幅"等）
- [ ] 禁止 HEX 颜色代码（`#FFFFFF`）
- [ ] 禁止数值化身高 / 尺寸（"身高 175cm"）
- [ ] 完全规避血腥暴力 / 色情暗示 / 现实品牌 / 公众人物 / 版权角色
- [ ] 不渲染伤害细节（原文若触碰边界 → 用剪影/遮挡/声响/破碎物件/光影骤变替代）

## 持久化

**用户确认分镜后，AI 必须把分镜表落盘到 `<workspace>/creative-video-suite/<project-name>/03_storyboard.md`**（`cmd_write_workspace_file`）。落盘前自检 §7 集成清单；落盘后 update `project.json.current_stage = "storyboard"`。

分镜表内每个镜头的角色 / 场景 / 道具名**严格沿用 `02_script.md` 已确认的命名**（drama）或 brief 命名（commercial）——命名漂移会破坏 assets 阶段 file 查找。跨阶段引用：下一阶段 assets 阶段读 `03_storyboard.md` 时，角色 / 场景 / 道具名直接当 file path 段用（`04_assets/characters/<角色名>/...`）。commercial 分支 ugc / marketing / corporate 的分镜表落盘路径同上，差异在产物形态（见 output-conventions.md §5）。

## 产品图强制门控

**drama 强门控**（与 commercial 同级）：分镜切分阶段如果分镜表涉及产品特写 / 品牌植入镜头 → AI **必须**确认产品图已落 `04_assets/product-refs/<产品名>.{jpg,png}`，否则 stop。

**触发判定**（分镜层）：
- 分镜表里某镜头标注"产品特写" / "品牌 LOGO 出现" / "XX 牌包装入镜"
- 镜头时长 > 1s 且主体是产品（不是角色 / 场景）

**流程**：
1. 分镜阶段发现产品镜头 → 检查 `04_assets/product-refs/<产品名>.{jpg,png}` 是否存在
2. 不存在 → 停下告诉用户"剧本确认有产品但没传图，请上传"
3. 存在 → 分镜表该镜头**显式标注**产品参考图来源：`<产品特写镜头> 参考 product-refs/<产品名>.png；保持包装 / logo / 颜色 / 比例一致`
4. 用户**显式 ack 降级** → 标记该镜头为"产品视觉相似，无真实参考"，不阻塞后续流程

完整规范见 `references/mcp-usage-guide.md` §1。
