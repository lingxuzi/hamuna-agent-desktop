# crawl-xueqiu-my-timeline

爬取雪球**关注时间线 + 热帖**（默认双源），把帖子当作信号素材，用 **stock-datasource 行情/财务数据交叉验证 A 股标的**，通过**观点对撞 + 逻辑链综合**，生成**深度分析报告**（Markdown + PDF，雪球发帖兼容排版，正文零署名引用）。

**特点**：
- **双数据源**：关注时间线（个性化）+ 热帖（市场热门），默认合并分析，也可单源
- **综合分析链路**：信号采集 → 观点对撞 → 数据裁决 → 完整逻辑链 → 深度分析产出
- **正文零署名**：不直接引用"@某大V说..."，所有观点消化为分析语言，信息出处只在文末"信号依据"
- **雪球发帖兼容**：正文用段落/加粗/`$代码$` 标的，不用 Markdown 表格/代码块（雪球富文本编辑器不支持）
- 自动过滤官方账号（上市公司、指数、ETF 等行情播报）
- 按发言人分组输出，发言数量降序排列

## AI 分析指引

### ⚠️ 重要：观点归属判断

**只有不以 `//` 或 `>` 开头的内容才是发言人自己的观点**：

| 标记 | 含义 | 是否总结 |
|------|------|---------|
| 无标记行 | 发言人本人的发言 | ✅ 需总结 |
| `//` 开头 | 被评论的其他用户发言 | ❌ 非本人观点 |
| `>` 开头 | 被引用的转发内容 | ❌ 非本人观点 |

**注释**：`回复@XXX：` 前缀是雪球自动生成的，整行都是发言人自己的观点，应总结。

**示例**：
```
回复@阿企笔记：要知道很多农村的人需要方言语音设备
//回复@青年完：支付宝本来就有音响
> @阿企笔记：中概股失去增长动力
```

**正确总结**：发言人认为农村用户需要方言语音设备

**错误总结**：发言人讨论了支付宝音响、中概股财报

### 读取输出文件

爬取脚本会在当前目录生成 Markdown 文件：`xueqiu_YYYYMMDD_YYYYMMDD.md`（原 `home_timeline_*.md` 已废弃）

```bash
# 读取最新生成的文件
cat xueqiu_*.md
```

## 核心：深度研究方向分析流程

**这是本 skill 的核心输出。** 雪球帖子只是**研究线索**——指出"哪些方向有人在关注、有什么争议"。真正的产出是**研究报告**：对值得研究的方向，用全部可用的数据源做**独立研究**，产出帖子本身没有的新认知（因果、算账、产业链拆解、风险演化）。

> **铁律：正文不出现"@某大V 说..."的署名引用。** 帖子观点作为研究线索，在内部消化。报告呈现的是**你的研究结论**，不是观点的转述或整理。出处只在文末"研究线索"清单。

### 第一步：筛选研究方向（从帖子到研究选题）

通读 `xueqiu_*.md`，提取候选研究方向。但这里的判断标准是**"这个方向值得不值得花力气研究"**：

| 研究选题要素 | 说明 | 示例 |
|---------|------|------|
| **方向名** | 一句话主题 | "功率半导体涨价" |
| **提及标的** | `$代码$` 格式 | $士兰微(SH600460)$ |
| **关注热度** | 几个人在聊、情绪分布 | 3人，2乐观1中性 |
| **催化事件** | 触发讨论的事件 | IGBT 缺货涨价 |
| **争议点** | 存在哪些未解决的分歧 | 涨停次日资金分歧、估值是否透支 |

**选题标准**（宁缺毋滥，**少而深**）：
- **只选 3-5 个"有真实研究空间"的方向**：有明确标的 + 有可研究的问题（不只是"某某涨了"）
- **过滤掉**：纯理念分享、生活记录、情绪发泄、无法用数据研究的话题
- 一个方向值不值得研究，问自己：**"这个问题，用现有数据源能回答到多深？"** 能回答得深 → 选；只能复述 → 不选

### 第二步：深度研究（核心产出——用全部数据源独立研究）

对每个选中的方向，**像研究员一样做研究**，不是"验证帖子说法"。研究要回答**帖子没回答的问题**：

**研究工具箱（stock-datasource 全部工具，按需使用）**：

| 工具 | 用途 | 深度研究能回答什么 |
|------|------|------|
| `get_realtime` | 实时行情 | 现价/涨跌/成交额/五档 |
| `get_kline` | 历史K线（D/W/M/5分钟） | 趋势结构、放量缩量、支撑压力位、历史同款行情复盘 |
| `get_stock_annual_report` | **年报文本（4表全字段）** | **真实业绩**：营收/利润/现金流逐季拆解，验证"涨价→业绩"是否已兑现 |
| `get_cninfo_announcement` | **最新公告** | **催化事件是否属实**：涨价/扩产/大单公告 |
| `get_stock_financial` | 财务指标 | EPS/PE/PB/ROE/市值，纵向看趋势 |
| `get_stock_industry_compare` | **同业对比** | 该标的是否行业内最优（估值/盈利/成长） |
| `get_shareholders` | **十大流通股东** | 谁在持有：社保/养老/机构/散户化程度 |
| `get_chip_distribution` | **筹码分布** | 套牢盘/获利盘比例，当前价位上方压力 |
| `get_dividend` | 分红历史 | 分红能力，防御性 |
| `get_stock_money_flow` | 资金流向 | 主力/特大单净额，可看分时明细 |
| `get_plate_ranking` / `get_plate_constituents` / `get_kline_by_plate` | 板块 | 板块强度、成分股对比 |
| `get_news_by_stock` / `get_tech_news` | 个股/行业新闻 | 最新催化、产业动态 |

**研究深度要求**——每个方向至少回答这几个问题（用数据，不是复述）：
1. **现象背后是什么**？帖子说"涨停"，研究：为什么涨停？资金结构如何（主力/散户）？筹码是集中还是分散？
2. **逻辑目前兑现到哪一步**？帖子说"涨价→业绩"，研究：财报里涨价体现了吗？毛利率环比改善了吗？业绩是预期还是已兑现？
3. **估值贵不贵**？不是看一个 PE 数字，而是：和同业比、和历史区间比、和成长性比（PEG）
4. **谁在买/谁在卖**？股东结构、资金流、筹码分布——是机构在建仓还是游资炒作
5. **最坏情况是什么**？逻辑证伪的信号有哪些，现在出现没有

### 第三步：收束未来投资方向（从研究结论 → 方向推演）

**本 skill 的最终产出是"未来 1-3 个月可能的方向"，不是"过去 24 小时发生了什么"。** 深度研究解决"现状是什么、兑现到哪一步"，这一步要把研究结论**往前推演成方向**：

**怎么推**（每个方向三步走）：
1. **现状落脚**：这 24 小时市场在围绕什么转，研究后结论是什么（数据发现）
2. **判断依据**：为什么这个状态会延续/反转？跨月度的产业变量是什么（AI 资本开支季度节奏、涨价周期、猪周期去化、政策窗口）——注意方向必须落在**产业趋势+基本面**上，24 小时舆情撑不起未来判断，它只是线索
3. **未来收敛**：一句"沿着 X 往下看，我后面会盯这几个变量"，把方向落成可跟踪的信号

**三条纪律**：
- **只对"研究过、有数据支撑"的方向给未来判断**。研究不透的方向，说"这个我看不清"比硬给方向更专业
- **方向是"分层"的不是"并列"的**：有把握的方向给明确的倾向和信号表；没把握的作为"等信号"一笔带过。宁要两个说得清的方向，不要六个都说得含糊的方向
- **研究推演 ≠ 荐股指令**：必须带"基于什么判断、到什么信号作废"。这是给读者的投资框架，不是买卖点。这既是专业性也是合规性底线

### 第四步：成文（研究结论 → 深度分析）

把研究成果写成**有深度、像人写的长文**（投资长文风，去标题去列表，数据融入叙述）。但每一段背后都是**研究过的**，不是观点整理：

- **每个方向都有"研究发现"**：帖子没提、你通过研究新发现的东西（如"筹码分布显示上方套牢盘密集"、"三季报显示毛利率已环比改善 2 个点"、"十大股东里社保在增持"）
- **每个结论都有数据支撑**：不只是"有人这么想"，而是"数据是这样"
- **敢于下判断**：研究过了就敢说"我认为X"、"这不符合常识，但数据支持"
- **诚实标注研究边界**：哪些是验证过的事实、哪些是推演、哪些是数据够不到的地方

**质量自检**（成文后问自己）：
- 这篇文章里，有没有**至少 2-3 处"数据新发现"**（帖子之外、通过研究才得到的信息）？
- 如果把它贴给一个专业投资者，他会不会觉得"这个人做了功课"？
- 还是它本质上只是把帖子观点整理了一遍？（如果是，重写）

## 报告格式（投资长文风，雪球发帖兼容）

**⚠️ 雪球富文本编辑器不支持 Markdown 表格、代码块、`#` 标题**。报告必须用**段落**组织，直接可粘贴雪球发帖。`$代码$` 是雪球股票引用格式，必须保留。

**⚠️ 铁律：正文不出现"@某大V 说..."署名引用。** 全部消化为分析者自己的语言，观点通过对撞分析综合成完整叙事。信息出处只在文末"信号依据"清单。

### 报告 = 一篇投资长文，不是结构化报告

**彻底去标题、去列表、去分节。** 输出是**连贯的散文段落**，像一位深度投资者在雪球写的长文：有开头引入、有展开、有转折、有个人判断、有收尾。读起来是"一个人在说话"，不是"一份研究报告"。

**写作内核（前几轮迭代的分析质量必须保留，但用叙述表达）**：
- **零署名**：观点消化成自己的语言，不出现"某大V认为"
- **不提帖子**：**正文不得出现"帖子""雪球""有人发帖"等措辞**。帖子只是你获取研究线索的**后台参考**，读者看到的是**独立的深度分析**，不是在"回应帖子"。分析对象直接用市场/公司/方向本身来陈述
- **对撞分析**：多空分歧自然融进叙述（"有人看到了缺货的确定性，也有人看到了涨停后主力在跑——两边都有道理，但我更倾向..."）
- **数据佐证**：行情/财务数据**融入叙述**，不列表罗列（"士兰微 $士兰微(SH600460)$ 涨停那天收在 35.89，可隔天主力净流出 5.6 亿，这个分歧很耐人寻味"）
- **完整逻辑**：从现象到传导到机会到证伪，一条线在叙述里走完

### ⚠️ 去 AI 味（铁律：写得像人，不像 AI 生成的报告）

AI 写长文有几个一眼可辨的毛病，**逐条自查并消除**：

| AI 味 | 长什么样 | 改法 |
|------|---------|------|
| **破题模板** | "这24小时，市场的注意力全部压在X两个字上" | 用一句具体的话开场，不总结"两个字" |
| **排比对仗过密** | "讲给预期听的，还是讲给业绩听的" | 对仗偶尔一次是文采，三次以上是 AI。打断节奏 |
| **转场词重复** | "更耐人寻味的是""值得注意的是""最让我感兴趣" | 每篇最多出现一次；改用手势指向前后（"再说另一头""上面那条线的反面"） |
| **"我"字密度** | "我拉了一下""我评估下来""我的判断很直白" | 主语能省则省，判断直接陈述；"我的"每段最多一次 |
| **收尾金句化** | 每段都以升华金句收（"周期股最贵的就是X这六个字"） | 金句全篇最多 1-2 处，其余段落用平实结论收尾 |
| **数据均匀堆砌** | 每段都是完整数据块（毛利率X%净利率Y%ROE Z%） | 数据服务论点，不为凑数。一段里只挑最能说明问题的 1-3 个数字，其余带过 |
| **结构均匀** | 每个方向都写到差不多长 | 详略失衡才对：有把握的多写，没把握的一两句话带过 |

**"讲的语气"不是"报的语气"**：
- 报的语气：罗列数据 → 得出结论（"士兰微毛利率19.8%，净利率5.9%，估值高企"）
- 讲的语气：带着反应和思考过程（"毛利率一出来我就皱眉头——19.8%，比行业均值低了十个点。这种盈利质量配132倍估值，我是不会追的"）
- 允许不完美：研究够不到的地方直接说（"这个我查不到""港股那边数据源覆盖不到，只能点到为止"），真人不假装全知

**允许详略失衡**：这24小时值得深挖的也许只有两个方向，那就写透两个，其余一笔带过。宁要两段有血有肉，不要六段四平八稳。

### 写作风格要点

- **有开头**：一句具体的话破题（写一个具体画面或数字，不总结"市场围绕X字转"）
- **有过渡**：方向之间用自然转折，用手势指向前后（"再说另一头""上面那条线的反面"），"耐人寻味/值得注意的是"这类全篇最多一次
- **有判断**：敢于下结论，但不把话说死（"我更倾向于..."、"目前看...")；给确信度时用人类的话（"这事我比较有把握" / "这个还早"）而不是"高/中/低"
- **有温度**：允许"有意思的是""反直觉的是"这类叙述，但**全篇每种最多一次**，不叠用
- **有收尾**：结尾总结整篇判断，顺带点一句风险（"这些判断的前提是...，如果...就得重新想"）
- **少而深**：聚焦 2-4 个有证据的方向写透；低确信度/研究不透的方向一两句话带过，宁缺毋滥
- **港美股不单列**：阿里等港股美股作为"跨市场背景"融进相关段落，不单独开节
- **去 AI 味**：见上方"⚠️ 去 AI 味"区块，成文后逐条自查

### 未来方向收束（每个方向的最后一步，也是整篇的灵魂）

每个方向写完后，必须落到"未来"——**现状分析是过程，方向推演是终点**：

- **每个方向给一个"未来 1-3 个月往哪看"的判断**，用叙述带出，不写清单：
  - "沿着这条线往下走，我后面会盯两个变量：10 月的第三波提价是否落地，和两家公司三季报毛利率是否环比抬升——前者验证逻辑，后者验证兑现"
  - "反转要成立，得等营运利润增速转正，那是四季报的事。现在喊在情绪上没错，喊在数据上还早"
- **方向之间要能串成一个整体判断**（光模块已兑现 vs 功率半导体在兑现 vs 平安等确认），不要写成互不相干的方向列表
- **每个未来判断都带"到什么信号作废"**：给读者的不是结论，是"如果 X 就推翻重来"的框架
- **研究不透的方向**：一句"这个我看不清/要等数据"带过，不硬给方向

### 结构示意（示意，不是模板——实际按散文写）

```
（第一段）破题：这 24 小时，市场的注意力高度集中在 AI 的资本开支上。资金在围绕它分化...

（第二段起，每个方向 1-3 段）方向一：功率半导体涨价。
自然叙述：先讲现象（士兰微涨停、缺货涨价链条）→ 再讲分歧（涨停次日主力净流出、
估值高企）→ 再给判断（数据裁决：缺货是真，但选股要看盈利质量，扬杰 vs 士兰微）
→ 点关键变量（10 月第三波涨价）→ 证伪（需求转弱）。全部用叙述串起来，不分节。

（继续其他方向，用过渡句连接）

（倒数第二段）阿里配售这个跨市场背景怎么融进主线：资本开支军备竞赛 → 卖铲子优于买铲子。

（末段）**未来方向收束**：把几个方向的判断串成一个整体——"排个序：确定性最高的是已经用财报证明自己的X，次之是盈利质量好、估值还没透支的Y，再次是作为防守的Z；而W和V，我宁愿等数据先说话。这些判断的前提是AI资本开支不被打断、半导体需求不超预期转弱——如果FCC真把光模块一刀切纳入限制名单，或功率半导体下游下半年转弱，上面的排序全部推翻重来"。
```

**质量自检加一条**：删掉所有"未来方向"句子后，文章是否还有投资指导价值？如果只剩现状分析 → 没完成"未来投资方向"的核心产出，重写。

**写作自检**：
- ✅ 通读一遍像"一个人写的文章"，不是"AI 生成的结构化报告"
- ✅ 没有 `##`、`**现状事实**`、`观点对撞`、`风险与边界` 这类章节标签
- ✅ 数据融入句子，不是 `- 士兰微: 35.89` 这种列表
- ✅ 观点都消化成"我的判断"，没有 @署名
- ✅ **全文不出现"帖子""雪球""有人发帖"等措辞**——读起来是完全独立的深度分析
- ✅ **至少 2-3 处"数据发现"**（通过研究才得到的信息，如财报细节、筹码分布、股东结构、同业对比）
- ✅ 每个方向的结论背后有数据支撑，不是复述任何来源的观点
- ✅ **如果删掉"数据发现"部分，文章还剩什么？** 如果只剩观点的罗列 → 深度不够，重写
- ✅ **去 AI 味自查**：没有"压在X两个字上"式破题、排比对仗≤2处、转场词每种≤1次、"我"每段≤1次、收尾金句≤2处、数据不为凑数、详略有失衡
- ✅ **读起来像一个人在说话**：如果有任何一段能放进任何其他 AI 文章而不违和 → 那一段是 AI 味，重写
- ✅ **未来方向收束**：每个方向落到"未来 1-3 个月往哪看"（含信号表/作废条件），末段把方向串成整体判断；删掉未来方向后若只剩现状分析 → 未完成核心产出，重写

### 报告结构规则

1. **投资长文风**：输出是连贯散文，像深度投资者写的长文，不是结构化报告
2. **彻底去标题/去列表/去分节**：不出现 `##`、`现状事实`、`观点对撞`、`风险与边界` 等章节标签，也不用 `-` 列表罗列
3. **正文零署名 + 不提帖子**：不出现"@谁谁谁说"，也不出现"帖子/雪球/有人发帖"等措辞——呈现完全独立的深度分析
4. **深度研究驱动**：每个方向的结论来自独立研究（财报/公告/股东/筹码/同业/资金流），不是观点整理
5. **每个方向有"数据发现"**：至少一处帖子没提、通过研究得到的新信息（业绩兑现度/筹码结构/股东变化/估值分位）
6. **数据融入叙述**：行情/财务数据嵌进句子（"士兰微涨停收 35.89，可隔天主力净流出 5.6 亿"），不列表
7. **少而深**：聚焦 3-5 个有研究价值的方向写透；低价值方向一句话带过或略去
8. **港美股不单列**：并入相关段落作跨市场背景，不单独开节
9. **研究线索在文末**：方向 → 数据来源 → 关键数据，供查证但不进正文
10. 报告整体风格 = **雪球发帖兼容**（段落，无表格/代码块/`#` 标题）
11. 涉及 A 股标的统一用雪球 `$名称(代码)$` 格式，如 `$士兰微(SH600460)$`

## AI 分析流程（Subagent 调度）

### 步骤 1: 创建研究 TODO 列表

通读 `xueqiu_*.md`，**选定 3-5 个值得深入研究的方向**（不是按发言人分组！），每个方向创建一个研究 TODO：

| TODO | 研究方向 | 研究重点 |
|------|---------|---------|
| 研究：功率半导体涨价 | 缺货→涨价→业绩 兑现到哪步 | 士兰微/扬杰财报、毛利率、估值对比 |
| 研究：AI 算力硬件 | 订单真实性 + 资金结构 | 中际旭创/新易盛资金流、筹码、估值分位 |
| 研究：低估值反转 | 平安/牧原 反转证据 | 营运利润、股东结构、周期位置 |

**选题标准**：只选有明确标的 + 有可研究问题的方向。纯理念/情绪/无法数据研究的话题不选。

### 步骤 2: Subagent 指令模板（深度研究）

每个 subagent 对一个方向做**独立研究**（不是总结用户发言）。指令模板：

```
对以下方向做深度研究：功率半导体涨价

**研究标的**：士兰微(600460)、扬杰科技(300373)
**研究问题**：
1. 涨价逻辑在财报里兑现了吗？（营收/毛利率/净利润趋势）
2. 两个标的估值与盈利质量对比（PE/PB/毛利率/净利率/成长性）
3. 资金面谁在买谁在卖（主力净流入/股东结构）
4. 催化事件是否属实（公告/新闻验证缺货涨价）

**数据工具**（通过 stock_datasource_call.sh 调用）：
- get_stock_financial / get_stock_annual_report：财务与业绩
- get_stock_industry_compare：同业对比
- get_stock_money_flow：资金流
- get_stock_chip_distribution：筹码分布
- get_cninfo_announcement：最新公告
- get_realtime / get_kline：行情
用法：sh scripts/stock_datasource_call.sh <工具> '<JSON>'

**输出要求**：
返回研究发现（不要写文件）：
- 每个研究问题的数据结论（带具体数字）
- 帖子没提、你新发现的信息（数据发现）
- 你的独立判断
```

> **注意**：subagent 输出是研究素材，报告正文**不得**出现 @署名引用。数据必须真实调用，港美股不可验证就明说。

### 步骤 3: 并发调度

- **并发限制**：同时运行的 subagent 不超过 3 个
- **执行流程**：
  1. 填充空闲槽位（启动 subagent）
  2. 等待任一 subagent 完成
  3. 标记 TODO 完成/失败
  4. 继续下一批

### 步骤 4: 重试机制

- subagent 失败时自动重试，最多 2 次
- 持续失败的 TODO 在报告中标注"⚠️ 研究失败"，并提示用户可手动研究

### 步骤 5: 结果汇总（成文）

整合所有 subagent 的研究结果，生成深度分析长文：
- 每个方向呈现**研究结论**（数据支撑），不是观点整理
- 突出**数据发现**（帖子之外的新信息）
- 敢于下判断，诚实标注研究边界（验证过/推演/数据够不到）
- 投资长文风，去标题去列表，数据融入叙述
- 正文**零署名**，研究线索放文末

## 爬取脚本参数

```bash
skills/crawl-xueqiu-my-timeline/scripts/crawl_xueqiu_home_timeline_api.py [选项]
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--hours` | 爬取最近 N 小时 | 24 |
| `--days` | 爬取最近 N 天 | - |
| `--start-date` | 开始日期 (YYYY-MM-DD) | - |
| `--end-date` | 结束日期 (YYYY-MM-DD) | 今天 |
| `-o, --output` | 输出文件名 | 自动生成 |
| `--hot` | **仅**爬取热帖（不爬关注时间线） | - |
| `--follow-only` | **仅**爬取关注时间线 | - |

**数据源说明**：
- **默认双源**：关注时间线 + 热帖合并分析，同一帖子自动去重
- `--hot`：只要热帖（账号未关注任何人时也能用）
- `--follow-only`：只要关注时间线（原行为）

**注意**：`--hours`、`--days`、`--start-date` 三个参数互斥；`--hot` 与 `--follow-only` 互斥。

### 示例

```bash
# 爬取最近 24 小时（默认：关注 + 热帖）
skills/crawl-xueqiu-my-timeline/scripts/crawl_xueqiu_home_timeline_api.py

# 只爬热帖（推荐，任何账号可用）
skills/crawl-xueqiu-my-timeline/scripts/crawl_xueqiu_home_timeline_api.py --hot

# 只爬关注时间线
skills/crawl-xueqiu-my-timeline/scripts/crawl_xueqiu_home_timeline_api.py --follow-only

# 爬取最近 2 小时
skills/crawl-xueqiu-my-timeline/scripts/crawl_xueqiu_home_timeline_api.py --hours 2

# 爬取最近 7 天
skills/crawl-xueqiu-my-timeline/scripts/crawl_xueqiu_home_timeline_api.py --days 7

# 指定日期范围
skills/crawl-xueqiu-my-timeline/scripts/crawl_xueqiu_home_timeline_api.py --start-date 2026-03-01 --end-date 2026-03-06
```

## PDF 输出流程

### 1. 保存分析报告

将分析报告保存为 `深度分析_YYYYMMDD_YYYYMMDD.md`，日期为时间范围的起始和结束日期。

示例：`深度分析_20260305_20260306.md`

### 2. 转换为 PDF

```bash
bunx mdpdf 深度分析_YYYYMMDD_YYYYMMDD.md \
  --style=skills/crawl-xueqiu-my-timeline/assets/github-markdown.css
```

例如：
```bash
bunx mdpdf 深度分析_20260305_20260306.md \
  --style=skills/crawl-xueqiu-my-timeline/assets/github-markdown.css
```

**可选参数**：
- `--border=<size>`：页边距（默认 20mm），如 `--border=15mm`
- `--format=<format>`：纸张大小（默认 A4），如 `--format=A4`
- `--orientation=<orientation>`：方向（默认 portrait）
- `--title=<title>`：PDF 标题

### 3. 清理临时文件

```bash
rm 深度分析_YYYYMMDD_YYYYMMDD.md
```

### 完整示例

```bash
# AI 写入总结文件 → 深度分析_20260305_20260306.md

# 转换为 PDF（当前目录生成 PDF）
bunx mdpdf 深度分析_20260305_20260306.md \
  --style=skills/crawl-xueqiu-my-timeline/assets/github-markdown.css

# 删除临时 Markdown 文件
rm 深度分析_20260305_20260306.md
```

**结果**：当前工作目录生成 `深度分析_20260305_20260306.pdf`

## 一次性登录（首次使用必需）

爬虫通过 Chrome Debug 实例内携带的雪球 cookie 获取关注时间线，**首次使用必须手动登录一次**：

```bash
# 1. 确认 Chrome Debug 模式已启动
sh skills/crawl-xueqiu-my-timeline/scripts/check-cdp.sh

# 2. 用 agent-browser 打开雪球首页
agent-browser --cdp 9222 open https://xueqiu.com

# 3. 在弹出的 Chrome 窗口里手动扫码/账号登录雪球，直到首页显示已登录
# 4. 登录态持久化在浏览器 profile（scripts/check-cdp.sh 的 USER_DATA_DIR），下次无需重复登录
```

未登录时 API 会返回 `error_code: 10022 用户未登录`，爬取结果为空——看到这个就按上面的步骤补一次登录。

> **热帖数据源不依赖关注列表**：账号没关注任何人时，`--hot` 或默认双源仍能爬取雪球热帖（市场热门内容）。

## 注意事项

1. 需要先登录雪球账号（见上方"一次性登录"）
2. 如遇 Verification 验证页面，需手动完成验证后重新运行
3. 爬取过程自动处理分页和 md5__1038 令牌
4. 输出文件保存在当前工作目录
5. **Subagent 调度**：分析任务通过 subagent 执行，并发数≤3，失败自动重试 2 次
6. **环境适配**：主 agent 根据当前环境工具选择 subagent 启动方式
7. **行情验证**：候选 A 股标的用 stock-datasource MCP（`get_realtime`/`get_kline`/`get_stock_financial`/`get_stock_money_flow`/`get_news_by_stock`）验证，港美股不验证只标观点

## 典型使用场景

1. **每日投资要闻回顾**：爬取最近 24 小时（关注+热帖），AI 验证后生成未来投资方向报告
2. **市场热点洞察**：账号未关注任何人时用 `--hot` 爬热帖，AI 分析当下市场热门方向
3. **关注大 V 动态**：`--follow-only` 爬取最近 N 天关注时间线，AI 分析投资观点变化
4. **特定事件追踪**：指定日期范围，AI 整理事件期间的讨论并生成方向报告
