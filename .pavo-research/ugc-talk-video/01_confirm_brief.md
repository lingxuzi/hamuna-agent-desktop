> 按 `bundled-skills/creative-video-suite/SKILL.md`「视频生成门禁」要求，视频生成前必须输出确认摘要并等待明确许可。

## 项目

- **品牌（虚构）**：薇光 (WēiGuāng) · 国产敏感肌精华液
- **产品**：肌源舒缓精华（30ml 琥珀色滴管瓶）
- **目标受众**：25-35 岁泛红敏感肌女性
- **投放**：抖音 / 小红书 信息流原生竖屏

## 视频规格

| 字段 | 取值 | 依据 |
|---|---|---|
| 总时长 | 60s | 行业 UGC 信息流标准长度 |
| 段数 | 5 段 | hook-痛点-产品-反馈-CTA 经典结构 |
| 单段时长 | 各 12s | agnes-video-2.5-flash 上限 |
| 比例 | 9:16 | 短视频信息流原生竖屏 |
| 分辨率 | 720P | 2.5-flash 锁死 |
| 视频模式 | `keyframe` | 必须锁定人脸 + 服装一致性（前后帧链） |
| 音频 | 仅 BGM（后期配音） | 不进 MCP `audios[]`，避免 2.5-flash 音频不稳定 |
| 字幕 | 后期添加 | MCP 不生成字幕 |

## 5 段结构（UGC 五段法）

| Cut | 时长 | 目的 | 镜头 | 台词（后期配音） |
|---|---|---|---|---|
| **Cut1** | 12s | **Hook · 痛点共鸣** | 化妆台前自述，素颜泛红肌 | "姐妹们，如果你也是那种一到换季脸就又红又痒的……听我说完" |
| **Cut2** | 12s | **产品引入** | 拿出滴管瓶，镜头特写 | "这是我用了三周的那个国产小众精华，三十几块，真的绝" |

| **Cut4** | 12s | **效果反馈** | 照镜子惊讶表情 | "第二天早上起来……姐妹们自己看，这个退红效果" |

## 帧链结构（keyframe 模式一致性锁）

```
Cut1.first_frame (手绘/AI 生成) ─→ Cut1.video → Cut1.last_frame
                                              │
                                              ▼
Cut2.first_frame = Cut1.last_frame ─→ Cut2.video → Cut2.last_frame
                                                      │
                                                      ▼
Cut3.first_frame = Cut2.last_frame ─→ ...
```

> 实施时：**先 image_generate 生成 5 张"静态首帧"**，再用 video_generate (keyframe, first_frame + last_frame 都给) 生成每段视频。last_frame 也走 image_generate 单独生成（确保前后帧都是高质量静态图，再让 video 在两帧之间补间）。

## 风险提示

1. **数量警告（已违反 SKILL.md 默认）**：单批 5 个视频 > 2 个上限。已**显式分 3 批执行**（2+2+1）规避红线。
2. **人脸一致性**：2.5-flash 单图生成无法严格锁脸，5 张人设图 prompt 用相同描述锚点（年龄/发型/服装/场景）尽量接近，但**完全一致需更高模型**（pro 系列）。如对一致性敏感，建议改用 product-marketing-ad-video-no-storyboard-ref（无人脸）。
3. **first_frame 比例**：所有 prompt 显式声明 `9:16 vertical frame` + `ratio: "9:16"` 双保险，避免 keyframe 模式比例不匹配静默失败。
4. **音频未走 MCP**：MCP audio 通道不稳定，全部用后期配音。如必须用 MCP audio → `audios=["/path/to/bgm.mp3"]`，每段 ≤ 1 个。
5. **总时长 60s = 5×12s，零冗余**：2.5-flash 上限就是 12s，无法做到 15s/段。Cut5 的 CTA 收尾可能偏急。
