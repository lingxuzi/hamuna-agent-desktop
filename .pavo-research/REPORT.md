# Pavo 工作台短剧制作调研报告

> **调研时间**：2026-09-08
> **目标 URL**：https://app.pavo-ai.cn/
> **方法**：Playwright 实操浏览器 + DOM 抓取（pavo 残留登录态可用）
> **样本**：3 个对比项目（AI 生成路径 ×2 + 上传 docx 路径 ×1）

## 一、端到端制作流程（3 步走）

```
AI剧本创作（首页 /playlet/list）
   │
   ├─ 路径 A：AI 生成剧本（4 个输入字段）
   │     └─ 用户故事创意 + 风格库 + 视频比例 + 集数
   │
   └─ 路径 B：上传我的剧本（≤10万字 txt/docx）
         └─ 拖拽或点上传，自动解析分集
   │
   ▼
┌────────────────────────────────────┐
│ Step 1. 剧本大纲（/playlet/review/:id）    │
│   • 元数据：剧集 / 故事类型 / 目标受众         │
│   • 剧情概要 / 世界观设定 / 角色设定           │
│   • 集标题 + 导演式分集脚本                   │
└────────────────────────────────────┘
   │ [下一步]
   ▼
┌────────────────────────────────────┐
│ Step 2. 资产库                          │
│   • 角色列表 / 场景列表 / 道具列表            │
│   • 自动从剧本提取所有角色（含 AI 加配角）    │
│   • 每个角色生成 1 张"日常"形象图            │
└────────────────────────────────────┘
   │ [下一步]
   ▼
┌────────────────────────────────────┐
│ Step 3. 分集视频                          │
│   • 每集拆为 N 个镜头（13-18 个）             │
│   • 单镜头：4-15 秒                         │
│   • 单集总时长：50s-104s                    │
│   • 批量生成图片 → 批量生成视频 → 合成       │
└────────────────────────────────────┘
```

**关键数字**（小满面馆 5 集样本）：

| 1 | 00:50 | 3 | 2 | 14 |
| 2 | 00:58 | 3 | 2 | 16 |
| 3 | 01:04 | 3 | 2 | 18 |
| 4 | 00:50 | 4 | 1 | 13 |
| 5 | 01:01 | 4 | 2 | 17 |

## 三、AI 自动生成的剧本元数据（剧本大纲页可见）

| 字段 | 雾城迷踪（悬疑） | 小满面馆（穿越美食） |
|------|---------------|-------------------|
| **剧集** | 10 | 5 |
| **故事类型** | 悬疑推理 | **古装穿越 + 美食爽文 + 市井创业**（多标签） |
| **目标受众** | 悬疑爱好者 25-45岁 | **女频 / 短剧泛受众 / 美食爱好者**（多标签） |
| **剧情概要** | 1 段 4-5 句的紧凑铺陈 | 1 段主线 + 转折 + 高潮 + 钩子 |
| **世界观设定** | 时代 / 地域 / 社会背景 / 科技水平 | 同结构 |
| **角色设定** | 每人 2-3 行（身份+动机+性格） | 同结构 |

> 💡 关键洞察："故事类型"和"目标受众"都允许**多标签组合**（用 + / /  分隔），不是单选。这给下游模型更宽的语义锚点。

## 四、剧本（集级）的导演式语法

**统一的 4 种标记**：

| 标记 | 作用 | 示例 |
|------|------|------|
| `【场景】` | 镜头场景标题（时间 + 地点） | 【场景】夜，老旧出租屋。<br>【场景】夜，老旧出租屋（回忆：三年前）。 |
| `△` | 镜头内动作 / 视觉描述 | △ 林远蜷缩在沙发一角，衬衫领口敞开着... |
| `角色名（情感，语调）：` | 对话 | 林远（低沉，断续）：陈默…… |
| `【道具】` | 关键道具插入 | 【道具】净室标识<br>【道具】演唱会门票 |

**对比样本 1：雾城迷踪（悬疑电影风格）**
```
【场景】夜，老旧出租屋。
△ 林远蜷缩在沙发一角，衬衫领口敞开着，布满胡茬的下巴埋进手掌。
  他面前散落着几瓶空了的酒瓶...
林远（低沉，断续）：陈默……
【场景】夜，老旧出租屋（回忆：三年前）。
画面色调骤然转冷，冷白色的警灯红光交替闪烁...
```

**对比样本 2：绿茶舍友的现形记（国风3D风格）**
```
【场景】白天，女生宿舍。
△ 柔弱矮小的周妍正用纤细的双手试图搬起那桶水，她咬着牙，脸涨得通红...
周妍（带着哭腔，气喘吁吁）：好重啊……
林夏（宠溺地笑，从兜里掏出一张精美的门票）：好啦，别贫了。给，拿着。
【道具】演唱会门票
```

**对比样本 3：小满面馆（真人古风写实风格）**
```
【场景】日，林家面馆。
△ 热油泼在葱花上，滋啦一声白烟腾起...
林小满（小声懵圈）：我刚拍完葱油面教程……这是哪里？我这是穿越了吗？！
【道具】二两债务欠条，阳春面，铜板
```

**差异**：
- **悬疑**：大量 △ 铺环境/动作，闪回子场景多（场景名后括号），文字密度高
- **现代情感**：△ 短而频，情感动作标注细腻（"带着哭腔"/"小得意"），【道具】密集
- **穿越爽文**：△ 含蒙太奇引导（"【快剪蒙太奇，配轻快国风 BGM】"），内心独白频繁

## 五、单镜头 Prompt 模板（Step 3 分镜页面，最精细的层级）

**单镜头的 prompt 字段**（从分镜页面 DOM 抓取，专业导演分镜语法）：

```
┌─ [约束]    片段时长请限制在4-15s，输入"@"可引用角色、场景
├─ [关键帧] ( 关键帧展示片段内容。可选择用作参考，或跳过生成 )
├─ [建议]   建议先生成分镜图片，以获得更统一的角色形象和更流畅的故事呈现
└─ [时长]   00:00 / 00:08

┌─ [起幅]   "特写起幅，一碗热气腾腾的骨汤阳春面..."
├─ [景别]   特写 / 近景 / 中近景 / 中景 / 过肩中景 / 双人中景 / 平视
├─ [运镜]   镜头固定 / 镜头缓缓下摇 / 镜头拉远 / 镜头跟随 / 镜头推近 /
│           镜头微微前推 / 镜头快速上拉 / 镜头向右横移
├─ [角色@]  @林小满 / @刘账房 / @赵衙役（@ 引用资产库角色）
├─ [场景@]  林家面馆厨房-基础形象（引用资产库场景）
├─ [动作]   猛地惊醒 / 大口喘着粗气 / 用手抚摸着粗粝的衣料
├─ [转场]   通过水波纹状的幻觉转场 / 叠画回切 / 横移重组画面
├─ [表情]   神色惊惶 / 嘴角挂着自信的微笑 / 满脸陶醉
├─ [对白]   "我刚拍完葱油面教程……这是哪里？！"
├─ [音效]   滋啦一声热油泼在葱花上 / 刀刃起落声
├─ [色调]   逆光 / 画面色调变黄 / 热浪袭人
└─ [落幅]   落幅在...的半身画面上 / 落幅在...的站位对比中
```

**示例**（小满面馆第 4 镜头，赵刑登场）：
> 起幅为过肩中景，逆光从大门射入。**板着脸、攥着账本猛然闯入大厅**，快步走到粗糙的木桌前。镜头跟随@刘账房的动作下移，只见他用毛笔笔杆重重敲击木桌。随后镜头快速上拉，对准@刘账房嚣张的面部近景，他朝着桌子对面的@林小满大声宣告："**你爹娘欠的二两银子，后天再不还，这面馆可就归我们当铺了。**"落幅在@刘账房那因轻蔑而微微挑起的嘴角上。

## 六、不同类型短剧的结构差异总结

| 维度 | 悬疑/推理 | 现代情感/都市 | 古装穿越/爽文 |
|------|----------|--------------|--------------|
| **故事类型（多标签）** | 单标签为主 | 单标签为主 | **多标签组合** |
| **目标受众** | 精准年龄层（25-45岁） | 模糊泛受众 | **标签组**（女频/泛受众/爱好者） |
| **世界观** | 当代 + 科技边缘 | 当代 + 校园/职场 | 架空古代 + 市井 |
| **场景密度** | 多（夜/雨/警局/地下） | 少（宿舍/家/咖啡厅） | 中（面馆/厨房/街市） |
| **道具频率** | 关键节点集中 | 频繁插入 | 关键转折 |
| **对白/动作比** | 动作 ≈ 对白 | 对白 > 动作 | **对白 + 内心独白** 多 |
| **转场复杂度** | 高（闪回/水波纹转场） | 中（叠画） | 中（蒙太奇） |
| **景别偏好** | 近景/特写（情绪） | 中景/对话景 | **特写（食物/道具）多** |
| **BGM/音效提示** | 偶有音效 | 偶有 | **显式蒙太奇 BGM 提示** |

## 七、复用建议（如果要学 pavo 做一个对标产品）

### 1. 输入要极简（pavo 只让用户填 4 个字段）
- 故事创意（textarea）
- 风格库（60+ 单选模板）
- 视频比例（4 个左右）
- 集数（5/10 档位）

> 拒绝让用户填"角色/场景/世界观"——这些都是 AI 自动生成的。

### 2. 用"剧本元数据"作为模型的中介表示
- 故事类型（多标签）→ 锚定题材
- 目标受众（多标签）→ 锚定风格密度
- 世界观设定 → 锚定场景词汇表
- 角色设定 → 锚定人物动机库

### 3. 用**专业导演脚本**而非自然语言当主格式
- `【场景】` 标记 = 镜头切换点
- `△` 标记 = 镜头内视觉描述
- `角色（情感，语调）：` = 对话
- `【道具】` = 关键物件锚点

> 比"角色A 走向桌子..."这种通用 LLM 写法更适合多模态视频生成。

### 4. 资产-剧本分离（自动提取 + @ 引用）
- Step 2 从剧本文本自动提取所有出场角色 / 场景 / 道具
- Step 3 单镜头 prompt 里用 `@` 符号引用这些资产
- 这样保证多镜头之间角色形象/场景一致（不出戏）

### 5. 单镜头 prompt 是"导演+摄影"双轨
- **导演**字段：动作、对白、情绪
- **摄影**字段：景别、运镜、转场、色调、起/落幅
- **美术**字段：道具、光线、空间
