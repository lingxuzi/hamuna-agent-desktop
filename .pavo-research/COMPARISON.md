## 二、AI 自动生成的"故事类型"和"目标受众"模式

### 故事类型标签组合规律

| 类型组合模式 | 样本 | 标签数 |
|------------|------|--------|
| **单标签精确** | 悬疑惊悚 / 仙侠悬疑 / 校园奇幻 | 1 个 |
| **跨题材多标签** | 古装穿越 + 美食爽文 + 市井创业 | 3 个 |
| **现实细分** | 悬疑推理 | 1 个 |
| **情绪化标签** | 现代情感 | 1 个 |

**洞察**：
- 风格库的"风格"≠"题材"，是**视觉**维度（真人/3D/2D + 时代/美学流派）
- "故事类型"是**题材**维度（悬疑/仙侠/校园/情感/穿越/美食...）
- 多标签组合时通常是**主类型 + 子类型 + 商业属性**
- 受众标签通常是 **年龄 + 性别倾向 + 兴趣** 三元组合

### 受众标签模式

| 模式 | 样本 | 结构 |
|------|------|------|
| **年龄 + 兴趣** | 悬疑爱好者18-35岁 / 青少年及玄幻爱好者 | age + interest |
| **性别 + 类型 + 兴趣** | 女频 / 短剧泛受众 / 美食爱好者 | gender / mass / niche |
| **纯年龄** | 青少年 | age only |

**洞察**：受众标签越细，下游生成的剧本就越"分众化"（如"女频"会优先生成男主视角的霸总/重生/逆袭元素；"美食爱好者"会加大量食物特写蒙太奇）。

## 四、角色设定的统一模式

**格式**：每人 2-3 行
```
{姓名} {身份/职业}，{核心性格}，{关键特征}。{核心动机是X}，{成长弧/阻碍是Y}。
```

| 样本 | 角色 1 | 角色 2 | 角色 3 |
|------|--------|--------|--------|
| 暴雨夜的回声 | 林远：古董店老板，性格沉稳但内心背负兄弟失踪的伤痛，核心动机是揭开真相并找回林近。 | 林近：林远的双胞胎兄弟，失踪多年后被囚禁在地下室，性格坚韧，在逆境中保持清醒。 | 苏晴：神秘女子，也在调查旧城失踪案，冷静且富有洞察力，帮助林远解开部分谜团。 |
| 古刹剑魂 | 青梧：表面是资质平庸的古刹剑修，实为镇魔剑灵的转世。她性格坚韧隐忍，因前世记忆觉醒而陷入身份危机，核心动机是拯救苍生并解开自身身世之谜。 | 玄慈住持：古刹的实际掌控者，表面慈悲庄严，实则野心勃勃。他渴望通过操控魔尊本源实现超脱，是青梧重塑灵根道路上的最大阻碍与反派。 | 阿哑：古刹中的神秘哑童，知晓部分禁忌真相。他天真而忠诚，关键时刻以命换命，成为青梧对抗住持与心魔的重要助力。 |
| 十年后的回信 | 林小满：内向高中女生，敏感善良但害怕被拒绝。核心动机是完成告白并理解日记真相，最终学会直面未来而非依赖预知。 | 陆言：阳光但有些笨拙的男生，暗恋林小满多年。主动靠近她并相信她的异常举动，成为她克服恐惧的催化剂。 | 日记：会说话的奇幻物品，记录十年后林小满的信。它既是警告者也是情感载体，推动小满面对内心恐惧。 |

**模式规律**：
1. **3 个角色是黄金数**（主+对手/盟友+辅助/信物）
2. **必有一个"表里不一"角色**——身份反转是 AI 短剧的高频套路（古刹剑魂的玄慈住持 / 雾城迷踪的陈局长 / 暴雨夜的林远父亲 / 绿茶舍友的周妍）
3. **角色描述里必带"核心动机"和"成长弧"**——这是剧本生成的关键种子
4. **物件可以当角色**（十年后的回信的"日记"）——非人实体入角，扩展了角色维度

## 五、剧情概要的统一模式

**结构公式**：
```
{开场钩子} → {核心冲突} → {升级事件} → {关键转折} → {高潮对决} → {结局钩子}
```

**示例对比**：

| 样本 | 概要节选 |
|------|---------|
| 暴雨夜的回声 | "暴雨夜，古董店老板林远收到匿名信，里面夹着一张三十年前的旧照片，照片中竟是他失踪多年的双胞胎兄弟林近。林远震惊之余...他决定独自深入旧城寻找线索，却在过程中发现近年来多起离奇失踪案的时间线都与这个工厂有关...当他终于撬开地下室深处的一扇铁门时，却看到林近被锁在里面，神情木然...幕后黑手现身，竟是林远以为早已去世的父亲。" |
| 古刹剑魂 | "青梧在青云古刹修行时遭遇心魔反噬，强行突破封印后觉醒了前世作为'镇魔剑灵'的记忆...若不立刻重塑灵根，魔尊将在三日内破封，届时苍生涂炭...她发现古刹中隐藏着一处禁地...意外发现古刹主持玄慈竟是隐藏最深的反派。" |
| 十年后的回信 | "林小满在图书馆捡到一本会说话的日记，发现它是十年后的自己寄来的信。日记警告她必须在三天后的天台告白截止日说出真话...截止日当晚暴雨，陆言也登上天台...最终放弃日记中的完美台词，用最真实笨拙的声音告白。" |

**AI 写作规律**：
- **开头必用场景+时间锚点**（"暴雨夜" / "在图书馆"）
- **核心冲突必有时间限制**（"三日" / "截止日" / "三日内"）—制造紧迫感
- **必有一个"表里不一"的揭露**（父亲囚禁儿子 / 住持是反派 / 日记不是预言）
- **结局留开放钩子**（兄弟重逢+旧城暗流 / 苍生待救+反派未灭 / 未来仍有选择）

## 七、单集剧本的导演式语法（横向对比）

### 统一 4 种标记
- `【场景】` = 镜头场景标题
- `△` = 镜头内视觉/动作描述
- `角色名（情感，语调）：` = 对话
- `【道具】` = 关键物件插入

### 风格特化差异

| 维度 | 悬疑电影风格 | 国风3D风格 | 二次元动漫 | 真人古风写实 |
|------|------------|-----------|-----------|------------|
| **场景描写的颗粒度** | 极细（光影、色彩、声音、回忆穿插） | 中等 | 偏心理活动+表情 | 中等偏细 |
| **△ 的密度** | 高（每段 3-5 个 △） | 中（每段 2-3 个） | 高（配合心理独白） | 高（特别在食物镜头） |
| **【道具】频率** | 关键节点（工牌、数据盘、徽章） | 中等 | 偶有 | 高频（菜品、调料、票据） |
| **闪回/转场** | 频繁（场景后括号标"回忆：X年前"） | 较少 | 较少 | 蒙太奇显式标注 |
| **内心独白** | 罕见（只露在表情） | 中等 | 频繁（配合日记旁白） | 显式标"内心独白" |
| **BGM/音效提示** | 偶有（电流声、警笛） | 偶有 | 显式（"内心BGM响起"） | 显式（"轻快国风BGM"） |
| **对白/动作比** | 动作 ≈ 对白 | 对白较多 | 对白 > 动作 | 对白 + 食物动作特写 |
| **场景后括号标注** | 频繁（"回忆：三年前"） | 较少 | 较少 | 偶尔 |

## 八、风格库风格 vs 视觉输出对照

| 风格库选 | 实际视觉风格（从分镜 + 角色描述反推） |
|---------|--------------------------------------|
| **悬疑电影风格** | 蓝橙色调 / 雨夜 / 阴影 / 镜头胶片质感 / 短焦景深 |
| **3D古风国漫** | 飘逸长袖 / 仙气 / 国风色系（青绿/朱红）/ 长镜头飘逸运镜 |
| **二次元动漫** | 大眼萌系 / 高饱和 / 校园樱花 / 内心独白框 / 镜头运动夸张 |
| **国风3D风格** | 水墨晕染 / 古典色 / 工笔线条 / 中景为主 |

1. 视觉美学（色调/光线/景别）
2. 镜头语言（运镜节奏/景别偏好）
3. 剧本语法（是否含蒙太奇标注、内心独白、转场提示）
4. 情绪密度（每分钟情感转折数）

## 九、复用提示词结构总结（核心交付）

### 用户输入层（4 个字段）
```
1. 故事创意（textarea，~80-150 字）
   格式："{主人公身份}在{触发事件}，发现{核心矛盾}。他必须{时间限制}，否则{严重后果}。"
   关键词锚点：身份 / 触发 / 矛盾 / 时限 / 后果
   
2. 风格库（60+ 单选模板，分类：2D / 3D / 真人）
   - 2D：动漫/插画/漫画/水墨/皮影...
   - 3D：次世代/国风/迪士尼/UE5...
   - 真人：影视仿真/古风/都市/悬疑/恐怖...
   
3. 视频比例（9:16 默认短剧）
4. 集数（5/10/20/50/80/100）
```

### AI 输出层（自动生成的元数据）

```
{
  "剧集": 5-10,
  "故事类型": "单标签" 或 "主类型 + 子类型 + 商业属性"（多标签）,
  "目标受众": "年龄 + 兴趣" 或 "性别 + 类型 + 兴趣"（三元）,
  "剧情概要": "开场钩子→核心冲突→升级→转折→高潮→钩子",
  "世界观设定": "时间+地域+场景列表+社会背景+冲突基调",
  "角色设定": [
    {"姓名":..., "身份":..., "性格":..., "核心动机":..., "成长弧":...}
    // 必有一个"表里不一"角色
    // 3 个角色是黄金数
  ]
}
```

### 集级剧本（导演式语法）
```
【场景】{时间}，{地点}（可选：{子场景注}）。
{环境描写。}
△ {镜头动作 / 视觉描述}。
{角色名}（{情感}，{语调}）：{台词}。
【道具】{关键道具名}
```

### 分镜级 prompt（4-15s/个）
```
[约束]: 片段时长 4-15s，@ 引用角色/场景
[起幅]: {特写/近景} 起幅，{起始画面}
[景别]: 特写/近景/中近景/中景/过肩中景/双人中景
[运镜]: 镜头固定/下摇/上拉/推近/前推/横移
[角色@]: @角色名（从资产库引用）
[场景@]: @场景名
[动作]: {动词} + {细节}
[转场]: {转场类型}（叠画/水波纹幻觉/横移重组）
[表情]: {情绪关键词}
[对白]: "..."
[音效/声]: {声音描述}
[色调/光线]: {光线方向} + {色调}
[落幅]: 落幅在...的画面上
```

## 十、对 agnes 短剧 skill 的设计启示

1. **用户输入要极简**（4 字段）：故事创意 + 风格 + 比例 + 集数
2. **AI 中介表示统一**：剧集/类型/受众/概要/世界观/角色 6 个字段
3. **导演式剧本语法**：4 种标记贯穿"集→分镜"两层
4. **风格 = 视觉+镜头+剧本+情绪**四维耦合：选风格不只是选滤镜
5. **跨题材多标签**比单标签更"商业化"（用户偏好"复合题材"）
6. **3 角色 + 1 物件**是黄金结构（角色 + 角色 + 反派/信物）
7. **剧情概要必须有时限**（"三日"/"截止日"）—AI 短剧的紧迫感来源
8. **风格库应该是"完整模板包"**——不是简单提示词后缀，而是耦合美学/镜头/剧本的全栈风格定义
9. **每个分镜必须含 12 个标准字段**——保证下游 Agnes Video 能产出稳定结果
10. **风格库要按"美学派系"分类**（真人/3D/2D），不要按题材分类（题材由故事类型决定）
