## 1. 适用范围：产品带货短剧

**"产品带货短剧"** = 兼具剧情形式与商业目的的短片，3 种 hybrid 路径：

| 路径 | 现有 skill 路由 | 适用场景 | 时长 |
|---|---|---|---|
| **A. UGC 升级版** | creative-video-suite UGC | "带货前讲故事"——30s 剧情 hook + 4 段式带货 | 30-45s |
| **B. Marketing 剧情弧** | creative-video-suite Marketing | "带货带情绪"——5 段式 + 小冲突反转 | 15-30s |
| **C. Drama 完整短剧** | agnes-short-drama / creative-video-suite drama | "剧情带货"——完整短剧 + 品牌植入 | 60-180s |

**路由边界（与现有 skill 不冲突）**：

- ❌ 不覆盖 TVC / 4A 广告大片 → 走 `tvc-director`
- ❌ 不覆盖企业宣传（旁白主导，8-10 镜）→ 走 `creative-video-suite` Corporate
- ❌ 不覆盖纯剧情无产品 → 走 `agnes-short-drama`（无 `product_ref` 强门控）
- ❌ 不覆盖传统 Marketing 5 段式无剧情弧 → 现有 `creative-video-suite` Marketing 路径

**强制起点**：3 路径都必须经过"4 模式路由（创意开发 / 剧本大纲 / 人物小传 / 剧本正文）"的上游结构——跳过模式 2（剧本大纲）直接写模式 4（剧本正文）是 XiaoLuo 红线禁止的常见错误。

## 2. 4 模式路由（编剧上游）

参考 XiaoLuo 4 模式，按 hamuna-agent-desktop 实际流水线映射：

| XiaoLuo 模式 | 对应流水线阶段 | 产物落点 | 强制阶段？ |
|---|---|---|---|
| **模式 1：创意开发** | planner 阶段 | `01_planner.md` + `project.json` | 仅创意模糊时 |
| **模式 2：剧本大纲** | scriptwriter / planner 后段 | `02_script.md`（drama 路径） | **必走** |
| **模式 3：人物小传** | assets 阶段 | `04_assets/characters/<名>/assets.md` | **必走** |
| **模式 4：剧本正文** | storyboard 阶段 | `03_storyboard.md` + 分镜表 | **必走** |

**应用顺序**：模式 1（如果需要创意孵化）→ 模式 2（结构）→ 模式 3（人物）→ 模式 4（场景剧本）。

**严禁顺序**：模式 1 跳过模式 2 直接写模式 4——长篇需要结构支撑，短剧需要钩子设计，广告需要产品进入时机。

## 3. 三幕结构 vs 短剧结构 vs 广告结构

| 维度 | 长篇三幕 | 短剧 | 广告 |
|---|---|---|---|
| **总时长** | 90+ 分钟 | 60-180s | 15-60s |
| **单元** | 场次 | 集数 / segment | 段（Cut1-Cut4） |
| **钩子位置** | 第一幕结束 | 集首 0-10s | 0-2s（hook） |
| **核心冲突** | 欲望 vs 阻力长线 | 当集目标 vs 正面阻力 | 产品需求 vs 用户问题 |
| **反转点** | 第二幕中点 | 中段信息释放 | 中段小冲突反转 |
| **结尾** | 视觉高潮 | 离场钩子 / 新威胁 | packshot hold |
| **应用范围** | ❌ 不在本方法论 | ✅ A / C 路径用 | ✅ A / B 路径用 |

**Hybrid 路径结构选择**：

- **A. UGC 升级版**：广告结构（30s 剧情 hook 段） + 短剧结构（4 段式带货段）
- **B. Marketing 剧情弧**：广告结构（5 段式 hook→证明→packshot） + 短剧钩子（中段小冲突反转）
- **C. Drama 完整短剧**：短剧结构（60-180s segment × N） + 广告结构（`product_ref` 推动剧情）

## 4. 短剧钩子设计（前 0-10s）

XiaoLuo 短剧结构强调：**0-10s 视觉钩子**——用异常画面、未完成动作、身份暴露或结果倒置抓住注意力。

| 钩子类型 | 适用场景 | 示例 |
|---|---|---|
| **异常画面** | 产品关联场景的非常规视觉 | "30 岁的她在地铁里突然站起来，手里的精华液倒进咖啡" |
| **未完成动作** | 制造悬念 | "她的手停在门把手上，没有按下" |
| **身份暴露** | 制造反差 | "她拿的产品包装上印着另一个名字——是她自己公司的竞品" |
| **结果倒置** | 反常识 | "三个月后她才意识到，她卖的产品救了她自己" |

**强制应用**：

- **A 路径必须**：30s 剧情 hook 段含 1 个明确钩子类型
- **B 路径必须**：5 段式 0-2s 第一镜就是钩子
- **C 路径**：每集 0-10s 都是新钩子，且每集必须"回答一个小问题 + 提出一个更大的问题"

## 5. 三路 Hybrid 方法论

### 5.1 路径 A：UGC 升级版（30s 剧情 hook + 4 段式带货）

**结构**：30s 剧情 hook 段 → 12s 4 段式带货段（Cut1-Cut4）

```text
[00:00-00:30]  剧情 hook 段
  - 单一场景 / 单一人物 / 单一冲突
  - 必须有"未完成动作 / 身份暴露 / 异常画面"钩子之一
  - 视觉锚点：人物 + 场景 + 一个产品相关物件（如开箱动作）

[00:30-00:42]  4 段式带货段（继承 creative-video-suite UGC 4 段式）
  - Cut1 0-2s hook → 接续剧情 hook 悬念
  - Cut2 2-5s 产品揭示（产品图门控）
  - Cut3 5-9s 卖点证明
  - Cut4 9-12s packshot
```

**产品图门控**：复用 `creative-video-suite` UGC §1.4 降级路径——无产品图需用户显式 ack。

**剧情 hook 剧本正文要求**（应用 XiaoLuo 模式 4）：

- 场景格式：`【场景名 / 时间 / 室内或室外】`
- 动作：现在时 / 短句 / 主动动词 / 可拍摄
- 对白：`角色正式姓名："台词。"`
- 5 维微表演（见 §7）

**时长硬约束**：单次视频生成固定 12 秒（MCP `seconds` 上限 12）。A 路径 30s 剧情 hook + 12s 带货 = **必须拆 3 段**（30s 拆 3×10s 或 12s/12s/18s 拼）→ 走 `long_video_stitch_mode`，先做全片叙事规划再切分。

### 5.2 路径 B：Marketing 剧情弧（5 段式 + 小冲突反转）

**结构**：15-30s 5 段式 hook→揭示→证明→结果→packshot，中段插入小冲突反转。

```text
[0-2s]   hook：异常画面钩子（如她困惑选哪款精华）
[2-5s]   揭示：产品进入（产品图门控）
[5-9s]   证明：卖点 A + 小冲突反转（朋友推荐出错，她重新对比）
[9-13s]  结果：冲突解决（她找到正确产品）
[13-15s] packshot hold
```

**小冲突反转设计模式**：

- **对比反转**：以为是 A，结果是 B（B 才是产品）
- **信任反转**：朋友推荐不可靠，最终靠自己研究
- **视觉反转**：表面是问题，底层是机会

**与 Marketing 现状差异**：`creative-video-suite` Marketing 现在是无剧情 hook→证明→packshot；本路径加"小冲突反转"做剧情弧——不破坏现有 §5 商业 3 路差异表 Marketing 行（Marketing 行只规定 15s 5 段结构 + `product_ref` 强门控，不规定是否含冲突反转）。

**`product_ref` 门控**：B 路径必须传 `product_ref`（继承 Marketing 强门控）+ 产品必须推动反转发生（XiaoLuo 广告结构 line 242 铁律："产品进入剧情后必须推动事件发生"）。

### 5.3 路径 C：Drama 完整短剧（5 阶段 + 品牌植入）

**结构**：完整 drama 5 阶段流水线（planner→script→storyboard→assets→frame→video）+ `product_ref` 强门控。

**关键差异 vs 现有 drama**：

- `product_ref` 门控继承：drama 默认无 `product_ref`，本路径 `product_ref` 是强门控
- product 必须**推动剧情发生**（XiaoLuo 广告结构铁律）
- product 卖点通过**可见结果呈现**（不靠旁白堆砌）
- 5 维微表演在每场必含至少 1 个维度

**分集表设计**（XiaoLuo line 235 模板）：

```text
集数｜当集目标｜核心冲突｜关键反转｜结尾钩子｜人物变化
```

**场次规划**（XiaoLuo line 206-219）：

- 场景与时间 / 出场人物 / 场景目标 / 主要阻碍 / 信息释放 / 关系变化 / 场景转折 / 离场钩子
- 没有人物目标、冲突或状态变化的场次应删除或合并

## 6. 人物小传要点（XiaoLuo 模式 3）

每个核心人物必含：

- **基础信息**：姓名 / 年龄 / 身份与职业 / 可拍摄外貌特征 / 性格外显方式
- **深层设计**：人物欲望 / 人物需求 / 人物恐惧 / 人物秘密 / 人物缺陷 / 人物底线 / 人物能力 / 人物代价 / 人物弧光
- **戏剧功能**：制造或承受冲突 / 与主角价值观差异 / 掌握关键信息 / 推动反转 / 视觉记忆点
- **人物关系**：`角色A ↔ 角色B` 表面关系 / 实际需求 / 隐藏矛盾 / 权力变化 / 关系终点

**落点**：`04_assets/characters/<名>/assets.md`（与 `creative-video-suite` 现有规范一致）

**关键禁忌**（XiaoLuo 连续性检查）：

- ❌ 不同人物只有相同欲望和说话方式（必须差异化）
- ❌ 抽象情绪词代替表演（必须转换为可观察行为，见 §7）
- ❌ 人物代词（他 / 她 / 它 / 他们）——必须用正式姓名

## 7. LuoDesign 五维微表演系统

**剧本动作描述禁止用抽象情绪词代替表演**——高层创意分析可以讨论情绪功能，但剧本正文必须转换为可观察行为。

**禁止直写情绪词**：悲伤 / 愤怒 / 绝望 / 委屈 / 崩溃 / 害怕 / 紧张。

### 维度一：微表情与视线

- 瞳孔收缩或扩张
- 视线停留、躲闪、失焦或重新聚焦
- 睫毛颤动
- 眼睑收紧或抬起
- 眉间、鼻翼、咬肌和嘴角变化
- 双唇轻抿、张开、停顿或闭合

### 维度二：肢体与重心

- 肩膀收拢或下沉
- 胸腔起伏
- 身体前倾、后撤或侧移
- 手指抓握、松开、摩擦和悬停
- 膝盖与脚步方向
- 防御姿态与支撑面

### 维度三：动作中间态

优先捕捉未完成瞬间：

- 抬起的手停在半空
- 转身动作突然停顿
- 半步跨出后收回
- 想触碰却停在物体前方
- 已经开口却没有发出声音

**禁忌**：不得每句都机械加入停顿——动作中间态必须服务冲突和节奏。

### 维度四：生理反应

- 呼吸变浅、加快、卡顿或长吐
- 喉结滚动
- 鼻翼翕动
- 手指颤动
- 冷汗沿皮肤移动
- 肌肉、下颌与手腕紧绷
- 声音发紧、断句或气息不足

### 维度五：光影动态

- 人物转身使窗光从面部移到耳后
- 胸腔起伏带动衣领阴影轻微位移
- 门缝扩大后，走廊光线逐渐切入地面
- 人物靠近灯具后，眼底反光变得清晰

**禁忌**：光影必须来自场景内合理光源，不能凭空变化。

**落点**：所有 5 维描述进入：

- `02_script.md`（drama 路径，剧本正文段）
- `03_storyboard.md`（commercial 路径，分镜表 `shot_description` 字段）
- creative-video-suite T04-T12 video_generate 模板的 `Dynamic Description` 段

**正确 vs 错误示例**（XiaoLuo line 319-325）：

```text
❌ 林雪想起童年，心中非常难过。

✅ 林雪拇指反复摩擦旧钥匙的缺口。林雪视线停在墙上的合影，呼吸逐渐变浅。
```

## 8. 视觉导演化表达

**只在叙事转折 / 信息释放 / 关键表演处加入镜头语言**——不要为每个动作指定镜头。

| 景别 | 用途 |
|---|---|
| 远景 | 人物与环境、权力和距离关系 |
| 全景 | 完整动作与空间调度 |
| 中景 | 对话、动作和人物关系 |
| 近景 | 视线、呼吸和细微选择 |
| 特写 | 证据、手部、眼睛和关键道具 |

| 运镜 | 用途 |
|---|---|
| 推近 | 信息发现和选择时刻 |
| 拉远 | 结果、隔离和关系改变 |
| 横移 / 跟拍 | 连续运动和空间揭示 |
| 固定镜头 | 压迫、等待和强构图 |

**镜头提示格式**（与 XiaoLuo 一致）：

```text
[镜头：景别，机位与运动，构图焦点。]
```

**落点**：`03_storyboard.md` 的 storyboard-shot-table（每个 shot 含 `camera_path` 字段）或 creative-video-suite T04-T08 video_generate 模板的 `Dynamic Description` 段。
